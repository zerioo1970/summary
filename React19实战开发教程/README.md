# React 19 实战开发教程：照着日常开发任务写后台管理系统

> 版本基线（2026-11-10 从 npm 与 Maven Central 查得的最新版本，写到对应章节时再用实际生成的项目核对）：
>
> **前端**：`react 19.3.x` + `react-dom 19.3.x` ｜ `vite 8.3.x`（`react-ts` 模板，create-vite 9.3.x）｜ `typescript 7.0.x`（`strict` 开启，禁止 `any`）｜ `antd 6.7.x` + `@ant-design/icons 6.3.x` ｜ `react-router 8.5.x` ｜ `@tanstack/react-query 5.x` ｜ `axios 1.x` ｜ `dayjs 1.11.x` ｜ Node.js 24 LTS ｜ VS Code
>
> **后端**：Spring Boot 3.5.16 ｜ JDK 21 ｜ Gradle 8.14.x（Spring Boot 3.5 官方支持 Gradle 7.6.4+ 和 8.4+，不支持 Gradle 9）｜ `mybatis-flex-spring-boot3-starter 1.11.x` ｜ `mssql-jdbc 13.x` ｜ SQL Server（你自己的实例）｜ IntelliJ IDEA 或 VS Code
>
> 篇幅：16 章拆成 67 个小章（第 5A、5B……这样编号），每个小章只讲一个技术点，约 20–40 分钟，新概念 ≤ 3 个。
>
> 每章固定骨架：这一章解决什么问题 · 开始之前 · 正文（🖼 图解 → 💻 可运行代码 → 🔍 拆解结果 → 改坏一处试试）· ⚠️ 踩坑警告 · 🎯 动手练习 · 📌 一句话总结 · 下一章 · 参考答案

## 这本教程写给谁

- 学过 [React19精简教程](../React19精简教程/README.md)（至少第 1A–9C 章），知道组件、props、state、effect、路由是怎么工作的。
- 但接到一个真实需求时，不知道从哪里下手：项目目录怎么排、接口层怎么写、列表页和表单页按什么顺序做、登录和权限放在哪一层、怎么打包上线。

精简教程按 **React 概念** 排章节；本教程按 **开发任务** 排章节。每个小章从一个日常开发场景出发（「列表要能分页」「下拉框的选项来自接口」「没权限的按钮不显示」），给出前后端完整代码。原理已经在精简教程讲过的，只给链接，不重复讲。

示例数据不绑定具体业务，只用后台管理系统最常见的几类表来演示技术点：

| 表 | 用来演示 |
| --- | --- |
| 产品 | 列表、分页、查询、排序、新增、编辑、删除、导入导出 |
| 分类（树形） | 树形数据、TreeSelect、下拉选项来自接口 |
| 单据 + 明细 | 明细行（Form.List）、主从表保存与事务 |
| 用户、角色、权限 | 登录、Token、菜单权限、按钮权限 |

## 技术选型和理由

| 用途 | 选什么 | 为什么 |
| --- | --- | --- |
| 界面组件 | Ant Design 6 | 表格、表单、弹窗、树、上传都有现成组件，国内后台管理系统最常用 |
| 发请求 | axios | 拦截器统一处理 Token、返回格式和报错，比每处手写 `fetch` 少重复代码 |
| 服务端数据 | TanStack Query | 加载中、出错、缓存、保存后刷新列表都由它管理，不用每个页面自己写 `useEffect` 取数 |
| 日期 | dayjs | Ant Design 的日期组件用它 |
| 后端返回格式 | 统一 `Result<T>`（`code` / `message` / `data`） | 国内 Spring Boot 项目最常见的约定，前端拦截器只需判断一处 |
| 登录 | Spring Security + JWT | Spring 官方安全框架；前后端分离时用 Token 不用 Session |

**最短路径**：第 1A–8D 章（34 个小章）约 16 小时 30 分。做出带后台布局、可分页查询的列表页、新增/编辑/删除完整可用的模块，前后端连通。
**完整路径**：67 个小章约 33 小时，按每天 2 小时约 17 天。学完能独立完成一个带登录、权限、导入导出、可部署上线的后台管理系统。

小章短，被打断后容易接上。

## 目录

### 第一部分 搭好前后端骨架（11 个小章，约 5 小时 15 分）

**第 1 章 前端工程骨架**

- **第 1A 章 建项目并装好 Ant Design（中文界面）**（30 分钟）
  用 Vite 建项目，装 antd，用 `ConfigProvider` 设中文语言包，日期组件显示中文。
  新概念：组件库 · `ConfigProvider` 全局配置
- **第 1B 章 目录结构约定与路径别名 `@/`**（25 分钟）
  `pages`、`components`、`api`、`hooks`、`types`、`utils` 各放什么；用 `@/api/product` 代替 `../../../api/product`。
  新概念：按职责分目录 · 路径别名
- **第 1C 章 保存时自动格式化与代码检查**（20 分钟）
  多人协作时代码风格一致，提交前发现低级错误。
  新概念：格式化工具 · 代码检查

**第 2 章 后端工程骨架**

- **第 2A 章 用 Spring Initializr 建 Gradle 项目，写第一个接口**（35 分钟）
  选依赖、生成项目、看懂 `build.gradle`，浏览器访问 `/api/hello` 看到 JSON。
  新概念：Spring Initializr · `@RestController`
- **第 2B 章 连接 SQL Server，用 MyBatis-Flex 查一张表**（40 分钟）
  配连接串，实体类 + Mapper，查出产品列表。
  新概念：`@Table` 实体 · `BaseMapper`
- **第 2C 章 统一返回格式 `Result<T>`**（25 分钟）
  所有接口都返回 `{ code, message, data }`，前端只按一种格式处理。
  新概念：统一返回包装
- **第 2D 章 全局异常处理：出错也返回 `Result`**（30 分钟）
  业务错误（「编号已存在」）和程序异常都变成统一格式，不再返回 Spring 默认错误页。
  新概念：`@RestControllerAdvice` · 自定义业务异常

**第 3 章 前后端连通**

- **第 3A 章 开发代理：前端连上 Spring Boot**（20 分钟）
  前端 5173 端口请求后端 8080 端口，用 Vite 代理绕开跨域。
  新概念：开发代理（精简教程 11B–11C 讲过原理，这里只讲 Spring Boot 的配置）
- **第 3B 章 axios 实例与环境变量**（25 分钟）
  建一个全项目共用的请求实例，接口前缀和超时时间放在一处。
  新概念：axios 实例
- **第 3C 章 响应拦截器：拆出 `data`，统一提示错误**（35 分钟）
  页面拿到的直接是数据；`code` 不是成功时统一弹出提示。
  新概念：拦截器
- **第 3D 章 接口类型与按模块拆分的 api 文件**（30 分钟）
  `Result<T>`、`PageResult<T>` 泛型类型；每个模块一个 `xxxApi.ts`，页面不直接写 URL。
  新概念：泛型接口类型 · api 模块

### 第二部分 后台布局与路由（4 个小章，约 1 小时 50 分）

**第 4 章 后台框架**

- **第 4A 章 后台框架：Layout + 侧边菜单**（30 分钟）
  左侧菜单、顶部栏、内容区，菜单可以折叠。
  新概念：`Layout` · `Menu`
- **第 4B 章 布局路由：菜单跟着地址高亮**（30 分钟）
  所有后台页面共用一个框架，换页只换内容区；刷新后菜单仍高亮当前页。
  新概念：布局路由 + `Outlet` · `useLocation`
- **第 4C 章 面包屑与浏览器标签页标题**（25 分钟）
  路由表里写好每页的标题，面包屑和标签页标题都从这里取。
  新概念：路由元信息
- **第 4D 章 路由懒加载与 404 页面**（25 分钟）
  页面多了以后首屏只加载当前页的代码；地址写错显示 404。
  新概念：`lazy` + `Suspense`

### 第三部分 列表页（10 个小章，约 5 小时）

**第 5 章 表格与分页**

- **第 5A 章 Table 与列定义的类型**（30 分钟）
  用 `columns` 描述每一列，`render` 自定义单元格。
  新概念：`Table` · `TableColumnsType<T>`
- **第 5B 章 useQuery：用 TanStack Query 加载表格数据**（35 分钟）
  加载中、出错、数据三种状态不用自己写 `useEffect` 和 state。
  新概念：`QueryClient` · `useQuery` · 查询键
- **第 5C 章 后端分页接口：MyBatis-Flex 的 `Page`**（30 分钟）
  `GET /api/products?pageNumber=1&pageSize=10` 返回当前页数据和总条数；SQL Server 的分页 SQL 长什么样。
  新概念：`paginate` 分页查询
- **第 5D 章 前端对接服务端分页**（30 分钟）
  表格翻页、改每页条数时重新请求，翻页时不闪空白。
  新概念：受控分页 · 查询键里带分页参数

**第 6 章 查询与行操作**

- **第 6A 章 查询表单：查询与重置**（30 分钟）
  表格上方的查询条件，点「查询」回到第 1 页，点「重置」清空。
  新概念：`Form` 的 `onFinish` · `form.resetFields`
- **第 6B 章 后端动态查询条件：`QueryWrapper`**（30 分钟）
  条件为空就不拼进 SQL；模糊查询、范围查询。
  新概念：`QueryWrapper` 条件构造
- **第 6C 章 查询条件放进地址栏：刷新、返回不丢**（30 分钟）
  从详情页返回列表时，查询条件和页码还在。
  新概念：`useSearchParams`
- **第 6D 章 服务端排序**（25 分钟）
  点列头排序，排序字段传给后端，后端只接受白名单字段防止 SQL 注入。
  新概念：`Table` 的 `onChange` · 排序字段白名单
- **第 6E 章 操作列与删除确认：useMutation 后刷新列表**（35 分钟）
  「编辑」「删除」按钮，删除前确认，删除后表格自动刷新。
  新概念：`useMutation` · `invalidateQueries` · `Popconfirm`
- **第 6F 章 勾选多行与批量删除**（25 分钟）
  勾选几行一次删除，翻页后勾选怎么处理。
  新概念：`rowSelection`

### 第四部分 表单（14 个小章，约 7 小时 5 分）

**第 7 章 表单基础**

- **第 7A 章 Form 与校验规则**（30 分钟）
  必填、长度、格式、自定义校验，错误提示显示在输入框下面。
  新概念：`Form.Item` 的 `name` 与 `rules` · `Form.useForm`
- **第 7B 章 常用输入控件与 dayjs 日期**（35 分钟）
  `InputNumber`、`Select`、`DatePicker`、`Switch`、`Radio`；日期在表单里是 dayjs 对象，提交前要转成字符串。
  新概念：dayjs 与日期转换
- **第 7C 章 新增页提交：保存中禁用、防止重复提交**（25 分钟）
  连点两次「保存」只发一次请求，成功后跳回列表。
  新概念：`isPending` 与按钮 `loading`
- **第 7D 章 后端参数校验：`@Valid`**（30 分钟）
  前端校验能绕过，后端必须再校验一次；校验失败统一返回字段错误列表。
  新概念：Bean Validation 注解 · `MethodArgumentNotValidException`
- **第 7E 章 后端字段错误显示到对应输入框**（25 分钟）
  「编号已存在」显示在编号输入框下面。
  新概念：`form.setFields`

**第 8 章 编辑与弹窗**

- **第 8A 章 编辑页：加载原数据回填表单**（30 分钟）
  按 Id 取数据，等数据回来再显示表单；日期字段回填时转回 dayjs。
  新概念：`initialValues` 与加载时机
- **第 8B 章 新增和编辑共用一个表单组件**（30 分钟）
  一个 `ProductForm` 组件，新增页和编辑页都用它。
  新概念：表单组件的 props 设计
- **第 8C 章 弹窗表单：在 Modal 里新增和编辑**（35 分钟）
  字段少的模块不跳页，直接在弹窗里编辑；关闭弹窗后表单要清空。
  新概念：`Modal` + `Form` · `destroyOnHidden`
- **第 8D 章 未保存就离开：提示用户**（25 分钟）
  表单改了没保存，点菜单离开时弹出确认。
  新概念：`useBlocker`

**第 9 章 复杂表单**

- **第 9A 章 下拉选项来自接口**（25 分钟）
  分类下拉框的选项从后端取，多个页面共用同一份缓存。
  新概念：选项接口 + 共享查询键
- **第 9B 章 远程搜索下拉框**（30 分钟）
  选项太多时边输入边查，输入停顿后再发请求。
  新概念：`showSearch` + 远程搜索 · 防抖
- **第 9C 章 字段联动：一个字段决定另一个字段**（30 分钟）
  选了「类型」才显示对应字段；数量 × 单价自动算金额。
  新概念：`Form.useWatch` · `dependencies`
- **第 9D 章 明细行：Form.List 动态增减**（40 分钟）
  单据下面的明细表格，可以加行、删行，每行单独校验，底部显示合计。
  新概念：`Form.List`
- **第 9E 章 后端保存主从表：`@Transactional`**（35 分钟）
  单据和明细一起保存，任何一步失败全部回滚。
  新概念：`@Transactional` · 批量插入

### 第五部分 常用功能（8 个小章，约 4 小时 5 分）

  新概念：`App` 组件与 `App.useApp`
- **第 10C 章 状态标签与金额、日期格式化**（25 分钟）
  状态码显示成彩色标签；金额千分位、日期格式写成公共函数。
  新概念：`Tag` · 格式化工具函数
- **第 10D 章 树形数据：后端组装树，前端 TreeSelect**（40 分钟）
  分类表存 `parentId`，后端组装成树返回；前端用树形下拉框选择。
  新概念：后端组装树 · `TreeSelect`

**第 11 章 文件**

- **第 11A 章 上传文件：Upload + `MultipartFile`**（35 分钟）
  上传附件，限制类型和大小，后端保存文件并返回地址。
  新概念：`Upload` · `MultipartFile` · 上传大小配置
- **第 11B 章 下载文件与图片预览**（30 分钟）
  需要登录才能下载的文件，用 axios 取 `blob` 再保存；图片点击放大。
  新概念：`blob` 下载 · `Content-Disposition`
- **第 11C 章 导出 Excel**（30 分钟）

  新概念：后端生成 Excel
- **第 11D 章 导入 Excel：返回出错的行**（35 分钟）
  上传 Excel，后端逐行校验，出错的行和原因返回给前端显示。
  新概念：后端读取 Excel · 逐行校验结果

### 第六部分 登录与权限（11 个小章，约 5 小时 25 分）

**第 12 章 后端认证**

- **第 12A 章 后端登录接口：签发 JWT**（40 分钟）
  用户名密码正确时返回 Token；Token 里放什么、不能放什么。
  新概念：JWT · Spring Security 过滤器链
- **第 12B 章 后端校验 Token：保护接口**（35 分钟）
  没带 Token 返回 401，没权限返回 403，都是 `Result` 格式。
  新概念：Token 校验过滤器 · 401 / 403 统一返回
- **第 12C 章 密码加密存储：BCrypt**（20 分钟）

  新概念：`PasswordEncoder`

**第 13 章 前端认证**

- **第 13A 章 登录页与保存 Token**（30 分钟）

  新概念：Token 存储方式
- **第 13B 章 请求带上 Token，401 跳回登录页**（30 分钟）

  新概念：请求拦截器 · 登录后跳回原地址
- **第 13C 章 路由守卫：没登录进不了后台页面**（25 分钟）

**第 14 章 权限**

## 有意不讲的内容

| 内容 | 为什么不讲 | 什么时候需要 |
| --- | --- | --- |
| Redux / Zustand 等状态库 | 服务端数据交给 TanStack Query，剩下的当前用户等少量全局状态用 Context 就够 | 很多不相邻组件频繁改同一份客户端数据时 |
| Ant Design Pro / ProComponents | 封装层次高，出问题时不懂底层组件就无从排查；先学会用基础组件写 | 基础组件熟练后想少写重复代码时 |
| 国际化（多语言） | 日常内部系统只用中文 | 系统要给海外用户使用时 |
| 单元测试与端到端测试 | 本教程目标是先把系统做出来 | 项目进入长期维护、多人协作时 |
| 微服务、Spring Cloud | 单体应用已能覆盖大多数内部系统 | 系统拆成多个独立部署的服务时 |
| Docker 部署 | 以 Windows Server 直接部署为主 | 用 Linux 服务器或容器平台时 |

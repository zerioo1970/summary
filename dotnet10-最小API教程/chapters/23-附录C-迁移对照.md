# 附录 C　从 Controller 迁移到最小 API 对照表

如果你有 MVC 控制器（Controller）经验，这份对照表帮你快速把已有认知迁移到最小 API。

## C.1 概念对照

| MVC 控制器 | 最小 API |
| --- | --- |
| `Controller` 类 | 无需类，直接 `app.MapXxx` |
| `[HttpGet]` / `[HttpPost]` 等特性 | `MapGet` / `MapPost` 等方法 |
| `[Route("api/[controller]")]` | `MapGroup("/api/xxx")` |
| Action 方法 | lambda 或命名方法（处理函数） |
| `[ApiController]` 自动模型校验 | `AddValidation()` + Data Annotations（.NET 10） |
| `IActionResult` / `ActionResult<T>` | `IResult` / `Results<...>` / `TypedResults` |
| `[FromBody]` / `[FromQuery]` 等 | 同名特性，且多数可省略 |
| 构造函数注入服务 | 处理函数参数注入服务 |
| `[Authorize]` | `.RequireAuthorization()` |
| 过滤器 `IActionFilter` | 端点过滤器 `AddEndpointFilter` |
| Swashbuckle/Swagger | 内置 OpenAPI（`AddOpenApi`/`MapOpenApi`） |

## C.2 代码对照：一个 GET

**MVC：**

```csharp
[ApiController]
[Route("api/[controller]")]
public class ProductsController : ControllerBase
{
    private readonly IProductService _svc;
    public ProductsController(IProductService svc) => _svc = svc;

    [HttpGet("{id:int}")]
    public ActionResult<Product> Get(int id)
    {
        var p = _svc.Find(id);
        return p is null ? NotFound() : Ok(p);
    }
}
```

**最小 API：**

```csharp
app.MapGet("/api/products/{id:int}",
    Results<Ok<Product>, NotFound> (int id, IProductService svc) =>
        svc.Find(id) is { } p ? TypedResults.Ok(p) : TypedResults.NotFound());
```

## C.3 代码对照：一个带校验的 POST

**MVC：**

```csharp
[HttpPost]
public IActionResult Create(CreateProductDto dto)
{
    if (!ModelState.IsValid) return ValidationProblem(ModelState);
    var p = _svc.Add(dto);
    return CreatedAtAction(nameof(Get), new { id = p.Id }, p);
}
```

**最小 API（.NET 10 校验自动生效）：**

```csharp
app.MapPost("/api/products", (CreateProductDto dto, IProductService svc) =>
{
    var p = svc.Add(dto);   // 校验失败已被框架拦截并返回 400
    return TypedResults.Created($"/api/products/{p.Id}", p);
});
```

## C.4 迁移建议

- **不必一次性全迁**：最小 API 和 Controller 可以**在同一个项目里共存**。可以新功能用最小 API，老功能逐步迁移。
- **先抽服务**：把 Controller 里的业务逻辑抽到服务类，端点/Action 都变薄，迁移时只是"换一层壳"。
- **善用分组**：用 `MapGroup` 复刻 `[Route]` 的前缀与共享特性（认证、过滤器）。
- **返回值优先 TypedResults**：语义清晰，且利于 OpenAPI 自动推断。

> **【提示】** 迁移不是目的，清晰和高效才是。若现有 MVC 项目运转良好、无强烈痛点，可只在新模块尝试最小 API，逐步积累经验。

# 附录 B　最小 API 常用速查表

把最常用的写法集中在这里，随查随用。

## B.1 路由映射

| 写法 | 说明 |
| --- | --- |
| `app.MapGet(path, handler)` | GET |
| `app.MapPost(path, handler)` | POST |
| `app.MapPut(path, handler)` | PUT |
| `app.MapDelete(path, handler)` | DELETE |
| `app.MapPatch(path, handler)` | PATCH |
| `app.MapMethods(path, ["GET","POST"], h)` | 多方法 |
| `app.MapGroup("/api")` | 路由分组 |

## B.2 路由参数与约束

```csharp
"/users/{id}"            // 参数
"/users/{id:int}"        // 整数
"/users/{id:guid}"       // GUID
"/files/{name:alpha}"    // 只字母
"/p/{age:int:min(18)}"   // 组合约束
"/blog/{*slug}"          // 捕获剩余全部路径
```

## B.3 参数绑定特性

| 特性 | 来源 |
| --- | --- |
| `[FromRoute]` | 路由 |
| `[FromQuery]` | 查询串 |
| `[FromBody]` | 请求体 JSON |
| `[FromHeader]` | 请求头 |
| `[FromForm]` | 表单 |
| `[FromServices]` | DI（.NET 10 常可省） |
| `[AsParameters]` | 聚合为一个对象 |

## B.4 返回结果（TypedResults）

| 方法 | 状态码 |
| --- | --- |
| `TypedResults.Ok(x)` | 200 |
| `TypedResults.Created(uri, x)` | 201 |
| `TypedResults.NoContent()` | 204 |
| `TypedResults.BadRequest(x)` | 400 |
| `TypedResults.Unauthorized()` | 401 |
| `TypedResults.Forbid()` | 403 |
| `TypedResults.NotFound()` | 404 |
| `TypedResults.Conflict(x)` | 409 |
| `TypedResults.Problem(...)` | 自定义 |
| `TypedResults.Json / Text / File / Bytes / Redirect` | 各类内容 |

多返回类型：`Results<Ok<T>, NotFound> (...)`

## B.5 依赖注入

```csharp
builder.Services.AddSingleton<IFoo, Foo>();  // 全程序一个
builder.Services.AddScoped<IFoo, Foo>();     // 每请求一个
builder.Services.AddTransient<IFoo, Foo>();  // 每次新建
builder.Services.Configure<Opt>(config.GetSection("Opt")); // 选项模式
```

## B.6 校验（.NET 10 内置）

```csharp
builder.Services.AddValidation();
// 模型属性上：
[Required] [StringLength(50)] [Range(0,100)]
[EmailAddress] [Url] [RegularExpression(...)] [Compare(...)]
```

## B.7 端点元数据与保护

```csharp
.WithName("X") .WithSummary("...") .WithDescription("...")
.WithTags("分组") .Produces<T>(200) .Produces(404)
.RequireAuthorization() .RequireAuthorization("策略名")
.RequireCors("策略") .RequireRateLimiting("策略")
.AddEndpointFilter(filter) .CacheOutput()
```

## B.8 常用服务注册一览

```csharp
builder.Services.AddOpenApi();          // OpenAPI 文档
builder.Services.AddCors(...);          // 跨域
builder.Services.AddAuthentication(...).AddJwtBearer(...);
builder.Services.AddAuthorization(...); // 授权
builder.Services.AddRateLimiter(...);   // 限流
builder.Services.AddHealthChecks();     // 健康检查
builder.Services.AddProblemDetails();   // 标准错误
builder.Services.AddDbContext<T>(...);  // EF Core
builder.Services.AddOutputCache();      // 输出缓存
```

## B.9 中间件顺序（推荐）

```csharp
app.UseExceptionHandler();

```

## B.10 EF Core 常用

```csharp
await db.Todos.ToListAsync();
await db.Todos.FindAsync(id);
await db.Todos.FirstOrDefaultAsync(x => x.Id == id);
db.Todos.Add(entity); await db.SaveChangesAsync();
db.Todos.Remove(entity); await db.SaveChangesAsync();
db.Todos.Where(...).OrderBy(...).Skip(n).Take(m);  // 过滤/排序/分页
```

## B.11 常用 CLI 命令

```bash
dotnet new web -n MyApi         # 创建最小 API 项目
dotnet run                      # 运行
dotnet watch                    # 热重载运行
dotnet add package <包名>       # 加 NuGet 包
dotnet ef migrations add <名>   # 新增迁移
dotnet ef database update       # 应用迁移
dotnet test                     # 运行测试
dotnet publish -c Release       # 发布
```

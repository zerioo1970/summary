# React 19 精简教程：日常开发够用的基本功

> 版本基线：`react 19.3.x` + `react-dom 19.3.x` ｜ `vite 8.3.x`（`react-ts` 模板，create-vite 9.3.3）｜ `typescript 7.0.x`（`strict` 开启，禁止 `any`）｜ `@types/react 19.3.x` ｜ `react-router 8.5.1`（第 9A 章起）｜ Node.js 24 LTS（≥ 22.22）｜ VS Code
> 第 15A–15C 章后端：.NET 10 SDK（实测 10.0.403）+ C# 14 + ASP.NET Core Minimal API ｜ Visual Studio 2026 或命令行 `dotnet`
> 版本于 2026-10-30 用 `npm create vite@latest -- --template react-ts` 实际生成项目核对；全部代码在 Node.js 24.22.2 上实测。
>
> 篇幅：全书 15 章拆成 48 个小章（第 3A、3B……这样编号），每个小章只讲一个技术点，约 20–35 分钟。讲清楚、全面、连贯优先，单章正文不受 400 行限制（规范 6.1）；每章新概念 ≤ 3 个。代码一律给完整文件，不用「见仓库」代替。
>
> 每章固定骨架：这一章解决什么问题 · 开始之前 · 正文（🖼 图解 → 💻 可运行代码 → 🔍 拆解结果 → 改坏一处试试）· ⚠️ 踩坑警告 · 🎯 动手练习 · 📌 一句话总结 · 下一章 · 参考答案

## 这本教程写给谁

- 有多年后端/业务系统开发经验，但现代前端是全新学习。
- 想用最短时间掌握 React 日常开发的基本方法：组件、数据、交互、表单、取数、路由、打包。
- 要的是「能跑起来的页面」，不是 React 概念大全。

全书用一个**产品价格清单**小应用贯穿：从一个静态页面开始，每章加一点功能，最后得到带列表、筛选、新增、详情页、数据加载的完整前端，并打包成可部署的静态文件。

第 1A–10C 章的数据来自项目里的 `public/products.json`（第 7C 章起从网络加载）；第 11A–14C 章换成项目自带的本地模拟接口（`mock-server/server.ts`，只用 Node.js 自带功能），不需要安装后端或数据库；第 15A–15C 章用 .NET 10 Minimal API 写真正的后端（数据放内存，仍不需要数据库）。

**最短路径**：第 1A–7D 章（23 个小章）≈ 9 小时 30 分，做出能加载数据、删除、入库、录入新产品的单页清单。
**完整路径**：48 个小章 ≈ 20 小时 50 分，按每天 2 小时约 11 天。小章短，被打断后容易接上。第 11A–14C 章学完，能做出连接接口、能增删改查、带登录的页面；第 15A–15C 章换成 ASP.NET Core Minimal API 后端，前后端合成一个网站。

## 有意不讲的内容

| 内容 | 为什么不讲 | 什么时候需要 |
| --- | --- | --- |
| Redux / Zustand 等状态库 | 日常页面用 state + 状态提升 + 自定义 Hook 就够 | 很多不相邻的组件要共享同一份数据、改动频繁时 |
| `useReducer` | 状态更新逻辑复杂时才需要，`useState` 已能覆盖日常页面 | 一个组件里有很多互相关联的 state、更新规则复杂时 |
| TanStack Query 等取数库 | 先弄懂 `useEffect` 取数的原理再用库 | 需要缓存、自动重试、分页加载时 |
| React 19 Actions / `use()` / Server Components | 依赖框架或新写法，单纯 Vite 项目日常用不到 | 使用 Next.js 等框架时 |
| Next.js | 是在 React 上加了一层框架，概念更多 | 需要服务端渲染、SEO 时 |
| 单元测试 | 本教程目标是先把页面做出来 | 项目进入长期维护时 |

## 目录结构

```
React19精简教程/
├── README.md
├── docs/                      # 每章一个 Markdown
└── code/
    └── chNNX/                 # 例如 ch03A、ch03B：每个小章一个文件夹
        ├── price-list/        # 本章结束时的完整项目（不含练习答案、不含 node_modules）
        ├── answers/           # 练习参考答案，目录结构与项目相同
        └── steps/             # 只有 ch04A 有：正文里「错误示范」那一版代码
        （第 15A–15C 章另有 PriceApi/：后端 Minimal API 项目，和 price-list 并排）
```

每章的 `price-list` 都能直接运行：进入该目录执行 `npm install`，再执行 `npm run dev`。正文里所有带文件路径注释的代码块，都和这里的文件逐字一致。

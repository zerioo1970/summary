> 版本基线：`react 19.3.x` + `react-dom 19.3.x` ｜ `vite 8.3.x`（`react-ts` 模板，create-vite 9.3.3）｜ `typescript 7.0.x`（`strict` 开启，禁止 `any`）｜ `@types/react 19.3.x` ｜ `react-router 8.5.1`（第 9 章起）｜ Node.js 24 LTS（≥ 22.22）｜ VS Code

## 这本教程写给谁

- 有多年后端/业务系统开发经验，但现代前端是全新学习。
- 想用最短时间掌握 React 日常开发的基本方法：组件、数据、交互、表单、取数、路由、打包。
- 要的是「能跑起来的页面」，不是 React 概念大全。

全书用一个**产品价格清单**小应用贯穿：从一个静态页面开始，每章加一点功能，最后得到带列表、筛选、新增、详情页、数据加载的完整前端，并打包成可部署的静态文件。

数据来自项目 `public/products.json` 静态文件，**不需要启动任何后端**。

**最短路径**：第 1–7 章 ≈ 6 小时，做出能加载数据、删除、入库、录入新产品的单页清单。
**完整路径**：10 章 ≈ 8 小时，按每天 2 小时约 4–5 天。

## 目录

### 第一部分 把页面搭起来（3 章，约 2 小时 15 分）

**[第 1 章 环境搭建与第一个页面](docs/ch01-setup.md)**（45 分钟）
从零装好 Node.js 和 VS Code，用 Vite 建项目，在浏览器里看到自己改的页面。
新概念：Vite 开发服务器 · 入口文件 `main.tsx` → `App.tsx` · 热更新

**[第 2 章 组件与 JSX](docs/ch02-components-jsx.md)**（45 分钟）
把一大段页面拆成可复用的小块，分到不同文件里。
新概念：函数组件 · JSX 规则 · `import` / `export` 拆分文件

**[第 3 章 Props：给组件传数据](docs/ch03-props.md)**（45 分钟）
同一个产品卡片组件，显示不同的产品。
新概念：props · 用 `type` 声明 props 类型 · `children`

### 第二部分 让页面能交互（3 章，约 2 小时 30 分）

**[第 4 章 State：让页面动起来](docs/ch04-state.md)**（50 分钟）
数量点一下就要变，但直接改变量页面没反应——本章解决这个。
新概念：`useState` · 事件处理及其类型 · 重新渲染的原理

**[第 5 章 列表与条件渲染](docs/ch05-list-condition.md)**（50 分钟）
用一个数组渲染整张清单，能入库、能删除，缺货自动标红，删光了显示「暂无产品」。
新概念：`map` + `key` · 条件渲染 · 数组的不可变更新

**[第 6 章 表单](docs/ch06-forms.md)**（50 分钟）
录入新产品，名称为空、价格不是数字时给出提示。
新概念：受控输入框 · 表单提交（`SubmitEvent`；`@types/react` 19.3 已把旧的 `FormEvent` 标为弃用）· 派生值（校验结果从 state 计算，不另存）

### 第三部分 数据、复用与多页面（3 章，约 2 小时 40 分）

**[第 7 章 从接口加载数据](docs/ch07-fetch.md)**（60 分钟）
页面打开时自动从 `public/products.json` 取数据，并显示「加载中」「出错了」。
新概念：`useEffect` · 依赖数组 · 加载中 / 出错 / 成功三种状态的判别联合

**[第 8 章 组件之间共享数据与自定义 Hook](docs/ch08-lift-state-hook.md)**（50 分钟）
表单录入的产品加进表格；搜索框和表格在两个组件里，要联动；取数逻辑抽出来复用。
新概念：回调 props（子组件通知父组件）· 状态提升 · 自定义 Hook（把第 7 章的取数逻辑抽成 `useProducts`）

**[第 9 章 路由：多个页面](docs/ch09-router.md)**（50 分钟）
从列表点进产品详情页，地址栏跟着变，刷新后仍停在详情页。
新概念：React Router 路由表 · `Link` · URL 参数

### 第四部分 交付（1 章，约 40 分钟）

**[第 10 章 样式与打包发布](docs/ch10-style-build.md)**（40 分钟）
让页面不再难看，并打包成能交给 Web 服务器部署的静态文件。
新概念：CSS Modules · `npm run build` · `dist` 目录与部署注意事项（刷新 404、子路径 `base`）

## 有意不讲的内容

| 内容 | 为什么不讲 | 什么时候需要 |
| --- | --- | --- |
| Redux / Zustand 等状态库 | 日常页面用 state + 状态提升 + 自定义 Hook 就够 | 很多不相邻的组件要共享同一份数据、改动频繁时 |
| `useContext` / `useReducer` | 入门阶段容易和 state 混淆 | 层级很深的组件要拿同一份数据（如登录用户、主题）时 |
| TanStack Query 等取数库 | 先弄懂 `useEffect` 取数的原理再用库 | 需要缓存、自动重试、分页加载时 |
| React 19 Actions / `use()` / Server Components | 依赖框架或新写法，单纯 Vite 项目日常用不到 | 使用 Next.js 等框架时 |
| Next.js | 是在 React 上加了一层框架，概念更多 | 需要服务端渲染、SEO 时 |
| 单元测试 | 本教程目标是先把页面做出来 | 项目进入长期维护时 |

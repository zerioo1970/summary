# 084 scp：在本机和服务器之间复制文件

> 级别：初级 · 软件包：`openssh-client`

## 1. 作用

`scp`（secure copy）通过 ssh 连接复制文件：从本机传到服务器，或者从服务器下载到本机。它走 ssh 的认证方式（密码或密钥），ssh 能登录的服务器，scp 就能传文件。

## 2. 基本格式

```bash
scp [参数] 本机文件 用户@主机:远程路径     # 上传
scp [参数] 用户@主机:远程文件 本机路径     # 下载
```

远程路径都写在冒号 `:` 后面。冒号后面不写路径，表示远程用户的家目录。

## 3. 常用参数

| 参数 | 作用 |
|---|---|
| `-r` | 复制目录 |
| `-P 端口` | 指定端口（注意是**大写** P，ssh 用的是小写 p） |
| `-i 私钥` | 指定私钥 |
| `-p` | 保留修改时间和权限（小写 p） |
| `-C` | 传输时压缩，适合网络慢、文件是文本的情况 |

## 4. 常用示例

演示用的 sshd 在本机 2222 端口。

### 4.1 上传文件

```
$ scp -P 2222 readme.txt tom@127.0.0.1:/tmp/

$ ssh -p 2222 tom@127.0.0.1 ls -l /tmp/readme.txt
-rw-r--r-- 1 tom tom 6 Oct 29 07:09 /tmp/readme.txt
```

在真实终端里，scp 会显示文件名、进度百分比、速度。

### 4.2 `-r`：上传目录

```
$ scp -P 2222 -r logs tom@127.0.0.1:/tmp/

$ ssh -p 2222 tom@127.0.0.1 ls -R /tmp/logs
/tmp/logs:
app.log
```

### 4.3 从服务器下载

```
$ scp -P 2222 tom@127.0.0.1:/etc/hostname dl/

$ ls dl
hostname
```

### 4.4 配合 `~/.ssh/config` 的简称

```
$ scp readme.txt db01:/tmp/r2.txt && echo copied
copied
```

config 里写好了地址、端口、用户名（见 [ssh](083-ssh.md) 4.4），scp 命令就短多了。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `scp -p 2222 ...` 连接的还是 22 端口 | scp 的端口参数是大写 `-P`，小写 `-p` 是“保留时间” | 改成 `-P 2222` |
| `scp: dest open "/root/readme.txt": Permission denied` | 远程用户对目标目录没有写权限 | 先传到 `/tmp` 或家目录，再 ssh 上去 `sudo mv` |
| 忘了写冒号，文件被复制成了本机上一个叫 `tom@127.0.0.1` 的文件 | 没有冒号时 scp 把它当成本地文件名 | 远程地址一定带 `:` |
| 传几 GB 的文件中途断了，只能从头再来 | scp 不支持断点续传 | 大文件改用 `rsync -avP`（中级篇讲） |

第二条的实测：

```
$ scp -P 2222 readme.txt tom@127.0.0.1:/root/
scp: dest open "/root/readme.txt": Permission denied
scp: failed to upload file readme.txt to /root/
```

## 6. 一句话总结

上传 `scp 文件 用户@主机:路径`，目录加 `-r`，端口用大写 `-P`，大文件换 rsync。

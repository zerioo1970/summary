# 071 groups：查看用户属于哪些组

> 级别：初级 · 软件包：`rust-coreutils`（系统自带）

## 1. 作用

`groups` 列出用户所属的组名。它是 `id -Gn` 的简写，只输出组名，更简洁。

Linux 用组来批量授权：把用户加进 `sudo` 组就能用 sudo，加进 `docker` 组就能直接用 docker 命令，加进 `www-data` 组就能读写网站目录。

## 2. 基本格式

```bash
groups [用户名...]
```

## 3. 常用示例

```
$ groups
tom sudo

$ groups root
root : root
```

带用户名时，输出格式是“用户名 : 组名...”。

Ubuntu 安装时创建的第一个用户，在桌面版上通常属于这些组：

| 组 | 作用 |
|---|---|
| `sudo` | 可以使用 sudo |
| `adm` | 可以读取 /var/log 下的系统日志 |
| `lpadmin` | 可以管理打印机 |

把用户加入组用 `sudo usermod -aG 组名 用户名`（中级篇讲 usermod）。

> ⚠️ 上表“通常属于这些组”未实机验证：测试环境是手工建的用户，只加了 sudo 组。

## 4. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 加组后 `groups` 还是旧的 | 当前登录会话读的是登录时的组信息 | 重新登录；或用 `groups 用户名` 查看最新配置 |

## 5. 一句话总结

`groups` 看自己在哪些组里，加组之后要重新登录。

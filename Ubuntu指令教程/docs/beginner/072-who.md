# 072 who：查看谁登录了系统

> 级别：初级 · 软件包：`rust-coreutils`（系统自带）

## 1. 作用

`who` 列出当前登录在这台机器上的用户：用户名、终端、登录时间、从哪个 IP 登录。准备重启服务器前，先看看还有没有别人在用。

## 2. 基本格式

```bash
who [参数]
```

## 3. 常用参数

| 参数 | 作用 |
|---|---|
| `-b` | 上次开机的时间 |
| `-q` | 只显示用户名和人数 |
| `-H` | 显示列标题 |
| `am i` | 只显示当前这个终端的登录信息（`who am i`） |

## 4. 常用示例

```bash
who
who -H
who -b
```

典型的输出格式：

```
tom      pts/0        2026-10-29 08:12 (192.168.1.50)
zhang    pts/1        2026-10-29 09:03 (192.168.1.61)
```

| 列 | 含义 |
|---|---|
| 第 1 列 | 用户名 |
| 第 2 列 | 终端：`pts/N` 是 ssh 或图形界面里的终端窗口，`tty1` 是本机控制台 |
| 第 3 列 | 登录时间 |
| 括号里 | 来源 IP |

> ⚠️ 上面的输出是格式示意，未实机验证：测试环境不是通过登录进入的，`who` 没有任何输出。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 用 `sudo -i` 切到 root 后，who 显示的还是原来的用户名 | who 显示的是登录时的身份 | 这是正常的；查当前身份用 `whoami` |
| 在容器里执行 who 没有任何输出 | 容器里没有登录记录 | 这是正常的 |

## 6. 一句话总结

重启前先 `who` 看有没有人在线；想看每个人在做什么用 `w`。

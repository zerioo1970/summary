# 025 df：查看磁盘空间

> 级别：初级 · 软件包：`gnu-coreutils`（Ubuntu 26.04 的 df 仍由 GNU 版提供）

## 1. 作用

`df`（disk free）显示每个已挂载的文件系统总共多大、用了多少、还剩多少。程序报 `No space left on device`，或者服务器监控报警“磁盘使用率 90%”时，先用 df 看是哪个分区满了。

df 看的是整个分区；要知道分区里**哪个目录**占得多，用 [du](026-du.md)。

## 2. 基本格式

```bash
df [参数] [目录或设备...]
```

指定目录时，只显示该目录所在的分区。

## 3. 常用参数

| 参数 | 长格式 | 作用 |
|---|---|---|
| `-h` | `--human-readable` | 用 K、M、G 显示大小 |
| `-T` | `--print-type` | 显示文件系统类型（ext4、xfs、tmpfs 等） |
| `-i` | `--inodes` | 显示 inode（文件个数）的使用情况 |
| `-x 类型` | `--exclude-type` | 不显示某类文件系统，如 `-x tmpfs` |

## 4. 常用示例

> 以下输出来自测试环境，设备名和容量与真实服务器不同。在普通 Ubuntu 机器上，根目录一般显示为 `/dev/sda2`、`/dev/nvme0n1p2` 或 `/dev/mapper/ubuntu--vg-ubuntu--lv`，类型为 ext4。

### 4.1 `df -h`：看全部分区

```
$ df -h
Filesystem      Size  Used Avail Use% Mounted on
/dev/loop1       87G  1.3G   86G   2% /
tmpfs            16G     0   16G   0% /dev
tmpfs            64M     0   64M   0% /dev/tty
tmpfs            16G     0   16G   0% /run
tmpfs            16G  2.5M   16G   1% /home
tmpfs            16G     0   16G   0% /tmp
```

| 列 | 含义 |
|---|---|
| Filesystem | 设备或文件系统名 |
| Size / Used / Avail | 总大小 / 已用 / 可用 |
| Use% | 使用率，超过 90% 就该清理了 |
| Mounted on | 挂载点，也就是它对应哪个目录 |

`tmpfs` 是内存里的临时文件系统，重启后内容会清空，一般不用关心。

### 4.2 只看某个目录所在的分区

```
$ df -h /home
Filesystem      Size  Used Avail Use% Mounted on
tmpfs            16G  2.5M   16G   1% /home
```

不确定 `/var/lib/mysql` 在哪个分区，就 `df -h /var/lib/mysql`。

### 4.3 `-T`：显示文件系统类型

```
$ df -hT /home
Filesystem     Type   Size  Used Avail Use% Mounted on
tmpfs          tmpfs   16G  2.5M   16G   1% /home
```

### 4.4 `-i`：空间够但还是写不进去

```
$ df -i /home
Filesystem      Inodes IUsed   IFree IUse% Mounted on
tmpfs          4039707    15 4039692    1% /home
```

每个文件占用一个 inode。如果程序产生了几百万个小文件（比如没清理的会话文件），inode 会先用完，这时 `df -h` 还显示有空间，写文件却报 `No space left on device`。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 删了一个大日志，df 显示的可用空间没变 | 文件还被某个进程打开着，空间要等进程关闭文件才释放 | `sudo lsof +L1` 找出占用的进程并重启它；清空日志用 `: > 文件` 而不是删除 |
| `df -h` 有空间，仍然 `No space left on device` | inode 用完了 | `df -i` 确认，找出并清理大量小文件 |
| df 的 Used + Avail 小于 Size | ext4 默认给 root 保留 5% 空间，防止磁盘写满后系统无法维护 | 这是正常现象 |

## 6. 一句话总结

磁盘满了先 `df -h` 定位分区，再用 `du` 找大目录；写不进去还要看 `df -i`。

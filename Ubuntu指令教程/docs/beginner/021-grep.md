# 021 grep：按关键词搜索文本

> 级别：初级 · 软件包：`grep`（GNU 版）

## 1. 作用

`grep` 在文件里逐行查找包含某个关键词的行，把匹配的行打印出来。查日志里的报错、在一堆配置文件里找某个参数、从命令输出里过滤出想看的那几行，都用 grep。

关键词可以是普通文字，也可以是正则表达式（regular expression，用特殊符号描述“一类文字”的写法，比如 `[0-9]+` 表示一串数字）。

## 2. 基本格式

```bash
grep [参数] 关键词 [文件...]
命令 | grep [参数] 关键词
```

## 3. 常用参数

| 参数 | 长格式 | 作用 |
|---|---|---|
| `-i` | `--ignore-case` | 忽略大小写 |
| `-n` | `--line-number` | 显示行号 |
| `-v` | `--invert-match` | 反向：显示**不**包含关键词的行 |
| `-c` | `--count` | 只显示匹配的行数 |
| `-r` | `--recursive` | 递归搜索目录下的所有文件 |
| `-l` | `--files-with-matches` | 只列出包含关键词的文件名 |
| `-w` | `--word-regexp` | 整词匹配 |
| `-E` | `--extended-regexp` | 使用扩展正则，可以写 `A\|B` 这种“或” |
| `-o` | `--only-matching` | 只输出匹配到的部分，不输出整行 |
| `-A 数字` | `--after-context` | 同时显示匹配行之后的 N 行 |
| `-B 数字` | `--before-context` | 同时显示匹配行之前的 N 行 |
| `-C 数字` | `--context` | 同时显示前后各 N 行 |

## 4. 常用示例

演示用的日志 `logs/app.log` 共 8 行，见 [目录页](../../README.md#演示环境)。

### 4.1 找出所有错误

```
$ grep ERROR logs/app.log
2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
2026-10-28 11:30:40 ERROR 连接数据库失败
```

### 4.2 `-i`：忽略大小写

```
$ grep -i error logs/app.log
2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
2026-10-28 11:30:40 ERROR 连接数据库失败
```

不加 `-i` 时，`grep error` 找不到任何行，因为日志里写的是大写的 ERROR。

### 4.3 `-n` 和 `-c`：行号和数量

```
$ grep -n ERROR logs/app.log
4:2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
7:2026-10-28 11:30:40 ERROR 连接数据库失败

$ grep -c ERROR logs/app.log
2
```

### 4.4 `-v`：排除干扰

```
$ grep -v INFO logs/app.log
2026-10-28 09:15:22 WARN  价格表缓存过期，重新加载
2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
2026-10-28 11:30:40 ERROR 连接数据库失败
```

去掉所有 INFO，剩下的就是需要关注的。查看配置文件时，`grep -v "^#" 文件` 可以去掉注释行。

### 4.5 `-E`：同时找多个关键词

```
$ grep -E "WARN|ERROR" logs/app.log
2026-10-28 09:15:22 WARN  价格表缓存过期，重新加载
2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
2026-10-28 11:30:40 ERROR 连接数据库失败
```

### 4.6 `-A`、`-B`、`-C`：看出错前后发生了什么

```
$ grep -A 1 "保存失败" logs/app.log
2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
2026-10-28 10:02:14 INFO  重试订单 A1002

$ grep -B 1 -n "连接数据库失败" logs/app.log
6-2026-10-28 10:02:15 INFO  订单 A1002 保存成功
7:2026-10-28 11:30:40 ERROR 连接数据库失败
```

带 `-n` 时，匹配行的行号后面是冒号 `:`，上下文行后面是减号 `-`。

### 4.7 `-r` 和 `-l`：在整个目录里找

```
$ grep -r "A1002" .
./logs/app.log:2026-10-28 10:02:13 ERROR 订单 A1002 保存失败：超时
./logs/app.log:2026-10-28 10:02:14 INFO  重试订单 A1002
./logs/app.log:2026-10-28 10:02:15 INFO  订单 A1002 保存成功

$ grep -rl ERROR .
./logs/app.log
```

想知道“哪个配置文件里设置了端口 8080”，用 `grep -rn 8080 /etc/nginx/`。

### 4.8 `-w`：整词匹配

```
$ grep -w 探头A src/products.csv
U001,探头A,探头,12000
U005,探头A,探头,12000
```

不加 `-w` 时，搜 `探头` 还会匹配到“探头B”。

### 4.9 `-o`：只取出匹配的内容

```
$ grep -o "A[0-9]\+" logs/app.log
A1002
A1002
A1002
```

`A[0-9]\+` 表示“A 后面跟一个或多个数字”。从日志里提取订单号、IP 地址时常用。

### 4.10 过滤其他命令的输出

```bash
ps aux | grep nginx
history | grep ssh
```

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `grep error` 什么都没找到 | grep 默认区分大小写 | 加 `-i` |
| `grep: logs: Is a directory` | 对目录搜索要加 `-r` | `grep -r ERROR logs` |
| 关键词里有空格，报 `No such file or directory` | 空格后面的部分被当成了文件名 | 关键词加引号：`grep "订单 A1002" 文件` |
| 搜 `1.5` 却匹配到了 `125` | `.` 在正则里表示“任意一个字符” | 按普通文字搜索用 `-F`：`grep -F "1.5" 文件` |
| `ps aux \| grep nginx` 结果里总有一行 `grep nginx` 自己 | grep 进程本身也在 ps 列表里 | 写成 `grep "[n]ginx"`，或改用 `pgrep -a nginx` |
| 脚本里判断“没找到”时出错退出 | 没有匹配时 grep 的退出码是 1，`set -e` 的脚本会因此中止 | 写成 `grep xxx 文件 \|\| true` |

没有匹配时的退出码：

```
$ grep error logs/app.log; echo "退出码=$?"
退出码=1
```

## 6. 一句话总结

`grep -rni 关键词 目录` 能解决大部分查找；看上下文加 `-C`，排除用 `-v`。

# 088 watch：定时重复执行一条命令

> 级别：初级 · 软件包：`procps`

## 1. 作用

`watch` 每隔一段时间（默认 2 秒）执行一次指定的命令，并全屏显示最新的结果。想盯着某个数字变化时用它：磁盘空间在不在涨、文件有没有传完、某个进程还在不在。

## 2. 基本格式

```bash
watch [参数] 命令
```

按 `Ctrl+C` 退出。

## 3. 常用参数

| 参数 | 长格式 | 作用 |
|---|---|---|
| `-n 秒` | `--interval` | 刷新间隔 |
| `-d` | `--differences` | 高亮显示和上一次相比变化的部分 |
| `-t` | `--no-title` | 不显示顶部的标题行 |
| `-g` | `--chgexit` | 输出发生变化时自动退出 |

## 4. 常用示例

### 4.1 每秒刷新一次

```bash
watch -n 1 date
```

屏幕顶部显示标题行，下面是命令的输出，每秒更新：

```
Every 1.0s: date                                   ubuntu: Thu Oct 29 07:08:42 2026

Thu Oct 29 07:08:42 UTC 2026
```

标题行依次是：刷新间隔和命令、主机名、当前时间。

### 4.2 盯着上传进度

```bash
watch -n 2 -d "ls -l /data/upload/"
```

`-d` 会把变化的数字（文件大小）高亮显示。

### 4.3 盯着磁盘和内存

```bash
watch -n 5 "df -h / && free -h"
```

命令里有管道、`&&` 这类符号时，整条命令要加引号。

### 4.4 等到变化时退出

```bash
watch -g "ls /data/done.flag" && echo "处理完成"
```

> ⚠️ 本页只验证了 4.1：watch 是全屏程序，测试环境只截取到了第一屏的标题和内容。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `watch ls \| grep log` 结果不对 | 管道被当前 Shell 先处理了，watch 只拿到了 `ls` | 整条命令加引号：`watch "ls \| grep log"` |
| 别名在 watch 里用不了 | watch 用 `sh -c` 执行命令，不认识 bash 的别名 | 写完整命令，如 `watch "ls -alF"` |

## 6. 一句话总结

`watch -n 秒 -d "命令"` 定时刷新并高亮变化，`Ctrl+C` 退出。

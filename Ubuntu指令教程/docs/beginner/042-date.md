# 042 date：显示和计算日期时间

> 级别：初级 · 软件包：`rust-coreutils`（系统自带）

## 1. 作用

`date` 显示当前的日期和时间，也能按指定格式输出、计算“昨天”“7 天后”这样的日期。在脚本里，它最常见的用途是给备份文件、日志文件名加上日期。

修改系统时区和时间，用的是 `timedatectl`（中级篇讲），不建议用 date 直接改时间。

## 2. 基本格式

```bash
date [参数] [+格式]
```

## 3. 常用参数和格式符

| 参数 | 作用 |
|---|---|
| `+格式` | 按格式输出，格式符见下表 |
| `-d "描述"` | 显示指定时间，而不是现在，如 `-d yesterday` |
| `-u` | 显示 UTC 时间 |

| 格式符 | 含义 | 示例 |
|---|---|---|
| `%Y` `%m` `%d` | 年、月、日 | 2026、10、29 |
| `%H` `%M` `%S` | 时、分、秒 | 06、56、11 |
| `%F` | 等同 `%Y-%m-%d` | 2026-10-29 |
| `%T` | 等同 `%H:%M:%S` | 06:56:11 |
| `%A` | 星期几（英文） | Thursday |
| `%s` | Unix 时间戳（1970-01-01 以来的秒数） | 1793256971 |

## 4. 常用示例

### 4.1 当前时间

```
$ date
Thu Oct 29 06:56:11 UTC 2026
```

系统语言是中文时，月份和星期会显示成中文。

### 4.2 自定义格式

```
$ date "+%Y-%m-%d %H:%M:%S"
2026-10-29 06:56:11

$ date +%F
2026-10-29

$ date "+%Y%m%d"
20261029
```

格式里有空格时，整个格式要加引号。

### 4.3 `-d`：计算日期

```
$ date -d "yesterday" +%F
2026-10-28

$ date -d "+7 days" +%F
2026-11-05

$ date -d "last monday" +%F
2026-10-26

$ date -d "2026-10-01" +%A
Thursday
```

“导出昨天的订单”这类脚本，就用 `date -d yesterday +%F` 算出日期，再拼进 SQL 或文件名。

### 4.4 时间戳和日期互转

```
$ date +%s
1793256971

$ date -d @1793257200
Thu Oct 29 07:00:00 UTC 2026
```

日志、数据库里存的数字时间戳，用 `date -d @时间戳` 翻译成人能看懂的时间。

### 4.5 临时按其他时区显示

```
$ TZ=Asia/Shanghai date
Thu Oct 29 14:56:11 CST 2026

$ date -u
Thu Oct 29 06:56:11 UTC 2026
```

### 4.6 给备份文件加日期

```
$ tar -czf backup-$(date +%Y%m%d).tar.gz logs; ls backup-*
backup-20261029.tar.gz
```

`$(命令)` 会被替换成命令的输出。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 服务器时间比北京时间慢 8 小时 | 系统时区是 UTC（云服务器、容器常见） | `sudo timedatectl set-timezone Asia/Shanghai` |
| 文件名用了 `$(date)`，结果名字里有空格和冒号，处理起来很麻烦 | date 的默认格式带空格和冒号 | 文件名用 `+%Y%m%d` 或 `+%Y%m%d_%H%M%S` |
| crontab 里写 `date +%Y%m%d` 不生效 | crontab 里的 `%` 有特殊含义 | 在 crontab 里写成 `\%`，或把命令放进脚本里 |

## 6. 一句话总结

`date +%F` 取日期，`-d yesterday` 算日期，文件名用 `+%Y%m%d` 格式。

# 048 sort：排序

> 级别：初级 · 软件包：`rust-coreutils`（系统自带）

## 1. 作用

`sort` 把文本按行排序后输出，可以按数字、按指定列、正序或倒序。它不修改原文件。和 [uniq](049-uniq.md)、[cut](079-cut.md)、[head](019-head.md) 组合起来，在命令行里就能做简单的统计报表。

## 2. 基本格式

```bash
sort [参数] [文件...]
```

## 3. 常用参数

| 参数 | 长格式 | 作用 |
|---|---|---|
| `-n` | `--numeric-sort` | 按数值大小排序 |
| `-r` | `--reverse` | 倒序 |
| `-h` | `--human-numeric-sort` | 按带单位的大小排序（2K、1M、3G） |
| `-u` | `--unique` | 去掉重复行 |
| `-t 字符` | `--field-separator` | 指定列分隔符，如 `-t,` |
| `-k 列` | `--key` | 按第几列排序，如 `-k4`；`-k4,4` 表示只用第 4 列 |
| `-o 文件` | `--output` | 结果写入文件，可以写回原文件 |

## 4. 常用示例

演示文件 n.txt 有 4 行：300、25、1000、25。

### 4.1 默认排序和 `-n`

```
$ sort n.txt
1000
25
25
300

$ sort -n n.txt
25
25
300
1000
```

不加 `-n`，sort 按字符逐个比较，`"1000"` 的第一个字符 `1` 比 `"25"` 的 `2` 小，所以排在前面。数字一定要加 `-n`。

### 4.2 `-nr`：从大到小

```
$ sort -nr n.txt
1000
300
25
25
```

### 4.3 `-u`：排序并去重

```
$ sort -u n.txt
1000
25
300
```

### 4.4 `-t -k`：按 CSV 的某一列排序

按第 4 列（价格）从高到低，`tail -n +2` 先去掉表头：

```
$ tail -n +2 src/products.csv | sort -t, -k4 -nr
U003,主机X,主机,280000
U002,探头B,探头,15000
U005,探头A,探头,12000
U001,探头A,探头,12000
U004,凝胶,耗材,35
```

先按第 3 列（分类）排，同一分类里再按价格倒序：

```
$ tail -n +2 src/products.csv | sort -t, -k3,3 -k4,4nr
U003,主机X,主机,280000
U002,探头B,探头,15000
U001,探头A,探头,12000
U005,探头A,探头,12000
U004,凝胶,耗材,35
```

相当于 SQL 的 `ORDER BY category, price DESC`。

### 4.5 `-h`：按文件大小排序

```
$ du -sh * | sort -h
0       link.txt
4.0K    logs
4.0K    n.txt
4.0K    readme.txt
4.0K    run.sh
4.0K    src
2.4M    big.iso
```

### 4.6 `-o`：写回原文件

```
$ sort n.txt -o n.txt
```

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| 1000 排在了 25 前面 | 没加 `-n`，按字符排序 | 加 `-n` |
| `sort n.txt > n.txt` 之后文件变空了 | Shell 先清空 n.txt，sort 读到的是空文件 | 用 `sort n.txt -o n.txt` |
| `-k4` 排序结果和预期不一致 | `-k4` 表示“从第 4 列一直到行尾”作为排序依据 | 只按某一列排写成 `-k4,4` |
| 表头也被排进了数据中间 | sort 不知道哪行是表头 | 先 `tail -n +2` 去掉表头 |
| 中文排序不是按拼音 | sort 按字符编码排序 | 命令行里无法按拼音排，需要在程序或数据库里处理 |

## 6. 一句话总结

数字排序加 `-n`，倒序加 `-r`，CSV 用 `-t, -kN,N`，写回原文件用 `-o`。

# 073 w：查看谁在线、在做什么

> 级别：初级 · 软件包：`procps`

## 1. 作用

`w` 是 `uptime` 和 `who` 的合体，再加上每个用户当前正在运行的命令。第一行是系统时间、运行时长和负载，下面每行一个登录会话。

## 2. 基本格式

```bash
w [参数] [用户名]
```

## 3. 常用参数

| 参数 | 作用 |
|---|---|
| `-h` | 不显示标题行 |
| `-s` | 简短格式，不显示登录时间和 CPU 时间 |
| `用户名` | 只看某个用户 |

## 4. 常用示例

测试环境没有登录会话，所以只有标题：

```
$ w
 07:03:58 up  1:29,  0 users,  load average: 0.61, 0.57, 0.55
USER     TTY      FROM             LOGIN@   IDLE   JCPU   PCPU  WHAT
```

在有人登录的服务器上，标题下面每行一个会话，例如：

```
tom      pts/0    192.168.1.50     08:12    0.00s  0.05s  0.00s w
zhang    pts/1    192.168.1.61     09:03    12:30  0.10s  0.08s vim /etc/nginx/nginx.conf
```

> ⚠️ 上面两行会话是格式示意，未实机验证。

| 列 | 含义 |
|---|---|
| FROM | 从哪个 IP 登录 |
| LOGIN@ | 登录时间 |
| IDLE | 多久没有操作了 |
| WHAT | 正在运行的命令 |

看到同事正在 `vim /etc/nginx/nginx.conf`，这时重启 nginx 或者也去改同一个文件，就要先打个招呼。

## 5. 一句话总结

`w` 一眼看清系统负载、谁在线、每人在做什么。

# 096 lsusb：列出 USB 设备

> 级别：初级 · 软件包：`usbutils`

## 1. 作用

`lsusb` 列出连接在电脑上的所有 USB 设备：U 盘、键盘鼠标、USB 网卡、打印机、加密狗、扫码枪等。插了一个设备没反应时，先用 lsusb 看系统有没有识别到它。

## 2. 基本格式

```bash
lsusb [参数]
```

## 3. 常用参数

| 参数 | 作用 |
|---|---|
| `-t` | 树形显示设备接在哪个 USB 控制器、哪个端口上，以及速率 |
| `-v` | 显示详细信息（加 sudo 才能看全） |
| `-d 厂商ID:产品ID` | 只显示指定的设备 |

## 4. 常用示例

```bash
lsusb
lsusb -t
```

每行的格式：

```
Bus 001 Device 003: ID 0781:5581 SanDisk Corp. Ultra
```

| 内容 | 含义 |
|---|---|
| `Bus 001 Device 003` | 在第 1 条 USB 总线上，设备编号 3 |
| `ID 0781:5581` | 厂商 ID : 产品 ID，查驱动时用 |
| 后面的文字 | 厂商和产品名称 |

> ⚠️ 本页未实机验证：测试环境是云服务器，没有 USB 设备，lsusb 报 `unable to initialize usb spec`。上面的输出行为格式示意。

## 5. 排查思路

| lsusb 的结果 | 说明 |
|---|---|
| 插拔前后列表没有变化 | 系统没识别到：换个接口、换根线，或设备本身坏了 |
| 列表里有，但设备用不了 | 识别到了，缺驱动或权限：用 `sudo dmesg -T \| tail` 看内核日志 |

## 6. 一句话总结

插了 USB 设备没反应，先 `lsusb` 看有没有识别，再看 `dmesg`。

# 012 apt：安装、升级、卸载软件

> 级别：初级 · 软件包：`apt`（Ubuntu 26.04 自带 3.2 版）

## 1. 作用

`apt` 是 Ubuntu 的软件包管理工具。它从 Ubuntu 官方软件源下载软件，自动处理依赖关系（装 A 需要先装 B、C，apt 会一起装好）。装软件、打补丁、卸载软件，都用 apt。

软件源的地址写在 `/etc/apt/sources.list.d/ubuntu.sources` 里。apt 本地保存了一份“软件源里有哪些包、什么版本”的清单，`apt update` 就是刷新这份清单。

## 2. 基本格式

```bash
sudo apt 子命令 [包名...]
```

除了 `search`、`show`、`list` 这类只读查询，其他子命令都要加 sudo。

## 3. 常用子命令

| 子命令 | 作用 |
|---|---|
| `update` | 刷新软件包清单（不安装任何东西） |
| `upgrade` | 把已安装的软件升级到最新版本 |
| `install 包名` | 安装软件 |
| `remove 包名` | 卸载软件，保留配置文件 |
| `purge 包名` | 卸载软件，连配置文件一起删除 |
| `autoremove` | 删除当初作为依赖装进来、现在已经没用的包 |
| `search 关键词` | 搜索软件包 |
| `show 包名` | 查看包的详细信息 |
| `list --installed` | 列出已安装的包 |
| `list --upgradable` | 列出可以升级的包 |

常用参数：

| 参数 | 作用 |
|---|---|
| `-y` | 自动回答“是”，不再询问 |
| `--names-only` | 和 search 一起用，只在包名里搜索 |
| `-s` | 模拟执行，只显示会做什么，不真的执行 |

## 4. 常用示例

> 以下输出在 Ubuntu 26.04.1 实测，软件包版本号和数量会随软件源更新而变化。

### 4.1 `apt update`：刷新清单

```
$ sudo apt update
Hit:1 http://security.ubuntu.com/ubuntu resolute-security InRelease
Hit:2 http://archive.ubuntu.com/ubuntu resolute InRelease
Hit:3 http://archive.ubuntu.com/ubuntu resolute-updates InRelease
Hit:4 http://archive.ubuntu.com/ubuntu resolute-backports InRelease
Reading package lists...
Building dependency tree...
Reading state information...
20 packages can be upgraded. Run 'apt list --upgradable' to see them.
```

`resolute` 是 Ubuntu 26.04 的代号（Resolute Raccoon）。装软件、升级之前，先执行一次 update。

### 4.2 `apt list --upgradable`：看哪些可以升级

```
$ apt list --upgradable
Listing...
gnu-coreutils/resolute-updates,resolute-security 9.7-3ubuntu2.1 amd64 [upgradable from: 9.7-3ubuntu2]
gpgv/resolute-updates,resolute-security 2.4.8-4ubuntu3.1 amd64 [upgradable from: 2.4.8-4ubuntu3]
...（共 20 行，此处只列前两行）
```

### 4.3 `apt install`：安装软件

```
$ sudo apt install cowsay
Solving dependencies...
Upgrading:
  perl-base

Installing:
  cowsay

Installing dependencies:
  libgdbm-compat4t64  libtext-charwidth-perl  perl-modules-5.40
  libperl5.40         perl

Suggested packages:
  filters     libterm-readline-gnu-perl     libtap-harness-archive-perl
  cowsay-off  | libterm-readline-perl-perl
  perl-doc    make

Summary:
  Upgrading: 1, Installing: 6, Removing: 0, Not Upgrading: 19
  Download size: 10.2 MB
  Space needed: 51.5 MB / 91.9 GB available

Continue? [Y/n]
```

apt 3.x 的输出按“升级 / 安装 / 依赖 / 建议”分块显示，最后的 Summary 告诉你一共改动多少包、要下载多少。按回车（默认 Y）开始安装。加 `-y` 就不会停下来询问。

软件已经装过时：

```
$ sudo apt install tree
tree is already the newest version (2.3.1-1).
Solving dependencies...
Summary:
  Upgrading: 0, Installing: 0, Removing: 0, Not Upgrading: 20
```

### 4.4 `apt search` 和 `apt show`：先查再装

```
$ apt search --names-only "^htop"
Sorting...
Full Text Search...
htop/resolute,now 3.4.1-5build2 amd64 [installed]
  interactive processes viewer

$ apt show tree
Package: tree
Version: 2.3.1-1
Priority: optional
Section: universe/utils
Origin: Ubuntu
...
```

不加 `--names-only` 时，apt 会在包的描述里搜索，结果往往有几百条。

### 4.5 `remove`、`purge`、`autoremove`：卸载

```
$ sudo apt remove cowsay
Solving dependencies...
The following package was automatically installed and is no longer required:
  libtext-charwidth-perl
Use 'apt autoremove' to remove it.

REMOVING:
  cowsay

Summary:
  Upgrading: 0, Installing: 0, Removing: 1, Not Upgrading: 19
  Freed space: 89.1 kB

$ sudo apt autoremove
REMOVING:
  libtext-charwidth-perl

Summary:
  Upgrading: 0, Installing: 0, Removing: 1, Not Upgrading: 19
  Freed space: 43.0 kB
```

remove 只删程序，`/etc` 下的配置文件还在，重装后配置不丢。要彻底清除用 `sudo apt purge 包名`。

### 4.6 日常打补丁

```bash
sudo apt update && sudo apt upgrade
```

`&&` 表示前一条成功了才执行后一条。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| `Error: Unable to locate package xxx` | 包名写错，或者还没执行过 `apt update` | 先 `sudo apt update`，再用 `apt search` 查准包名 |
| 在脚本里用 apt，输出多了一行 `WARNING: apt does not have a stable CLI interface. Use with caution in scripts.` | apt 的输出格式面向人，可能随版本变化 | 脚本里改用 [apt-get](063-apt-get.md)，例如 `sudo apt-get install -y 包名` |
| 报 `Could not get lock /var/lib/dpkg/lock-frontend` | 另一个 apt 进程（常见的是开机后的自动更新）正在运行 | 等几分钟再试。不要删除锁文件 |
| 卸载后重装，软件还是用旧配置 | `remove` 保留了配置文件 | 想恢复默认配置，用 `purge` 卸载后再装 |
| `Error: Unable to acquire the dpkg frontend lock (/var/lib/dpkg/lock-frontend), are you root?` | 安装、卸载需要管理员权限，普通用户打不开锁文件 | 加 `sudo` |

## 6. 一句话总结

先 `update` 再 `install`；`remove` 留配置、`purge` 全删；脚本里用 `apt-get`。

# 026 du：查看目录和文件占用的空间

> 级别：初级 · 软件包：`rust-coreutils`（系统自带）

## 1. 作用

`du`（disk usage）统计目录或文件实际占用了多少磁盘空间。`df` 告诉你哪个分区满了，`du` 帮你找到是哪个目录把它占满的。

## 2. 基本格式

```bash
du [参数] [目录或文件...]
```

不加参数时，du 会列出每一个子目录的大小，输出很长。日常基本都配合 `-sh` 使用。

## 3. 常用参数

| 参数 | 长格式 | 作用 |
|---|---|---|
| `-h` | `--human-readable` | 用 K、M、G 显示 |
| `-s` | `--summarize` | 每个参数只显示一个总数 |
| `-a` | `--all` | 文件也列出来（默认只列目录） |
| `-d N` | `--max-depth=N` | 只统计到第 N 层子目录 |
| `-c` | `--total` | 最后加一行总计 |

## 4. 常用示例

### 4.1 `-sh`：看一个目录总共多大

```
$ du -sh .
2.5M	.
```

### 4.2 `du -sh *`：当前目录下谁最大

```
$ du -sh *
2.4M	big.iso
0	link.txt
4.0K	logs
4.0K	readme.txt
4.0K	run.sh
4.0K	src
```

readme.txt 只有 6 字节，du 却显示 4.0K，因为磁盘按 4K 一块分配空间，du 统计的是实际占用的块。

### 4.3 包括隐藏文件

```
$ du -sh .[!.]* *
4.0K	.env
2.4M	big.iso
0	link.txt
4.0K	logs
4.0K	readme.txt
4.0K	run.sh
4.0K	src
```

`*` 不匹配以 `.` 开头的名字，`.[!.]*` 专门匹配隐藏文件。家目录里的 `.cache`、`.local` 经常占几个 GB，不加这个就看不到。

### 4.4 `--max-depth=1`：只看一层

```
$ du -h --max-depth=1
4.0K	./src
4.0K	./logs
2.5M	.
```

### 4.5 排序：找出最大的几项

```
$ du -ah | sort -rh | head -3
2.5M	.
2.4M	./big.iso
4.0K	./src/products.csv
```

`sort -rh` 按带单位的大小倒序排列。服务器磁盘满了，常用这一条：

```bash
sudo du -h --max-depth=1 /var | sort -rh | head
```

先找到 /var 下最大的子目录，再进去重复同样的步骤，一层层缩小范围。

## 5. ⚠️ 踩坑警告

| 现象 | 原因 | 怎么改 |
|---|---|---|
| du 统计的总数比 df 显示的已用空间小很多 | 已删除但仍被进程占用的文件，du 看不到 | 见 [df](025-df.md) 踩坑表第一条 |
| 统计 `/` 时刷出大量 `Permission denied` | 普通用户读不了某些目录 | 加 `sudo`，或在命令末尾加 `2>/dev/null` |
| 统计根目录时，把挂载的网络盘也算进去，非常慢 | du 默认会进入其他文件系统 | 加 `-x`，只统计同一个文件系统 |
| `du -sh *` 漏掉了 `.cache` 等大目录 | `*` 不匹配隐藏文件 | 用 4.3 的写法 |

## 6. 一句话总结

`du -sh *` 看谁最大，`du -h --max-depth=1 | sort -rh` 一层层找出占空间的目录。

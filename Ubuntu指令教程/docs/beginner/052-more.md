# 052 more：简单的分页查看

> 级别：初级 · 软件包：`util-linux`

## 1. 作用

`more` 一屏一屏地显示文件，按空格翻到下一页。它比 [less](018-less.md) 早出现，功能少：主要只能往下翻，看到末尾会自动退出。

现在基本都用 less。了解 more 是因为一些老脚本和文档里还会出现它，而且极简的系统里可能只有 more。

## 2. 基本格式

```bash
more [参数] 文件
命令 | more
```

## 3. 常用参数和按键

| 写法 | 作用 |
|---|---|
| `more +行号 文件` | 从指定行开始显示 |
| `more +/关键词 文件` | 从第一次出现关键词的位置开始显示 |
| `-s` | 连续空行压缩成一行 |

| 按键 | 作用 |
|---|---|
| `空格` | 下一页 |
| `回车` | 下一行 |
| `b` | 上一页（只对文件有效，对管道输入无效） |
| `/关键词` | 搜索 |
| `q` | 退出 |

> ⚠️ 本页未实机验证：more 是交互程序，测试环境只确认了版本（`more from util-linux 2.41.3`）。按键为 more 长期稳定的默认行为。

## 4. 常用示例

```bash
more /etc/services
more +/ssh /etc/services
ps aux | more
```

## 5. more 和 less 怎么选

| | more | less |
|---|---|---|
| 往回翻 | 有限 | 随意 |
| 读到末尾 | 自动退出 | 停在末尾，按 q 才退出 |
| 跟踪实时日志 | 不支持 | `F` 键 |

结论：有 less 就用 less。

## 6. 一句话总结

more 只适合往下翻着看，日常用 less。

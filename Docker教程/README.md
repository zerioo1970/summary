# Ubuntu 26.04 Docker 入门教程

> 版本基线：Ubuntu 26.04 LTS｜Docker Engine（Docker 官方 apt 仓库，第 2 章安装时写明实测版本号）＋ Docker Compose 插件
> 示例用到的镜像：MySQL 8.4、SQL Server 2022、.NET 10（ASP.NET Core Minimal API）、Spring Boot 3.5（Gradle）、nginx
>
> 每章固定结构：这一章解决什么问题 · 开始之前 · 正文（🖼 图解 → 💻 动手 → 🔍 看结果 → 改坏试试）· 🧱 类比 · ⚠️ 踩坑警告 · 🎯 动手练习 · 📌 一句话总结 · 下一章 · 参考答案

## 这本教程写给谁

- 会用 Ubuntu 终端敲命令，但**完全没接触过 Docker**。
- 想在 Ubuntu 上用容器跑数据库、发布自己写的程序（.NET 或 Spring Boot）和前端页面，并且能自己维护。
- 要的是“能跑起来、出了问题会查”，不是 Docker 的全部功能。

**最短路径**：第 1–8 章，再加第 11、13、18、21 章，共 12 章，约 15 小时。学完能用容器跑数据库、把程序打包成镜像、用 Compose 一次启动、出问题会自动重启。
**完整路径**：26 章 + 2 个附录，每天 2 小时约 3 周。

## 目录

### 第一部分　认识 Docker 并装好（3 章）

**[第 1 章 容器是什么：和虚拟机、直接安装软件有什么区别](docs/ch01-what-is-container.md)**
不装 Docker，只用 Ubuntu 自带的 `unshare` 命令，亲手做出一个“容器”，看清它和虚拟机的差别。

**第 2 章 在 Ubuntu 26.04 上安装 Docker Engine**
从 Docker 官方 apt 仓库安装，运行 `hello-world`，把自己加进 docker 用户组，以后不用每次都输 sudo。

**第 3 章 镜像拉不下来怎么办：镜像加速和代理设置**
国内访问 Docker Hub 经常失败，这一章配置镜像加速地址和代理，并验证配置是否生效。

### 第二部分　容器的基本操作（7 章）

**第 4 章 运行第一个容器：启动、查看、停止、删除**
前台运行和后台运行的区别，给容器起名字，容器停止后去哪了。

**第 5 章 管理镜像：下载、标签、删除**
镜像标签（tag）是什么，为什么不要用 `latest`，怎么删掉不用的镜像。

**第 6 章 端口映射：让浏览器访问容器里的网站**
用 `-p` 把容器里的 80 端口映射到你机器上，浏览器打开 nginx 默认页。

**第 7 章 进入容器、查看日志**
用 `docker exec` 进到运行中的容器里查问题，用 `docker logs` 看程序输出。

**第 8 章 数据卷：删掉容器，数据还在**
数据卷（volume）和目录挂载（bind mount）的区别，数据库文件为什么必须放在外面。

**第 9 章 环境变量：不改镜像就能改配置**
用 `-e` 和 `--env-file` 给容器传数据库密码、连接串。

**第 10 章 容器之间怎么互相访问**
建一个自定义网络，让程序容器用容器名访问数据库容器。

### 第三部分　用容器跑数据库（2 章）

**第 11 章 用容器跑 MySQL 8.4**
启动 MySQL、用初始化脚本建库建表、数据存到数据卷里。

**第 12 章 用容器跑 SQL Server 2022，并从 Windows 用 SSMS 连接**
SQL Server 容器的内存要求和 SA 密码规则，从另一台 Windows 电脑连进来。

### 第四部分　把自己的程序打包成镜像（3 章）

**第 13 章 Dockerfile 入门：把一个静态页面做成镜像**
写第一个 Dockerfile，用 `docker build` 做出自己的镜像。

**第 14 章 打包 .NET 10 Minimal API**
多阶段构建：在一个镜像里编译，只把编译结果放进最终镜像。

**第 15 章 打包 Spring Boot 3.5（Gradle）**
利用构建缓存加快重复打包，用 `.dockerignore` 排除不需要的文件。

### 第五部分　用 nginx 发布前端（2 章）

**第 16 章 用 nginx 发布前端页面**
把 React 构建出来的文件交给 nginx 容器发布，并写 nginx 配置文件。

**第 17 章 前端和后端用同一个地址：nginx 转发 /api**
用反向代理把 `/api` 开头的请求转给后端容器，浏览器不再有跨域问题。

### 第六部分　Docker Compose（3 章）

**第 18 章 Compose 入门：用一个文件启动服务**
把一长串 `docker run` 参数写进 `compose.yaml`，用 `docker compose up/down` 启停。

**第 19 章 程序 + 数据库一起启动**
用 `depends_on` 和健康检查，保证数据库准备好了程序才启动。

**第 20 章 综合实战：nginx + 后端 + SQL Server 一次启动**
不引入新概念，把前面学过的组合成一套完整系统。

### 第七部分　日常维护（6 章）

**第 21 章 自动重启和开机自启**
重启策略（restart）：程序崩了自动拉起来，服务器重启后容器自动启动。

**第 22 章 日志太大怎么办：限制日志大小**
容器日志默认不限大小，这一章给日志设上限。

**第 23 章 备份和恢复数据卷**
用一个临时容器把数据卷打包成文件，再恢复到新数据卷。

**第 24 章 磁盘满了：查看和清理**
用 `docker system df` 看空间用在哪，用 `prune` 安全地清理。

**第 25 章 升级镜像版本而不丢数据**
固定版本号，按步骤升级数据库和程序镜像。

**第 26 章 端口安全：为什么防火墙（UFW）挡不住 Docker 端口**
Docker 发布的端口会绕过 UFW 规则；只给本机用的端口要绑定到 127.0.0.1。

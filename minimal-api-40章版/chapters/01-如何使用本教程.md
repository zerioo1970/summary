# 如何使用本教程

本教程按"先看懂、再跑通、再逐层扩展"的顺序编写。第1～14章建立Minimal API基础；第15～23章进入日志、中间件、验证、错误、REST、数据库、DTO与项目拆分；第24～33章讲解认证授权、安全、文件与实时响应、缓存、后台任务、外部服务、性能、可观测性和测试；第34～40章完成质量、发布、Docker、CI/CD和TaskHub综合实战。

建议不要只阅读代码。每章都建立一个可运行状态：完成一节就启动应用、发出请求、观察状态码和日志。能解释请求为什么成功或失败，比机械记忆 API 更重要。

-   初学者：按章节顺序学习；每完成一个步骤就运行项目，并核对书中写明的预期结果。

-   有 C# 基础者：第1～2章可快速浏览，从第3章开始实际编码。

-   已有 ASP.NET MVC 经验者：重点阅读第6章OpenAPI与Swagger、第8章前后端交互，以及第9---14章中Minimal API特有的端点写法。

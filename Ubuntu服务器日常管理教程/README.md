# Ubuntu 服务器日常管理教程

> **版本基线**（2026-11）
>
> | 项 | 版本 |
> |---|---|
> | 服务器系统 | Ubuntu Server 26.04.1 LTS（只装命令行，不装桌面） |
> | 你的电脑 | Windows 10 / 11，命令在 **PowerShell** 里执行；使用 Windows 自带的 OpenSSH 客户端（`ssh`、`scp`、`ssh-keygen`） |
> | 用到的系统组件 | 26.04 默认的 `sudo-rs`（sudo）、`chrony`（时间同步）、`netplan`（网络配置）、`ufw`（防火墙）、`systemd`（服务、日志、定时器）；其他软件的具体版本在对应章节写作时核实 |

## 这本教程写给谁

- 你手上有（或马上要有）一台 Ubuntu 服务器，上面要跑网站，平时由你来管。
- 你会用 Windows Server，但没怎么用过 Linux 命令行。
- 你要的是日常要做的那些事**具体怎么操作**：装好后先配什么、加用户、装软件、管服务、看日志、磁盘满了怎么办、怎么备份、出了故障按什么顺序查。

每章的写法：

- 按"要办的一件事"组织，先用几句话说明为什么要做，然后是**编号的操作步骤**。
- 每一步写明在哪里执行：
  - `PS C:\Users\zhang>`：你自己的 Windows 电脑，PowerShell 窗口；
  - `ubuntu@web01:~$`：已经用 ssh 登录的服务器。
- 每条命令写清楚每个参数的作用，后面给出**实际运行的输出**，再告诉你看到什么算做对了。
- 文中服务器地址统一写成 `192.168.1.50`，用户名写成 `ubuntu`，主机名写成 `web01`，你的 Windows 用户名写成 `zhang`。照做时换成你自己的。

## 目录

### 第一部分 安装和登录

| 章 | 一句话说明 |
|---|---|
| 第 1 章 安装 Ubuntu Server 26.04 | 在虚拟机或物理机上安装；安装向导每一屏怎么选：语言、网络、磁盘（LVM）、用户、OpenSSH |
| 第 2 章 装好后先做的几件事 | 第一次 ssh 登录，更新系统，改主机名，设时区，检查时间同步（`timedatectl`、`chronyc`） |
| 第 3 章 用密钥登录，关掉密码登录 | `ssh-keygen` 生成密钥，把公钥放到服务器，确认密钥能登录后再关闭密码登录；用 `~/.ssh/config` 简化登录命令 |
| 第 4 章 在服务器上找文件、看文件、改配置 | `/etc`、`/var`、`/home`、`/srv` 各放什么；`cd`、`ls`、`less`、`grep`、`find`；用 `nano` 改配置文件，改之前先备份 |

### 第二部分 用户、权限和软件

| 章 | 一句话说明 |
|---|---|
| 第 5 章 用户和组 | `adduser` 加用户，`usermod -aG` 加入组，改密码，锁定和删除离职人员的账号 |
| 第 6 章 sudo：给别人管理权限 | 加入 `sudo` 组；在 `/etc/sudoers.d/` 里只授权部分命令；用 `visudo -c` 检查，避免写错后谁都用不了 sudo |
| 第 7 章 文件权限和网站目录规划 | 看懂 `rwx` 和属主；`chmod`、`chown`；规划 `/srv/www`，让部署用户能写、网站进程只能读 |
| 第 8 章 用 apt 安装、升级、卸载软件 | `update`、`upgrade`、`install`、`remove`、`purge`、`autoremove`；查软件版本和来源；换国内镜像源；添加第三方软件源 |
| 第 9 章 自动安全更新和重启 | `unattended-upgrades` 自动装安全补丁；怎么知道需要重启；安排重启时间 |

### 第三部分 服务和定时任务

| 章 | 一句话说明 |
|---|---|
| 第 10 章 用 systemctl 管理服务 | 启动、停止、重启、重新加载、开机自启；服务起不来时用 `status` 和日志找原因 |
| 第 11 章 把自己的程序做成系统服务 | 写 `.service` 文件：运行用户、工作目录、环境变量、崩溃后自动重启；改完后 `daemon-reload` |
| 第 12 章 定时任务 | `crontab` 和 systemd 定时器（timer）各写一个每天凌晨执行的任务；任务的输出和失败记录去哪看 |

### 第四部分 网络和安全

| 章 | 一句话说明 |
|---|---|
| 第 13 章 配置固定 IP 和 DNS | 用 `ip` 看网卡和地址；改 netplan 配置文件设固定 IP；用 `netplan try` 防止改错后连不上；`resolvectl` 查 DNS |
| 第 14 章 端口和网络连接排查 | `ss -tlnp` 看谁在监听哪个端口；`ping`、`curl`、`nc`、`tracepath`；"服务起来了但外面访问不到"的排查顺序 |
| 第 15 章 用 ufw 配置防火墙 | 先放行 SSH 再开启防火墙；放行 80/443；只允许指定 IP 访问某个端口；查看和删除规则；云服务器安全组和 ufw 的关系 |
| 第 16 章 用 fail2ban 挡住暴力破解 | 安装后保护 SSH；查看被封的 IP；手动解封；把自己的 IP 加入白名单 |

### 第五部分 磁盘和文件

| 章 | 一句话说明 |
|---|---|
| 第 17 章 磁盘空间满了怎么办 | `df`、`du` 找到占空间的目录；清理日志、apt 缓存、旧内核；文件删了空间却没释放（`lsof` 查被占用的已删除文件） |
| 第 18 章 加一块数据盘、扩容 | `lsblk` 认盘，分区、格式化、按 UUID 写进 `/etc/fstab` 开机自动挂载；安装时 LVM 没用满的空间怎么扩出来 |
| 第 19 章 传文件、同步目录、打包压缩 | `scp` 和 `rsync` 在 Windows 与服务器、服务器与服务器之间传文件；`rsync` 只传变化的部分；`tar` 打包压缩和解压 |

### 第六部分 日志和监控

| 章 | 一句话说明 |
|---|---|
| 第 20 章 看系统日志 | `journalctl` 按服务、时间、级别筛选，实时跟踪；`/var/log` 下的文件；`logrotate` 和日志占用空间的上限 |
| 第 21 章 服务器变慢了：看 CPU、内存、负载 | `uptime`、`top`、`free`、`vmstat`、`iostat` 怎么看；找出占资源的进程；`kill` 结束进程 |
| 第 22 章 健康检查脚本和告警 | 写一个 Shell 脚本检查磁盘、内存、服务状态和网站能否打开，用定时器每 5 分钟执行，出问题用 `curl` 调消息接口发告警 |

### 第七部分 备份和故障处理

| 章 | 一句话说明 |
|---|---|
| 第 23 章 备份和恢复 | 要备份哪些东西；用 `tar` 和 `rsync` 每天备份到另一台机器，只保留最近 N 天；实际恢复一次，确认备份能用 |
| 第 24 章 常见故障处理 | ssh 连不上、sudo 配置写坏、`fstab` 写错开不了机、磁盘变成只读、忘记密码、服务反复重启；每种故障的排查和恢复步骤 |
| 第 25 章 综合实战：一台新服务器从安装到上线 | 按前面各章从零配置一台服务器，部署一个静态网站，最后按上线检查清单逐项核对 |

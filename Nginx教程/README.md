# Nginx 新手实用教程

> **版本基线**（2026-11 实测）
>
> | 项 | 版本 |
> |---|---|
> | 服务器系统 | Ubuntu Server 26.04.1 LTS |
> | nginx | 1.28.3（Ubuntu 26.04 软件源自带，软件包版本 `1.28.3-2ubuntu1.14`） |
> | 后端示例（第 7 章起） | .NET 10 + C# 14 + ASP.NET Core Minimal API（具体补丁版本在第 7 章写作时核实） |
> | 你的电脑 | Windows 10 / 11，命令都在 **PowerShell** 里执行；使用 Windows 自带的 OpenSSH 客户端（`ssh`、`scp`、`ssh-keygen`）和 `curl.exe` |

## 这本教程写给谁

- 你做了很多年 Windows + IIS 上的网站，现在要把网站放到 **Ubuntu 服务器**上，前面用 nginx 接待访问。
- 你没怎么用过 Linux 命令行，也没配过 nginx。
- 你要的是"照着做就能上线"，同时知道每一步为什么这样做、出了错怎么查。

每章的写法：

- 先用几句话讲清原理，然后是**编号的操作步骤**。每一步写明在哪里执行：
  - `PS C:\Users\zhang>`：你自己的 Windows 电脑，PowerShell 窗口；
  - `ubuntu@web01:~$`：已经用 ssh 登录的服务器。
- 每条命令后面给出**实际运行的输出**，再告诉你看到什么算做对了。
- 文中服务器地址统一写成 `192.168.1.50`，用户名写成 `ubuntu`，主机名写成 `web01`；你的 Windows 用户名写成 `zhang`。照做时换成你自己的。

## 关于实测

- nginx、`curl`、`ssh`、`scp`、`ufw` 的输出，都是在 Ubuntu 26.04.1 官方根文件系统里实际运行得到的，方法见 [`tools/README.md`](tools/README.md)。
- 测试环境不能做的事情在正文里标了 `⚠️ 未实机验证`，主要有：
  - `systemctl` 的输出（测试环境没有以 systemd 启动）；
  - `sudo` 的密码提示（测试环境不能提权，命令以 root 直接执行，输出与加 `sudo` 时相同）；
  - Windows 上的界面和路径显示（`ssh`、`scp`、`curl.exe` 用的是 Linux 版同名程序，输出内容相同，Windows 上的路径写法按 Windows 改写）。
- 真实 Ubuntu Server 登录时的欢迎信息比文中多几行（系统负载、内存、可更新的软件包数量），这是正常的。

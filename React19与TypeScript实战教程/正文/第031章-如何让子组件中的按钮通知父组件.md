# 第 31 章：如何让子组件中的按钮通知父组件？

前置：[第 30 章：如何切换标签页显示的内容？](第030章-如何切换标签页显示的内容.md)

## 一、本章要解决的问题

`FaqPage` 越来越长：标签、问题列表、投票、客服都写在一个组件里。每个问题的显示部分结构完整、会在列表中重复出现，按第 11 章的方法，应该提取成一个组件 `FaqItem`。

但提取时遇到一个问题：“展开”按钮在 `FaqItem` 里面，而记住“哪个问题展开了”的 `openId` 必须留在 `FaqPage` 中，因为只有它知道所有问题，才能做到“同时只展开一个”。子组件中的按钮被点击了，怎样告诉父组件？

本章把问题提取成 `FaqItem` 组件，父组件通过 props 把“是否展开”和“点击后该做什么”交给它。完成后，页面的外观和行为与第 30 章完全相同，但每个问题由 `FaqItem` 负责显示。

## 二、必要原理

### 数据向下传，事件向上报

第 9 章学过，父组件通过 props 把数据传给子组件。子组件不能直接修改父组件的 state，那么它怎样让父组件知道“我被点击了”？

答案是：父组件把一个**函数**也通过 props 传给子组件。子组件在按钮被点击时调用这个函数，函数里的代码是父组件写的，可以修改父组件的 state。

```tsx
// 父组件
<FaqItem faq={faq} isOpen={faq.id === openId} onToggle={() => handleToggle(faq.id)} />

// 子组件
<button type="button" onClick={onToggle}>
```

点击子组件的按钮时，调用的 `onToggle` 正是父组件传进来的 `() => handleToggle(faq.id)`，于是父组件的 `openId` 被修改，父组件重新渲染，把新的 `isOpen` 传给每个 `FaqItem`。

整个过程中：

- 数据（`faq`、`isOpen`）从父组件**向下**传给子组件；
- 事件（“我被点击了”）通过函数从子组件**向上**通知父组件；
- state 只保存在父组件中一处。

### 函数类型的 props

函数也需要类型。`onToggle` 不接收参数、不返回值，类型写作：

```ts
onToggle: () => void;
```

`() => void` 表示“一个没有参数、没有返回值的函数”。`void` 就是“不返回任何东西”。

传给子组件的事件函数，名字习惯以 `on` 开头，例如 `onToggle`、`onSelect`，与 `onClick` 的风格一致；父组件中处理它的函数以 `handle` 开头。

### 子组件不知道 openId

`FaqItem` 只知道两件事：自己是否展开（`isOpen`），被点击时调用 `onToggle`。它不知道其他问题，也不知道 `openId` 的存在。这样 `FaqItem` 很简单，以后也可以用在“允许同时展开多个”的页面中，只要父组件换一种方式提供 `isOpen` 和 `onToggle`。

## 三、动手实现

### 第 1 步：把问题的样式移到组件中

在 `src/components` 中新建 `FaqItem.module.css`，把 `FaqPage.module.css` 中的 `.item`、`.question`、`.answer` 三段规则剪切过来：

```css
.item {
  padding: 12px 0;
  border-bottom: 1px solid #d9e2ec;
}

.question {
  margin: 0 0 8px;
  font-size: 18px;
}

.answer {
  margin: 8px 0 0;
  color: #52606d;
}
```

### 第 2 步：新建 FaqItem 组件

在 `src/components` 中新建 `FaqItem.tsx`：

```tsx
import type { Faq } from '../data/faqs';
import styles from './FaqItem.module.css';

type FaqItemProps = {
  faq: Faq;
  isOpen: boolean;
  onToggle: () => void;
};

export default function FaqItem({ faq, isOpen, onToggle }: FaqItemProps) {
  return (
    <li className={styles.item}>
      <h2 className={styles.question}>{faq.question}</h2>
      <button type="button" aria-expanded={isOpen} onClick={onToggle}>
        {isOpen ? '收起' : '展开'}
      </button>
      {isOpen && <p className={styles.answer}>{faq.answer}</p>}
    </li>
  );
}
```

内容与 `FaqPage` 中 `map` 返回的 `li` 相同，有两处变化：`isOpen` 改为从 props 获得；按钮直接调用 `onToggle`。

### 第 3 步：在 FaqPage 中使用 FaqItem

打开 `src/pages/FaqPage.tsx`，导入组件：

```tsx
import FaqItem from '../components/FaqItem';
```

把问题列表改为：

```tsx
      <ul className={styles.list}>
        {faqs.map((faq) => (
          <FaqItem
            key={faq.id}
            faq={faq}
            isOpen={faq.id === openId}
            onToggle={() => handleToggle(faq.id)}
          />
        ))}
      </ul>
```

`map` 中只剩下返回组件，又回到了第 17 章圆括号的写法。`key` 写在 `map` 直接返回的 `FaqItem` 上（第 18 章）。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 点击“展开”没有任何反应 | 子组件中写成了 `onClick={() => onToggle}`，箭头函数只是读取了函数，没有调用它 | 写成 `onClick={onToggle}` 或 `onClick={() => onToggle()}` |
| 想在 `FaqItem` 中调用 `setOpenId`，提示找不到 | state 和 set 函数属于 `FaqPage`，子组件拿不到 | 通过 `onToggle` 通知父组件 |
| 在 `FaqItem` 中自己写了 `useState` 记住是否展开，结果可以同时展开多个 | 每个 `FaqItem` 各有一份 state，彼此不知道 | 展开状态由父组件统一管理，通过 `isOpen` 传入 |
| 问题的边框和字号消失了 | 样式移到了 `FaqItem.module.css`，但组件中没有导入 | `import styles from './FaqItem.module.css';` |
| 控制台警告缺少 `key` | `key` 写在了 `FaqItem` 内部的 `li` 上 | `key` 写在 `map` 中的 `<FaqItem key={faq.id} ... />` 上 |

### `src/pages/FaqPage.tsx`

```tsx
import { useState } from 'react';
import FaqItem from '../components/FaqItem';
import { faqs, faqTabs } from '../data/faqs';
import type { FaqCategory } from '../data/faqs';
import styles from './FaqPage.module.css';

export default function FaqPage() {
  const [helpfulCount, setHelpfulCount] = useState(0);
  const [openId, setOpenId] = useState<number | null>(null);
  const [activeTab, setActiveTab] = useState<FaqCategory>('account');

  function handleToggle(id: number) {
    setOpenId(openId === id ? null : id);
  }

  function addHelpful() {
    setHelpfulCount((current) => current + 1);
  }

  function handleHelpfulClick() {
    addHelpful();
  }

  function handleVeryHelpfulClick() {
    addHelpful();
    addHelpful();
  }

  function handleContactClick() {
    window.alert('客服邮箱：help@example.com，工作日 9:00—18:00 回复。');
  }

  return (
    <main className="page">
      <h1>常见问题</h1>
      <div className={styles.tabs}>
        {faqTabs.map((tab) => (
          <button
            key={tab.value}
            type="button"
            aria-pressed={tab.value === activeTab}
            className={tab.value === activeTab ? styles.activeTab : undefined}
            onClick={() => setActiveTab(tab.value)}
          >
            {tab.label}
          </button>
        ))}
      </div>
      {activeTab === 'account' && <p className={styles.hint}>登录、密码和个人资料相关的问题。</p>}
      {activeTab === 'payment' && <p className={styles.hint}>付款方式、发票和退款相关的问题。</p>}
      {activeTab === 'study' && <p className={styles.hint}>课程观看、练习和证书相关的问题。</p>}
      <ul className={styles.list}>
        {faqs.map((faq) => (
          <FaqItem
            key={faq.id}
            faq={faq}
            isOpen={faq.id === openId}
            onToggle={() => handleToggle(faq.id)}
          />
        ))}
      </ul>
      <section className={styles.section}>
        <h2>这些回答对你有帮助吗？</h2>
        <button type="button" onClick={handleHelpfulClick}>
          有帮助（{helpfulCount}）
        </button>{' '}
        <button type="button" onClick={handleVeryHelpfulClick}>
          非常有帮助（算 2 票）
        </button>
      </section>
      <section className={styles.section}>
        <p>没有找到答案？</p>
        <button type="button" onClick={handleContactClick}>
          联系客服
        </button>
      </section>
    </main>
  );
}
```

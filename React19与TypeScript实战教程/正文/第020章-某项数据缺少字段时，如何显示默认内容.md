# 第 20 章：某项数据缺少字段时，如何显示默认内容？

前置：[第 19 章：列表为空时，如何显示提示？](第019章-列表为空时，如何显示提示.md)

## 一、本章要解决的问题

不是每条新闻都有摘要。有的新闻只有一个标题，例如“图书角新增三本前端书籍”，发布的人没写摘要。如果数据中没有摘要，页面上这条新闻的摘要位置会是空的，看起来像是漏了内容。

本章允许新闻没有摘要，并在没有摘要时显示“暂无摘要”。完成后，第二条新闻显示“暂无摘要”，其他新闻照常显示自己的摘要。

## 二、必要原理

### 在类型中标出可以缺少的字段

第 10 章给组件的属性加过问号，表示可以不传。数据类型中的字段也一样：

```ts
export type NewsItem = {
  id: number;
  title: string;
  summary?: string;
};
```

`summary?: string` 表示：有摘要时它是字符串，也可以完全没有这个字段。没有这个字段时，读取 `item.summary` 得到 `undefined`。

加上问号后，TypeScript 会提醒你：使用 `item.summary` 的地方要考虑它可能是 `undefined`。

### ?? ：没有值时使用默认值

`??` 叫做空值合并运算符：

```ts
item.summary ?? '暂无摘要'
```

意思是：左边有值就用左边；左边是 `undefined` 或 `null`（都表示“没有值”）时，用右边的默认值。

### 为什么不用 ||

你可能见过 `a || b` 的写法，它在左边为“假值”时使用右边。假值不只有 `undefined`，还包括空字符串 `''`、数字 `0`、`false`。

这在显示数据时会出问题：如果某个数字字段的值正好是 `0`（例如“评论数 0”），`count || '未知'` 会显示成“未知”。`??` 只在真正没有值时才使用默认值，`0` 和空字符串都会原样保留。需要“没有值时给默认值”，用 `??`。

### 第 10 章的默认值有什么不同

第 10 章的 `note = '还没有留言。'` 是组件参数的默认值，写在函数参数中，只在使用组件时没传这个属性时生效。本章处理的是数据对象中缺少的字段，数据不是通过组件属性一项一项传进来的，所以在显示的地方用 `??` 处理。

## 三、动手实现

### 第 1 步：允许 summary 缺少

打开 `src/data/news.ts`，在类型的 `summary` 后面加问号，并删除第二条新闻的摘要：

```ts
export type NewsItem = {
  id: number;
  title: string;
  summary?: string;
};
```

```ts
  { id: 2, title: '图书角新增三本前端书籍' },
```

### 第 2 步：没有摘要时显示默认文字

打开 `src/pages/NewsPage.tsx`，把显示摘要的那一行改为：

```tsx
              <p>{item.summary ?? '暂无摘要'}</p>
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 第一条和第三条新闻显示自己的摘要。
2. 第二条“图书角新增三本前端书籍”的摘要位置显示“暂无摘要”。
3. 给第二条新闻加上 `summary: ''`（空字符串），保存。页面上这一条的摘要变成空白，而不是“暂无摘要”。这说明 `??` 只处理“没有值”，空字符串被当作一个值保留了。想想这种情况下该怎样处理（见小练习）。检查后删掉 `summary: ''`。

最后运行检查，应没有错误：

```powershell

```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 删除第二条的 `summary` 后，编辑器报错缺少属性 | 类型中的 `summary` 没有加问号 | 写成 `summary?: string` |
| 没有摘要的新闻显示空白，没有默认文字 | 显示的地方没有用 `??` | 写成 `{item.summary ?? '暂无摘要'}` |
| 数字 0 被显示成默认文字 | 用了 `||` | 改用 `??` |
| 默认文字没有显示，页面显示“undefined” | 把整段写进了一个字符串，例如 `'{item.summary}'` | 花括号中写表达式，不要加引号 |
| 在类型中写 `summary?: string = '暂无摘要'` 报错 | 类型只描述形状，不能写值 | 默认值在显示时用 `??` 处理 |

## 六、本章完整代码

### `src/data/news.ts`

```ts
export type NewsItem = {
  id: number;
  title: string;
  summary?: string;
};

export const newsItems: NewsItem[] = [
  { id: 1, title: '学习小组本周开始新的练习', summary: '本周练习用数组生成新闻列表。' },
  { id: 2, title: '图书角新增三本前端书籍' },
  { id: 3, title: '下周六举行代码分享会', summary: '每位成员分享一个自己写的组件。' },
];
```

### `src/pages/NewsPage.tsx`

```tsx
import { newsItems } from '../data/news';
import styles from './NewsPage.module.css';

export default function NewsPage() {
  return (
    <main className="page">
      <h1>小组新闻</h1>
      {newsItems.length === 0 ? (
        <p className={styles.empty}>暂时没有新闻。</p>
      ) : (
        <ul className={styles.list}>
          {newsItems.map((item) => (
            <li key={item.id} className={styles.item}>
              <h2>{item.title}</h2>
              <p>{item.summary ?? '暂无摘要'}</p>
            </li>
          ))}
        </ul>
      )}
    </main>
  );
}
```

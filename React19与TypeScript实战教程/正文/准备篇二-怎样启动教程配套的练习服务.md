# 准备篇二：怎样启动教程配套的练习服务？

前置：[准备篇一：怎样创建并运行 React 19 + TypeScript 项目？](准备篇一-怎样创建并运行React19与TypeScript项目.md)

## 一、本章要解决的问题

从第 62 章开始，页面要从服务器读取数据、把修改保存到服务器，还要做登录。为此，本教程配套了一个现成的练习服务，它在你的电脑上运行，提供文章、任务、商品、登录、上传等接口。

本章把练习服务放进项目，学会启动、停止和重置数据。完成后，在浏览器中打开一个地址，能看到练习服务返回的数据。第 1—61 章用不到它，本章只是先把准备工作做完。

## 二、必要原理

### 前端和后端

浏览器中显示的页面叫前端，本教程学的就是前端开发。页面需要的数据通常保存在另一台程序里，这个程序叫后端或服务器。前端通过网址向后端要数据，这种专门返回数据的网址叫接口。

实际工作中，后端由后端开发人员编写。本教程的练习服务替你扮演这个角色：所有接口都已经写好，你只需要启动它，**不需要读懂或修改它的代码**。

### 两个程序，两个终端

准备篇一的开发服务器（`npm.cmd run dev`）负责提供页面，地址是 `http://127.0.0.1:5173`。练习服务是另一个独立的程序，地址是 `http://127.0.0.1:3001`。两者同时运行时，各占一个终端，互不影响：

| 程序 | 启动命令 | 地址 | 什么时候需要 |
| --- | --- | --- | --- |
| 开发服务器 | `npm.cmd run dev` | `http://127.0.0.1:5173` | 每一章 |
| 练习服务 | `npm.cmd run api` | `http://127.0.0.1:3001` | 第 62 章起，章节中会提示 |

`127.0.0.1` 是“本机”的意思，这两个地址只有你自己的电脑能访问。

### 练习服务的数据保存在哪里

练习服务第一次启动时，会在 `server/data` 文件夹中生成 `practice-data.json`，你新增或修改的任务等数据都保存在这个文件里。停止再启动服务，数据仍然保留。想回到初始状态时，运行重置命令即可。

登录状态是例外：它只保存在练习服务运行期间的内存中，重启服务后需要重新登录。

## 三、动手实现

### 第 1 步：复制练习服务文件

在项目文件夹 `react-daily-practice` 中新建 `server` 文件夹。本教程的文件夹中，与 `正文` 文件夹并列的是 `练习服务` 文件夹，里面有 `practice-server.mjs`。把它复制到 `server` 文件夹里：

```text
react-daily-practice/
  server/
    practice-server.mjs
  src/
  package.json
  ……
```

这个文件只使用 Node.js 自带的功能，不需要安装任何依赖。

### 第 2 步：添加启动和重置命令

打开 `package.json`，在 `scripts` 中 `preview` 那一行后面加上两行。注意 `preview` 那一行末尾要补一个逗号：

```json
    "preview": "vite preview --host 127.0.0.1",
    "api": "node server/practice-server.mjs",
    "reset-data": "node server/practice-server.mjs --reset"
```

- `api`：启动练习服务。
- `reset-data`：把练习数据恢复成初始状态，然后自动退出。

### 第 3 步：不让 Git 保存练习数据

练习数据是运行时自动生成的，不属于项目代码。打开 `.gitignore`，加上第三行：

```text
node_modules/
dist/
server/data/
```

## 四、运行与检查

1. 在项目文件夹中打开一个新的终端，运行：

   ```powershell
   npm.cmd run api
   ```

   终端显示“练习服务已启动：http://127.0.0.1:3001/api/health”，并保持运行。

2. 在浏览器中打开 `http://127.0.0.1:3001/api/health`，页面显示 `{"ok":true}`。大约有半秒的停顿，这是练习服务故意设置的等待时间，后面的章节会用它来观察“加载中”的效果。

3. 打开 `http://127.0.0.1:3001/api/articles`，页面显示一组文章数据。回到练习服务的终端，可以看到每次访问都打印了一行记录，例如 `GET /api/articles → 200`。

4. 在练习服务的终端按 Ctrl+C 停止服务，再刷新浏览器，页面无法打开。

5. 运行一次重置命令，终端显示“练习数据已恢复为初始状态”后自动结束：

   ```powershell
   npm.cmd run reset-data
   ```

6. 重新运行 `npm.cmd run api`，再访问第 2 步的地址，恢复正常。确认后可以停止练习服务，到第 62 章再启动。

以后需要练习服务的章节，会在“运行与检查”中提示“保持开发服务器和练习服务都在运行”。

练习服务提供的登录账号如下，第 109 章起会用到：

| 用户名 | 密码 | 身份 |
| --- | --- | --- |
| `admin` | `learn1234` | 管理员 |
| `member` | `learn1234` | 普通成员 |

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 提示 `Cannot find module`，后面是 `practice-server.mjs` 的路径 | 文件没有放在 `server` 文件夹中，或文件名不同 | 确认路径是 `react-daily-practice\server\practice-server.mjs` |
| 提示 `EADDRINUSE` 和 `3001` | 已经有一个练习服务在运行，端口被占用 | 找到之前运行 `npm.cmd run api` 的终端，继续使用它；或在那里按 Ctrl+C 后重新启动 |
| `npm.cmd run api` 提示找不到 `api` 命令 | `package.json` 中没有加上命令，或少了逗号导致格式错误 | 对照第三节第 2 步检查 |
| 浏览器访问 `http://127.0.0.1:3001/` 显示“练习服务只提供 /api 和 /uploads 地址” | 地址少了 `/api/...` 部分 | 访问具体接口，例如 `/api/health` |
| 按 Ctrl+C 后终端询问“终止批处理操作吗(Y/N)?” | 通过 `npm.cmd` 启动的程序被中断时，Windows 会这样确认 | 输入 Y 并回车即可 |

## 六、本章完整代码

### `package.json`

```json
{
  "name": "react-daily-practice",
  "private": true,
  "version": "0.0.0",
  "type": "module",
  "scripts": {
    "dev": "vite --host 127.0.0.1",
    "typecheck": "tsc --noEmit",
    "build": "npm run typecheck && vite build",
    "preview": "vite preview --host 127.0.0.1",
    "api": "node server/practice-server.mjs",
    "reset-data": "node server/practice-server.mjs --reset"
  },
  "dependencies": {
    "react": "19.3.1",
    "react-dom": "19.3.1"
  },
  "devDependencies": {
    "@types/react": "19.3.0",
    "@types/react-dom": "19.3.0",
    "@vitejs/plugin-react": "6.2.1",
    "typescript": "7.0.2",
    "vite": "8.3.5"
  }
}
```

### `.gitignore`

```text
node_modules/
dist/
server/data/
```

### `server/practice-server.mjs`

从本教程的 `练习服务` 文件夹（与 `正文` 文件夹并列）复制，内容不需要修改。

## 七、本章改动小结

新增 `server/practice-server.mjs`；修改 `package.json`（新增 `api`、`reset-data` 两个命令）和 `.gitignore`（新增 `server/data/`）。

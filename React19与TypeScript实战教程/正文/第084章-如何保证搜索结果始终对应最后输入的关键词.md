# 第 84 章：【组合】如何保证搜索结果始终对应最后输入的关键词？

前置：[第 83 章：如何把防抖逻辑提取成自定义 Hook？](第083章-如何把防抖逻辑提取成自定义Hook.md)

## 一、本章要解决的问题

搜索页已经有了防抖、取消旧请求和结果检查，但页面上只写着“正在搜索……”或者直接列出文章，用户无法确认眼前的结果是不是自己最后输入的那个词。搜索变慢、或者用户连续改了几次关键词时，这一点尤其重要。

本章让页面写清楚：搜索中显示“正在搜索“type”……”，完成后显示“‘type’的搜索结果：1 篇”，下面是文章。同时回顾本部分的几项技术，确认它们一起保证了“显示的结果始终对应最后输入的关键词”。

本章是一个组合练习，用到第 69 章的联合类型、第 77 章的防抖、第 79 章的取消请求。

## 二、必要原理

### 一次搜索要经过的几道关卡

用户输入后，到结果显示在页面上，要经过这几步：

| 环节 | 保证了什么 | 在哪一章 |
| --- | --- | --- |
| 在搜索的 Effect 中设置状态 | 只有搜索真正开始时才显示“正在搜索”，打错又改回也不会卡住 | 第 77 章 |
| 防抖 | 输入期间不发请求，只按停顿后的关键词搜索 | 第 77、83 章 |
| 清理时取消请求 | 关键词变化后，旧请求被取消，旧结果不会被显示 | 第 78、79 章 |
| 检查返回的数据 | 格式不对时显示错误，而不是显示错误的内容 | 第 68 章 |
| 结果中带上关键词 | 页面写明结果属于哪个关键词 | 本章 |

前四项已经保证了页面上的结果总是最后一次搜索的结果。但第 77 章以后，输入后等待的 0.5 秒里，页面上还是上一次的结果，用户分不清它属于哪个词。本章加上最后一项，把关键词写在结果上方。

### 把关键词存进状态

在联合类型中，给 `loading` 和 `success` 两种状态各加一个 `query` 字段：

```tsx
| { status: 'loading'; query: string }
| { status: 'success'; query: string; items: Article[] }
```

两个 `query` 都来自搜索 Effect 中的 `query` 变量，也就是这次请求实际使用的关键词：`loading` 的在搜索开始时设置，`success` 的在搜索完成时设置。显示时直接读取状态中的关键词，不再另外拼接输入框的值。

### 结果数量写在标题中

成功时用一个 `<h2>` 写明“‘type’的搜索结果：1 篇”。没有找到时同样显示这个标题，数量是 0 篇，原来单独的“没有找到相关文章。”就不需要了。

## 三、动手实现

### 第 1 步：添加标题样式

在 `src/pages/SearchPage.module.css` 末尾加入：

```css
.resultTitle {
  margin: 16px 0 0;
  font-size: 16px;
  color: #52606d;
}
```

### 第 2 步：状态中带上关键词

在 `src/pages/SearchPage.tsx` 中，把 `SearchState` 中的两行改为：

```tsx
  | { status: 'loading'; query: string }
  | { status: 'success'; query: string; items: Article[] }
```

搜索的 Effect 中，成功时的一行改为：

```tsx
        setSearchState({ status: 'success', query, items });
```

开始搜索时设置状态的一行改为：

```tsx
    setSearchState({ status: 'loading', query });
```

### 第 3 步：显示关键词和结果数量

加载提示改为：

```tsx
      {searchState.status === 'loading' && (
        <p role="status">正在搜索“{searchState.query}”……</p>
      )}
```

把成功状态的显示替换为：

```tsx
      {searchState.status === 'success' && (
        <section>
          <h2 className={styles.resultTitle}>
            “{searchState.query}”的搜索结果：{searchState.items.length} 篇
          </h2>
          {searchState.items.length > 0 && <ArticleList articles={searchState.items} />}
        </section>
      )}
```

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。

1. 输入 `type`，显示“正在搜索“type”……”，然后显示“‘type’的搜索结果：1 篇”和“TypeScript 类型检查”。
2. 输入 `t`，停顿约 0.7 秒，再输入 `ype`：中间短暂显示“正在搜索“t”……”，最后显示的是“type”的结果，`q=t` 的请求被取消。
3. 输入 `电脑`，显示“‘电脑’的搜索结果：0 篇”。
4. 输入 `  type  `（前后有空格），标题中显示的是去掉空格后的 `type`。
5. 搜出 `type` 的结果后，输入 `s` 再马上删掉：标题仍是“‘type’的搜索结果：1 篇”，没有新的请求。
6. 清空输入框，大约半秒后显示提示文字。
7. 停止练习服务后输入关键词，显示错误提示；启动后修改关键词，搜索恢复正常。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 编辑器提示 `loading` 状态缺少 `query` | 改了类型，搜索 Effect 中仍写 `{ status: 'loading' }` | 写成 `{ status: 'loading', query }` |
| 标题中的关键词前后带着空格 | 显示的是输入框的原始值，没有 `trim()` | 显示状态中保存的 `query` |
| 标题和结果对不上 | 成功时保存的是输入框当前的 `keyword`，而不是这次请求用的 `query` | 保存 Effect 中的 `query` 变量 |
| 没有结果时什么都不显示 | 把标题也放进了 `items.length > 0` 的条件中 | 标题总是显示，只有列表放在条件中 |

### `src/pages/SearchPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { ChangeEvent } from 'react';
import ArticleList from '../components/ArticleList';
import { useDebouncedValue } from '../hooks/useDebouncedValue';
import { apiUrl } from '../lib/api';
import { isArticle } from '../types/article';
import type { Article } from '../types/article';
import styles from './SearchPage.module.css';

type SearchState =
  | { status: 'idle' }
  | { status: 'loading'; query: string }
  | { status: 'success'; query: string; items: Article[] }
  | { status: 'error'; message: string };

async function fetchSearchResults(query: string, signal: AbortSignal): Promise<Article[]> {
  let response: Response;
  try {
    response = await fetch(apiUrl('/search?q=' + encodeURIComponent(query)), { signal });
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
  if (!response.ok) {
    throw new Error('搜索失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (
    typeof data !== 'object' ||
    data === null ||
    !('items' in data) ||
    !Array.isArray(data.items) ||
    !data.items.every(isArticle)
  ) {
    throw new Error('搜索结果格式不正确，暂时无法显示。');
  }
  return data.items;
}

export default function SearchPage() {
  const [keyword, setKeyword] = useState('');
  const [searchState, setSearchState] = useState<SearchState>({ status: 'idle' });
  const debouncedKeyword = useDebouncedValue(keyword, 500);

  useEffect(() => {
    const query = debouncedKeyword.trim();
    if (query === '') {
      setSearchState({ status: 'idle' });
      return;
    }
    setSearchState({ status: 'loading', query });
    const controller = new AbortController();

    async function search() {
      try {
        const items = await fetchSearchResults(query, controller.signal);
        setSearchState({ status: 'success', query, items });
      } catch (error) {
        if (controller.signal.aborted) {
          return;
        }
        const message = error instanceof Error ? error.message : '搜索失败。';
        setSearchState({ status: 'error', message });
      }
    }

    search();
    return () => {
      controller.abort();
    };
  }, [debouncedKeyword]);

  function handleKeywordChange(event: ChangeEvent<HTMLInputElement>) {
    setKeyword(event.target.value);
  }

  return (
    <main className="page">
      <h1>搜索文章</h1>
      <div className={styles.searchBox}>
        <label htmlFor="search-keyword">关键词</label>
        <input
          id="search-keyword"
          type="search"
          value={keyword}
          onChange={handleKeywordChange}
        />
      </div>
      {searchState.status === 'idle' && <p className={styles.hint}>输入关键词，搜索文章标题。</p>}
      {searchState.status === 'loading' && (
        <p role="status">正在搜索“{searchState.query}”……</p>
      )}
      {searchState.status === 'error' && <p role="alert">{searchState.message}</p>}
      {searchState.status === 'success' && (
        <section>
          <h2 className={styles.resultTitle}>
            “{searchState.query}”的搜索结果：{searchState.items.length} 篇
          </h2>
          {searchState.items.length > 0 && <ArticleList articles={searchState.items} />}
        </section>
      )}
    </main>
  );
}
```

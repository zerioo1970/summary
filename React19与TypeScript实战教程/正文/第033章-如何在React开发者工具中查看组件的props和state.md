# 第 33 章：如何在 React 开发者工具中查看组件的 props 和 state？

前置：[第 32 章：哪些数据需要放进 state，哪些可以直接计算出来？](第032章-哪些数据需要放进state，哪些可以直接计算出来.md)

## 一、本章要解决的问题

页面出了问题时，常常需要知道“现在某个组件的 state 是多少”“父组件到底传了什么 props 给子组件”。到目前为止，我们只能加 `console.log` 打印出来，看完还要删掉。

本章安装浏览器扩展 React Developer Tools（React 开发者工具），不改任何代码，直接查看页面上每个组件当前的 props 和 state，还能临时修改它们观察页面的变化。完成后，你能在工具中找到 `FaqPage` 的三个 state 和 `FaqItem` 收到的 props。

## 二、必要原理

### 浏览器自带的工具看不到组件

第 6 章用过的 Elements（元素）面板显示的是 HTML 元素。第 8 章说过，组件只存在于 React 代码中，浏览器得到的只是组件返回的 HTML，所以在 Elements 面板中找不到 `FaqPage`、`FaqItem`，也看不到 state。

React 开发者工具是 React 官方提供的浏览器扩展。它能读取 React 内部的信息，把页面按**组件**的层级显示出来，并列出每个组件当前的 props 和 state。

### 安装后多出两个面板

安装扩展后，打开开发者工具（F12）时，面板标签栏会多出两个：

- **Components**：组件树，以及选中组件的 props 和 state。本章使用这个面板。
- **Profiler**：用于性能分析，属于进阶专题。

标签栏放不下时，它们会收在最右边的 `»` 按钮中。

### state 在工具中显示为 hooks

在 Components 面板中选中一个函数组件，右侧会显示：

- **props**：组件收到的属性。函数类型的 props 显示为 `ƒ`，例如 `onToggle: ƒ ()`。
- **hooks**：组件中调用的 Hook，按调用顺序排列。`useState` 显示为 `State`，后面是当前值。

工具中只显示 Hook 的种类和顺序，不显示变量名。多个 `useState` 按代码中的顺序对应：第一个 `State` 就是第一个 `useState` 的值。这也说明了第 26 章的规则为什么重要：React 正是靠调用顺序区分它们的。

## 三、动手实现

本章不修改代码。

### 第 1 步：安装扩展

- **Chrome**：打开 Chrome 应用商店，搜索“React Developer Tools”，安装由 Meta 发布的那个扩展。
- **Edge**：打开 Edge 外接程序商店，搜索“React Developer Tools”并安装。

安装后，浏览器工具栏的扩展图标中会出现一个 React 图标。打开开发服务器的页面时，图标会亮起，表示检测到这个页面使用了 React。

如果商店无法访问，可以先跳过本章，后续章节不依赖这个工具。

### 第 2 步：找到组件和它的 state

1. 打开常见问题页，按 F12，切换到 **Components** 面板。
2. 左侧是组件树：`App` 下面是 `FaqPage`，`FaqPage` 下面有五个 `FaqItem`。
3. 点击 `FaqPage`，右侧的 hooks 中依次显示三个 `State`：`0`（投票数）、`null`（展开的问题）、`"account"`（当前标签）。
4. 回到页面，点击“有帮助”，再展开第二个问题，切换到“学习”标签。工具中三个 `State` 依次变成 `1`、`2`、`"study"`，与页面一致。

### 第 3 步：查看子组件收到的 props

1. 在组件树中点击第二个 `FaqItem`。
2. 右侧的 props 中显示 `faq`（可以点击展开，看到问题的 `id`、`category`、`question`、`answer`）、`isOpen: true`、`onToggle: ƒ ()`。
3. 点击第一个 `FaqItem`，它的 `isOpen` 是 `false`。“同时只展开一个”正是由父组件传入的不同 `isOpen` 实现的。

### 第 4 步：在工具中临时修改 state

1. 选中 `FaqPage`，双击第一个 `State` 的值 `1`，改成 `100`，按 Enter。
2. 页面上的按钮立刻变成“有帮助（100）”。
3. 刷新页面，一切恢复初始值。在工具中修改的只是这一次运行中的 state，不会改动代码。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），按第三节的步骤操作。

1. 在 Components 面板中能看到 `App` → `FaqPage` → 五个 `FaqItem` 的组件树。
2. `FaqPage` 的三个 `State` 随页面操作实时变化。
3. 展开的那个 `FaqItem` 的 `isOpen` 是 `true`，其余都是 `false`。
4. 在工具中修改 state 后，页面立即更新；刷新后恢复。

本章没有修改代码，不需要运行检查命令。

**小练习**：在工具中把 `FaqPage` 的第三个 `State` 改成 `"payment"`，观察标签高亮和说明文字的变化。再试着改成 `"hello"`，页面会怎样？为什么 TypeScript 没有阻止这个值？（提示：TypeScript 只检查你写的代码，工具中的修改发生在运行时。）

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 开发者工具中没有 Components 面板 | 扩展没有安装成功，或面板收在了 `»` 中 | 点击标签栏最右边的 `»` 查找；必要时重新安装扩展 |
| React 图标是灰色的 | 当前页面不是开发服务器的页面，或页面还没加载完 | 打开 `http://127.0.0.1:5173/` 后刷新 |
| 组件树中只有 `App`，找不到 `FaqItem` | 组件树没有展开 | 点击组件名左边的小三角 |
| hooks 中看不到变量名 | 工具只显示 Hook 的种类和顺序 | 按代码中 `useState` 的顺序对照 |
| 刷新后在工具中做的修改消失了 | 工具中的修改只在这一次运行中有效 | 正常现象，要长期修改就改代码 |

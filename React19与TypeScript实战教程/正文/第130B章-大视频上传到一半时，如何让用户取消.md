# 第 130B 章：大视频上传到一半时，如何让用户取消？

前置：[第 130A 章：上传大视频时，如何显示上传进度？](第130A章-上传大视频时，如何显示上传进度.md)

## 一、本章要解决的问题

上传一个大视频，传到一半发现选错了文件，只能干等它传完，或者关掉整个页面。另外，上传途中点导航去了别的页面，上传其实还在后台继续，白白占用网络，传完的结果也没有地方显示。

本章让上传可以中途取消。完成后：上传过程中，“上传视频”按钮旁边出现“取消上传”；点击后上传立刻停止，进度条消失，显示“已取消上传。”，服务器上也不会留下这个视频；上传途中离开“上传视频”页，上传会自动停止。

## 二、必要原理

### 用 AbortController 发出“不要了”

第 79 章取消搜索请求时用过 `AbortController`：创建一个控制器，把它的 `signal` 交给请求，需要取消时调用 `controller.abort()`。这次也用同样的方式，只是请求换成了 XHR：

- `uploadWithProgress` 多接收一个 `signal` 参数；
- 监听 `signal` 的 `abort` 事件，收到时调用 `xhr.abort()`，浏览器立刻中止这次上传；
- 中止后 XHR 触发自己的 `abort` 事件，这时调用 `reject`，让等待它的 `await` 结束。

这样，调用方取消上传的写法和取消 `fetch` 完全一样。

### 把控制器放进 ref

“取消上传”按钮的处理函数要拿到这一次上传的控制器。控制器不需要显示在页面上，修改它也不需要重新渲染，正适合放进第 115A 章的 ref：开始上传时 `controllerRef.current = controller`，结束时（不论成功、失败还是取消）改回 `null`。

### 取消不是出错

被取消的上传，`await` 会抛出错误，进入 `catch`。但这是用户自己要求的，不应该显示成红色的错误。在 `catch` 中先看 `controller.signal.aborted`：为 `true` 说明是取消的，显示一句普通的提示“已取消上传。”即可。

### 离开页面时也取消

页面组件被移除时，用 Effect 的清理函数调用 `abort()`，和第 81 章离开页面时清除定时器是同一个思路。这个 Effect 的依赖数组是 `[]`，主体中什么也不做，只提供清理函数。

### 服务器那边

上传被中止时，练习服务还没有收到完整的文件，不会保存它。真实项目中，服务器也应该在收到完整的文件后才保存，或者定期清理没有传完的临时文件。

## 三、动手实现

### 第 1 步：上传函数支持取消

打开 `src/lib/uploadWithProgress.ts`，在参数中 `onProgress` 的下面加入：

```ts
  // 和第 79 章的 fetch 一样，用 AbortSignal 通知“不要了”
  signal: AbortSignal,
```

在 `const xhr = new XMLHttpRequest();` 的下面加入：

```ts
    signal.addEventListener('abort', () => {
      xhr.abort();
    });
```

在监听 `error` 的代码后面加入：

```ts
    // 调用 xhr.abort() 后触发 abort 事件，load 和 error 都不会再触发
    xhr.addEventListener('abort', () => {
      reject(new Error('已取消上传。'));
    });
```

### 第 2 步：页面中保存控制器

打开 `src/pages/VideosPage.tsx`，把第一行改为：

```tsx
import { useEffect, useRef, useState } from 'react';
```

在 `isUploading` 那一行的上面加入一个 state，在它的下面加入 ref 和离开页面时的清理：

```tsx
  const [notice, setNotice] = useState('');
  const isUploading = progress !== null;
  // 保存当前这次上传的 AbortController，点“取消”或离开页面时用它中止
  const controllerRef = useRef<AbortController | null>(null);

  // 上传途中离开页面，就不要再继续上传了
  useEffect(() => {
    return () => {
      if (controllerRef.current) {
        controllerRef.current.abort();
      }
    };
  }, []);
```

在 `handleFileChange` 中 `setVideo(null);` 的下面加入 `setNotice('');`，选新文件时清除上一次的提示。

### 第 3 步：上传时创建控制器，取消时给出提示

在 `handleUpload` 中，把 `form.append('video', file);` 之后到调用 `uploadWithProgress` 的部分改为：

```tsx
    const controller = new AbortController();
    controllerRef.current = controller;
    setError('');
    setNotice('');
    setProgress(0);
    try {
      const response = await uploadWithProgress(
        apiUrl('/videos'),
        form,
        setProgress,
        controller.signal,
      );
```

把 `catch` 和 `finally` 两部分改为：

```tsx
    } catch (caught) {
      // 用户自己取消的，不算出错，只给一句提示
      if (controller.signal.aborted) {
        setNotice('已取消上传。');
        return;
      }
      setError(caught instanceof Error ? caught.message : '上传失败，请稍后重试。');
    } finally {
      controllerRef.current = null;
      setProgress(null);
    }
  }

  function handleCancel() {
    if (controllerRef.current) {
      controllerRef.current.abort();
    }
  }
```

`finally` 中的代码在 `catch` 里 `return` 之后仍然会执行（第 89 章），进度条照样会消失。

### 第 4 步：“取消上传”按钮

在“上传视频”按钮的 `</button>` 后面、`</div>` 前面加入：

```tsx
          {isUploading && (
            <button type="button" className={styles.cancel} onClick={handleCancel}>
              取消上传
            </button>
          )}
```

在这个 `</div>` 的后面加入提示：

```tsx
        {notice && <p role="status">{notice}</p>}
```

打开 `src/pages/VideosPage.module.css`，在文件最后加入：

```css

.cancel {
  margin-left: 8px;
}
```

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。准备一个几十 MB 的视频。

1. 打开“视频”页，选择视频，点“上传视频”。按钮旁边出现“取消上传”。
2. 进度到一半时点“取消上传”。进度条立刻消失，显示“已取消上传。”，没有红色的错误提示；“上传视频”按钮恢复可用。
3. 在 Network（网络）面板中，`/api/videos` 这次请求的状态显示为 `(canceled)`（已取消）。练习服务的终端中没有这次上传的记录。
4. 再点“上传视频”，可以重新上传，这一次让它传完，显示“上传完成”和播放器。
5. 再上传一次，途中点导航中的“新闻”。Network 中这次请求同样被取消，练习服务没有保存这个视频。
6. 停止练习服务后上传，显示红色的“上传失败：服务器返回了状态 502。”，和取消时的提示不同。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：点“取消上传”时先问一句“确定要取消上传吗？已上传 X%。”，用户点“取消”就继续上传（第 93B 章的 `window.confirm`）。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 点了“取消上传”，进度条还在继续增长 | 只调用了 `controller.abort()`，`uploadWithProgress` 中没有监听 `signal` 并调用 `xhr.abort()` | 监听 `signal` 的 `abort` 事件，在里面调用 `xhr.abort()` |
| 取消后页面一直显示“正在上传……” | XHR 没有监听自己的 `abort` 事件，`await` 永远等不到结果 | 在 `abort` 事件中调用 `reject` |
| 取消后显示红色的“已取消上传。” | 没有区分取消和真正的失败 | 在 `catch` 中先判断 `controller.signal.aborted` |
| 离开页面后，Network 中的上传仍在继续 | 没有在 Effect 的清理函数中中止 | 清理函数中调用 `controllerRef.current.abort()` |

## 六、本章完整代码

### `src/lib/uploadWithProgress.ts`

```ts
export type UploadResponse = {
  status: number;
  body: string;
};

// fetch 拿不到上传进度，所以用浏览器更早提供的 XMLHttpRequest 发送
export function uploadWithProgress(
  url: string,
  form: FormData,
  onProgress: (percent: number) => void,
  // 和第 79 章的 fetch 一样，用 AbortSignal 通知“不要了”
  signal: AbortSignal,
): Promise<UploadResponse> {
  return new Promise((resolve, reject) => {
    const xhr = new XMLHttpRequest();
    signal.addEventListener('abort', () => {
      xhr.abort();
    });
    xhr.open('POST', url);
    xhr.upload.addEventListener('progress', (event) => {
      if (event.lengthComputable) {
        onProgress(Math.round((event.loaded / event.total) * 100));
      }
    });
    // load 表示收到了服务器的回答，不论状态码是多少
    xhr.addEventListener('load', () => {
      resolve({ status: xhr.status, body: xhr.responseText });
    });
    xhr.addEventListener('error', () => {
      reject(new Error('无法连接练习服务，请确认它已经启动。'));
    });
    // 调用 xhr.abort() 后触发 abort 事件，load 和 error 都不会再触发
    xhr.addEventListener('abort', () => {
      reject(new Error('已取消上传。'));
    });
    xhr.send(form);
  });
}
```

### `src/pages/VideosPage.tsx`

```tsx
import { useEffect, useRef, useState } from 'react';
import type { ChangeEvent } from 'react';
import { apiUrl } from '../lib/api';
import { uploadWithProgress } from '../lib/uploadWithProgress';
import { isVideo } from '../types/video';
import type { Video } from '../types/video';
import styles from './VideosPage.module.css';

const ALLOWED_TYPES = ['video/mp4', 'video/webm'];
const MAX_SIZE = 200 * 1024 * 1024;

function formatSize(bytes: number) {
  return (bytes / 1024 / 1024).toFixed(1) + 'MB';
}

function readMessage(body: string, fallback: string) {
  try {
    const data: unknown = JSON.parse(body);
    if (typeof data === 'object' && data !== null && 'message' in data) {
      if (typeof data.message === 'string') {
        return data.message + '。';
      }
    }
  } catch {
    // 返回的不是 JSON 时，使用默认的提示
  }
  return fallback;
}

export default function VideosPage() {
  const [file, setFile] = useState<File | null>(null);
  const [error, setError] = useState('');
  const [progress, setProgress] = useState<number | null>(null);
  const [video, setVideo] = useState<Video | null>(null);
  const [notice, setNotice] = useState('');
  const isUploading = progress !== null;
  // 保存当前这次上传的 AbortController，点“取消”或离开页面时用它中止
  const controllerRef = useRef<AbortController | null>(null);

  // 上传途中离开页面，就不要再继续上传了
  useEffect(() => {
    return () => {
      if (controllerRef.current) {
        controllerRef.current.abort();
      }
    };
  }, []);

  function handleFileChange(event: ChangeEvent<HTMLInputElement>) {
    const files = event.target.files;
    setVideo(null);
    setNotice('');
    if (!files || files.length === 0) {
      setFile(null);
      return;
    }
    const selected = files[0];
    if (!ALLOWED_TYPES.includes(selected.type)) {
      setError('只能选择 MP4 或 WebM 格式的视频。');
    } else if (selected.size > MAX_SIZE) {
      setError('视频不能超过 200MB，这个视频有 ' + formatSize(selected.size) + '。');
    } else {
      setError('');
      setFile(selected);
      return;
    }
    setFile(null);
    event.target.value = '';
  }

  async function handleUpload() {
    if (!file) {
      return;
    }
    const form = new FormData();
    form.append('video', file);
    const controller = new AbortController();
    controllerRef.current = controller;
    setError('');
    setNotice('');
    setProgress(0);
    try {
      const response = await uploadWithProgress(
        apiUrl('/videos'),
        form,
        setProgress,
        controller.signal,
      );
      if (response.status !== 201) {
        setError(readMessage(response.body, '上传失败：服务器返回了状态 ' + response.status + '。'));
        return;
      }
      const data: unknown = JSON.parse(response.body);
      if (!isVideo(data)) {
        setError('上传成功，但返回的数据格式不正确。');
        return;
      }
      setVideo(data);
    } catch (caught) {
      // 用户自己取消的，不算出错，只给一句提示
      if (controller.signal.aborted) {
        setNotice('已取消上传。');
        return;
      }
      setError(caught instanceof Error ? caught.message : '上传失败，请稍后重试。');
    } finally {
      controllerRef.current = null;
      setProgress(null);
    }
  }

  function handleCancel() {
    if (controllerRef.current) {
      controllerRef.current.abort();
    }
  }

  return (
    <main className="page">
      <title>上传视频</title>
      <h1>上传视频</h1>
      <div className={styles.box}>
        <label htmlFor="video-file">选择视频</label>
        <input
          id="video-file"
          type="file"
          accept="video/mp4,video/webm"
          disabled={isUploading}
          onChange={handleFileChange}
        />
        <p className={styles.hint}>支持 MP4、WebM，不超过 200MB。</p>
        {file && <p>已选择：{file.name}（{formatSize(file.size)}）</p>}
        {error && (
          <p role="alert" className={styles.error}>
            {error}
          </p>
        )}
        <div>
          <button type="button" disabled={!file || isUploading} onClick={handleUpload}>
            {isUploading ? '正在上传……' : '上传视频'}
          </button>
          {isUploading && (
            <button type="button" className={styles.cancel} onClick={handleCancel}>
              取消上传
            </button>
          )}
        </div>
        {notice && <p role="status">{notice}</p>}
        {progress !== null && (
          <div>
            <progress className={styles.progress} max={100} value={progress}>
              {progress}%
            </progress>
            <p role="status">
              {/* 文件全部发出去以后，服务器还要一点时间保存，这段时间不算失败 */}
              {progress < 100 ? '已上传 ' + progress + '%' : '已全部发送，正在等待服务器保存……'}
            </p>
          </div>
        )}
        {video && (
          <div>
            <p role="status">上传完成：{video.name}（{formatSize(video.size)}）</p>
            <video className={styles.player} src={video.url} controls />
          </div>
        )}
      </div>
    </main>
  );
}
```

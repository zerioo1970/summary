# 第 119 章：如何把 ref 传给自定义输入组件？

前置：[第 118 章：打开弹窗后，如何自动聚焦第一个输入框？](第118章-打开弹窗后，如何自动聚焦第一个输入框.md)

## 一、本章要解决的问题

新建便签时，标题为空“保存”就不能点，可用户不知道为什么点不了。更好的做法是：允许点“保存”，标题为空时在输入框下面提示“请填写标题。”，并把光标送回标题输入框。

表单中“标签 + 输入框 + 错误提示”这一组，在注册页、登录页、任务页都写过好几遍，值得提取成一个组件 `TextField`。可是提取以后，ref 就要交给 `TextField`，再由它交给里面真正的 `input`，否则拿不到输入框，也就没法调用 `focus()`。

本章写出 `TextField` 组件，让它接收 ref 并交给里面的输入框。完成后：新建便签时只填内容、不填标题就点“保存”，标题输入框变成红色边框，下方显示“请填写标题。”，光标回到标题中；补上标题再保存，便签加入列表；再次打开弹窗时，错误提示已经清除。

## 二、必要原理

### 组件的 ref 要自己交给元素

第 115A 章把 ref 写在 `<input ref={…}>` 上，React 会把这个元素存进 ref。但 `TextField` 是我们自己写的组件，React 并不知道它里面的哪个元素该交给 ref。所以 `TextField` 要像接收其他 props 一样接收 `ref`，再亲手把它写到里面的 `input` 上：

```tsx
export default function TextField({ id, label, value, onChange, error, ref }: TextFieldProps) {
  return (
    …
    <input ref={ref} id={id} … />
    …
  );
}
```

使用它的地方和普通元素一样写：

```tsx
<TextField ref={titleInputRef} id="note-title" label="标题" … />
```

这样，`titleInputRef.current` 拿到的就是 `TextField` 里面的那个 `input`。

在 React 19 中，`ref` 就是一个普通的 prop。以前的版本要用 `forwardRef` 把组件包起来才能接收 `ref`，旧资料中常见这种写法，新代码不再需要。

### ref 的类型：Ref

在 props 类型中，`ref` 写成可选的 `Ref<HTMLInputElement>`：

```tsx
ref?: Ref<HTMLInputElement>;
```

`Ref` 是 React 提供的类型，表示“可以交给元素 `ref` 属性的东西”，尖括号中写最终接收它的元素类型。写成可选，是因为不需要聚焦的地方可以不传。

### TextField 的其他 props

| prop | 作用 |
| --- | --- |
| `id` | 输入框的 `id`，标签的 `htmlFor` 和错误提示的 `id` 都从它生成 |
| `label` | 标签文字 |
| `value`、`onChange` | 受控输入框（第 35 章）；`onChange` 直接交回输入的文字，不需要外面再处理事件对象 |
| `error` | 可选，有内容时显示在输入框下方，并把输入框标为出错（第 43 章） |

`onChange` 的类型是 `(value: string) => void`，所以使用时可以直接写 `onChange={setDraftTitle}`：`setDraftTitle` 正好接收一个字符串。

### 出错时把光标送回输入框

提交时发现标题为空，除了显示错误提示，再调用 `titleInputRef.current.focus()`。用键盘操作的人不用去找出错的输入框，读屏软件也会读出它和下方的错误提示。

## 三、动手实现

### 第 1 步：TextField 的样式

新建 `src/components/TextField.module.css`：

```css
}

  border-color: #c62828;
}

.error {
  margin: 0;
  color: #c62828;
  font-size: 14px;
}
```

### 第 2 步：TextField 组件

新建 `src/components/TextField.tsx`：

```tsx
import type { Ref } from 'react';
import styles from './TextField.module.css';

type TextFieldProps = {
  id: string;
  label: string;
  value: string;
  onChange: (value: string) => void;
  error?: string;
  // React 19 中，ref 和其他 props 一样传进来，再交给里面的 input
  ref?: Ref<HTMLInputElement>;
};

export default function TextField({ id, label, value, onChange, error, ref }: TextFieldProps) {
  const errorId = id + '-error';

  return (
    <div className={styles.field}>
      <label htmlFor={id}>{label}</label>
      <input
        ref={ref}
        id={id}
        value={value}
        onChange={(event) => onChange(event.target.value)}
        aria-invalid={error !== undefined && error !== ''}
        aria-describedby={error ? errorId : undefined}
      />
      {error && (
        <p id={errorId} className={styles.error}>
          {error}
        </p>
      )}
    </div>
  );
}
```

`aria-invalid` 只在真有错误时为 `true`：没传 `error`，或者传了空字符串，都不算出错。

### 第 3 步：便签页使用 TextField

打开 `src/pages/NotesPage.tsx`，在导入 `initialNotes` 的上一行加入：


在 `draftContent` 那一行的下面加入：

```tsx

```

在 `handleOpenCreate` 中清空两个 state 的后面加入：

```tsx

```

在 `handleCreate` 中 `event.preventDefault();` 的下面加入：

```tsx
    if (draftTitle.trim() === '') {
      setTitleError('请填写标题。');

        titleInputRef.current.focus();
      }
      return;
    }
```

把弹窗中标题的 `label` 和 `input` 两部分：

```tsx
            <label htmlFor="note-title">标题</label>
            <input
              ref={titleInputRef}
              id="note-title"
              value={draftTitle}
              onChange={(event) => setDraftTitle(event.target.value)}
            />
```

替换为：

```tsx
            <TextField
              ref={titleInputRef}
              id="note-title"
              label="标题"
              value={draftTitle}
              onChange={setDraftTitle}
              error={titleError}
            />
```

把“保存”按钮改为不再禁用：

```tsx
              <button type="submit">保存</button>
```

`handleOpenCreate` 中聚焦标题的代码不用改：`titleInputRef` 现在经过 `TextField`，拿到的仍然是标题输入框。

### 第 4 步：表单样式只留下多行文本框

打开 `src/pages/NotesPage.module.css`，把 `.form input, .form textarea {` 改为 `.form textarea {`。标题输入框的样式已经由 `TextField.module.css` 负责。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 检查命令报 `Property 'ref' does not exist on type 'IntrinsicAttributes & TextFieldProps'.` | `TextFieldProps` 中没有写 `ref` | 在类型中加上 `ref?: Ref<HTMLInputElement>;` |
| 检查命令提示 `'ref' is declared but its value is never read.`，光标也不会回到输入框 | 组件接收了 `ref`，却没有写到里面的 `input` 上 | 在 `input` 上写 `ref={ref}` |
| 照旧资料写了 `forwardRef`，代码很绕 | 那是 React 18 及以前的写法 | React 19 中直接把 `ref` 当作 prop 接收 |
| 打开新的弹窗，上一次的“请填写标题。”还在 | 打开时没有清空 `titleError` | 在 `handleOpenCreate` 中 `setTitleError('')` |

### `src/pages/NotesPage.tsx`

```tsx
import { useRef, useState } from 'react';
import type { MouseEvent, SubmitEvent } from 'react';
import TextField from '../components/TextField';
import { initialNotes } from '../data/notes';
import styles from './NotesPage.module.css';

export default function NotesPage() {
  const [notes, setNotes] = useState(initialNotes);
  const [viewingId, setViewingId] = useState<number | null>(null);
  const viewDialogRef = useRef<HTMLDialogElement>(null);
  const viewingNote = notes.find((note) => note.id === viewingId);
  const [draftTitle, setDraftTitle] = useState('');
  const [draftContent, setDraftContent] = useState('');
  const [titleError, setTitleError] = useState('');
  const createDialogRef = useRef<HTMLDialogElement>(null);
  const titleInputRef = useRef<HTMLInputElement>(null);

  function handleView(id: number) {
    setViewingId(id);
    if (viewDialogRef.current) {
      viewDialogRef.current.showModal();
    }
  }

  function handleCloseView() {
    if (viewDialogRef.current) {
      viewDialogRef.current.close();
    }
  }

  function handleViewDialogClick(event: MouseEvent<HTMLDialogElement>) {
    // 点在遮罩上时，事件的目标是 dialog 本身；点在内容上时，目标是里面的元素
    if (event.target === event.currentTarget) {
      handleCloseView();
    }
  }

  function handleOpenCreate() {
    setDraftTitle('');
    setDraftContent('');
    setTitleError('');
    if (createDialogRef.current) {
      createDialogRef.current.showModal();
    }
    // 弹窗打开时浏览器会把焦点放在第一个按钮“×”上，这里改放到标题输入框
    if (titleInputRef.current) {
      titleInputRef.current.focus();
    }
  }

  function handleCloseCreate() {
    if (createDialogRef.current) {
      createDialogRef.current.close();
    }
  }

  function handleCreate(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    if (draftTitle.trim() === '') {
      setTitleError('请填写标题。');
      // 把光标送到出错的输入框，用户可以直接补填
      if (titleInputRef.current) {
        titleInputRef.current.focus();
      }
      return;
    }
    const newNote = { id: Date.now(), title: draftTitle.trim(), content: draftContent.trim() };
    setNotes([...notes, newNote]);
    handleCloseCreate();
  }

  return (
    <main className="page">
      <title>便签</title>
      <h1>便签</h1>
      <p>
        <button type="button" onClick={handleOpenCreate}>
          新建便签
        </button>
      </p>
      <ul className={styles.list}>
        {notes.map((note) => (
          <li key={note.id} className={styles.item}>
            <span className={styles.itemTitle}>{note.title}</span>
            <button type="button" onClick={() => handleView(note.id)}>
              查看
            </button>
          </li>
        ))}
      </ul>
      <dialog
        ref={viewDialogRef}
        className={styles.dialog}
        aria-labelledby="view-title"
        onClick={handleViewDialogClick}
      >
        <div className={styles.dialogBody}>
          <h2 id="view-title">{viewingNote ? viewingNote.title : ''}</h2>
          <p className={styles.content}>{viewingNote ? viewingNote.content : ''}</p>
          <button type="button" onClick={handleCloseView}>
            关闭
          </button>
        </div>
      </dialog>
      <dialog ref={createDialogRef} className={styles.dialog} aria-labelledby="create-title">
        <div className={styles.dialogBody}>
          <div className={styles.dialogHeader}>
            <h2 id="create-title">新建便签</h2>
            <button type="button" aria-label="关闭" onClick={handleCloseCreate}>
              ×
            </button>
          </div>
          <form className={styles.form} onSubmit={handleCreate}>
            <TextField
              ref={titleInputRef}
              id="note-title"
              label="标题"
              value={draftTitle}
              onChange={setDraftTitle}
              error={titleError}
            />
            <label htmlFor="note-content">内容</label>
            <textarea
              id="note-content"
              rows={4}
              value={draftContent}
              onChange={(event) => setDraftContent(event.target.value)}
            />
            <div className={styles.actions}>
              <button type="button" onClick={handleCloseCreate}>
                取消
              </button>
              <button type="submit">保存</button>
            </div>
          </form>
        </div>
      </dialog>
    </main>
  );
}
```

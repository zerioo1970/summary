# 第 2 章：如何把一个变量显示在网页中？

前置：[第 1 章：如何用 React 显示一个最简单的个人介绍页？](第001章-如何用React显示一个最简单的个人介绍页.md)

## 一、本章要解决的问题

第 1 章的介绍页里，姓名“小林”直接写在标签中。现在介绍文字里也要出现姓名，例如“我是小林”。如果姓名写死在两个地方，以后改名就要改两处，很容易漏改。

本章把姓名保存到一个变量里，页面上两个位置都读取这个变量。完成后，只改一处变量，页面上两处姓名会同时变化。

## 二、必要原理

### 用 const 保存一个值

```tsx
const name = '小林';
```

`const` 声明一个变量，`name` 是变量名，等号右边是它保存的值。单引号括起来的 `'小林'` 是一段文字，在 JavaScript 中叫字符串。用 `const` 声明的变量不能再被赋予新值，适合保存这种在页面中不会改变的内容。

### 用花括号把变量放进 JSX

在 JSX 中，直接写的文字会原样显示。要显示变量的值，需要用花括号包住变量名：

```tsx
<h2>{name}</h2>
```

React 遇到 `{name}` 时，会取出 `name` 当前的值放到这个位置，页面上显示的是“小林”，而不是“name”这四个字母。

花括号可以和普通文字混在一起，例如 `<p>我是{name}。</p>` 会显示“我是小林。”。

花括号里不只能放变量，也能放一段有结果的表达式，例如 `{name + '同学'}`。本章只用变量，后面的章节会逐步用到其他写法。

## 三、动手实现

### 第 1 步：在组件里声明变量

打开 `src/App.tsx`，在 `return` 的上一行加入变量声明：

```tsx
export default function App() {
  const name = '小林';

  return (
```

变量要写在 `App` 函数内部、`return` 之前。React 每次显示这个组件时都会运行 `App` 函数，先得到 `name` 的值，再生成页面。

### 第 2 步：把写死的姓名换成变量

把 `<h2>` 中的“小林”换成 `{name}`，并在介绍文字中也使用它：

```tsx
      <article>
        <h2>{name}</h2>
        <p>前端开发学习者</p>
        <p>我是{name}，正在用 React 制作自己的第一个页面。</p>
      </article>
```

现在页面上两处姓名都来自同一个变量。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面标题下方显示“小林”，介绍文字显示“我是小林，正在用 React 制作自己的第一个页面。”。
2. 把 `const name = '小林';` 改成你自己的名字，保存。两处姓名应该同时变成新名字。
3. 在浏览器中按 F12 打开开发者工具，在 Elements（元素）面板中找到 `<h2>`，里面显示的是姓名文字，而不是 `{name}`。这说明花括号是在 React 生成页面时就被替换掉了。

最后在项目根目录另开一个终端，运行类型检查，应没有错误输出：

```powershell
npm.cmd run typecheck
```

**小练习**：再声明一个变量 `role`，值为“前端开发学习者”，用它替换第一段 `<p>` 中写死的身份文字。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 页面上显示的是“name”这几个字母 | 忘了写花括号，写成了 `<h2>name</h2>` | 改成 `<h2>{name}</h2>` |
| 页面空白，控制台提示 `name is not defined` | 变量名拼写不一致，例如声明的是 `name`，使用时写成了 `Name` | JavaScript 区分大小写，两处写法要完全一致 |
| 编辑器在 `const` 那一行标红 | 变量声明写到了 `return (` 后面的括号里 | 变量声明放在 `return` 之前 |
| 页面显示“我是{name}” | 把整句写在了引号里，例如 `<p>{'我是{name}'}</p>` | 直接写 `<p>我是{name}，……</p>`，花括号外面的文字不需要引号 |

## 六、本章完整代码

### `src/App.tsx`

```tsx
export default function App() {
  const name = '小林';

  return (
    <main>
      <h1>个人介绍</h1>
      <article>
        <h2>{name}</h2>
        <p>前端开发学习者</p>
        <p>我是{name}，正在用 React 制作自己的第一个页面。</p>
      </article>
    </main>
  );
}
```

修改 `src/App.tsx`：新增变量 `name`，两处姓名改为读取该变量。其他文件不变。

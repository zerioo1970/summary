# 第 43 章：如何让错误提示与对应的输入框关联？

前置：[第 42 章：【组合】如何检查两次输入的密码是否一致？](第042章-如何检查两次输入的密码是否一致.md)

## 一、本章要解决的问题

看得见页面的用户，能看到红色提示就在输入框下方，知道是哪个输入框出了问题。但使用读屏软件的用户，光标进入输入框时只会听到“用户名，编辑框”，并不知道下方有一条错误。红色文字和输入框之间，目前只是“位置上挨着”，程序中并没有任何关联。

本章用两个 `aria` 属性把错误提示和输入框关联起来，并让出错的输入框显示红色边框。完成后，出错的输入框边框变红；读屏软件进入这个输入框时，会读出“无效数据”和错误提示的内容。

## 二、必要原理

### aria-invalid：标明输入无效

`aria-invalid="true"` 告诉辅助工具：这个输入框当前的内容不符合要求。读屏软件读到它时会说“无效数据”或类似的提示。

在 React 中，它的值直接由是否有错误决定：

```tsx
aria-invalid={errors.username !== undefined}
```

有错误时是 `true`，没有错误时是 `false`。

### aria-describedby：指向说明文字

`aria-describedby` 的值是另一个元素的 `id`，意思是“这个元素就是我的补充说明”。读屏软件读完输入框的名称后，会接着读出那个元素的文字：

```tsx
<input aria-describedby="username-error" ... />
<p id="username-error">请填写用户名。</p>
```

光标进入用户名输入框时，读屏软件会读出“用户名，编辑框，无效数据，请填写用户名。”

错误提示只在有错误时才存在。没有错误时，不应该指向一个不存在的 `id`，所以写成：

```tsx
aria-describedby={errors.username ? 'username-error' : undefined}
```

值是 `undefined` 时，React 不会在页面上写这个属性。

### id 要和 label、错误提示对应

本章的每个字段用到三个名字：输入框的 `id`（第 35 章，与 `label` 的 `htmlFor` 对应），错误提示的 `id`，以及 `aria-describedby` 中引用的名字。约定错误提示的 `id` 为“输入框的 id + `-error`”，例如 `confirm-password-error`，一看就知道它属于哪个输入框。

同一个页面中 `id` 不能重复。本章的注册表单在页面上只出现一次，固定的 `id` 没有问题。同一个表单组件在页面上出现多次时怎样处理，见进阶专题。

### 用属性选择器给出错的输入框加红色边框

视觉上也要让出错的输入框更显眼。`aria-invalid` 已经写在元素上了，可以直接用 CSS 的属性选择器选中它：

```css
.field [aria-invalid='true'] {
  border-color: #c62828;
}
```

`[aria-invalid='true']` 选中属性值为 `true` 的元素。样式和辅助信息来自同一个属性，两者总是一致。

## 三、动手实现

### 第 1 步：添加出错时的边框样式

在 `src/pages/RegisterPage.module.css` 末尾加入：

```css
.field [aria-invalid='true'] {
  border-color: #c62828;
}
```

### 第 2 步：给用户名输入框加上关联

打开 `src/pages/RegisterPage.tsx`，在用户名输入框的 `onChange` 下面加入两个属性：

```tsx
            onChange={handleUsernameChange}
            aria-invalid={errors.username !== undefined}
            aria-describedby={errors.username ? 'username-error' : undefined}
```

把用户名的错误提示改为带 `id` 的写法：

```tsx
          {errors.username && (
            <p id="username-error" className={styles.error}>
              {errors.username}
            </p>
          )}
```

### 第 3 步：其余三个字段照此修改

密码、确认密码、学习方向按同样的方式修改：在输入框（或 `select`）上加 `aria-invalid` 和 `aria-describedby`，错误提示加上 `id`。三个错误提示的 `id` 分别是 `password-error`、`confirm-password-error`、`direction-error`。例如学习方向：

```tsx
          <select
            id="direction"
            value={direction}
            onChange={handleDirectionChange}
            aria-invalid={errors.direction !== undefined}
            aria-describedby={errors.direction ? 'direction-error' : undefined}
          >
```

四个字段修改后的完整代码见第六节。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 什么都不填，勾选同意后提交。用户名、密码、确认密码、学习方向四个控件的边框都变成红色，下方显示错误。
2. 按 F12，在 Elements（元素）面板中选中用户名输入框：`aria-invalid="true"`，`aria-describedby="username-error"`，下方的错误段落 `id="username-error"`。
3. 填好用户名再提交：用户名边框恢复，`aria-invalid` 变成 `false`，`aria-describedby` 属性消失。
4. 在 Elements 面板右侧切换到 Accessibility（无障碍）面板，选中出错的用户名输入框，可以看到它的 Description（描述）就是错误提示的文字，Invalid user entry（无效输入）为 true。
5. 如果电脑上有读屏软件（例如 Windows 自带的“讲述人”，按 Ctrl+Win+Enter 开启），提交后用 Tab 进入用户名输入框，会听到错误提示被读出。再按 Ctrl+Win+Enter 关闭。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：用户名下方的字数提示也是对输入框的说明。给它加上 `id="username-hint"`，让 `aria-describedby` 在没有错误时指向它，有错误时同时指向两者（多个 id 之间用空格分隔，例如 `'username-hint username-error'`）。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 无障碍面板中看不到描述 | `aria-describedby` 的值与错误提示的 `id` 不一致 | 两处使用完全相同的名字 |
| 没有错误时，`aria-describedby` 指向了不存在的元素 | 写成了固定值 `aria-describedby="username-error"` | 没有错误时传 `undefined` |
| 出错的输入框没有变红 | CSS 中写成了 `[aria-invalid=true]` 却在别处覆盖，或选择器漏了 `.field` | 按第三节第 1 步书写，并确认属性值是 `true` |
| 两个字段的错误提示读出了同一段文字 | 两个错误提示用了相同的 `id` | 每个错误提示的 `id` 都不同 |
| 编辑器提示 `aria-invalid` 类型不对 | 写成了 `aria-invalid="errors.username"` | 用花括号传入布尔值 |

### `src/pages/RegisterPage.tsx`

```tsx
import { useState } from 'react';
import type { ChangeEvent, SubmitEvent } from 'react';
import styles from './RegisterPage.module.css';

type FormErrors = {
  username?: string;
  password?: string;
  confirmPassword?: string;
  direction?: string;
};

export default function RegisterPage() {
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const [confirmPassword, setConfirmPassword] = useState('');
  const [showPassword, setShowPassword] = useState(false);
  const [direction, setDirection] = useState('');
  const [agree, setAgree] = useState(false);
  const [errors, setErrors] = useState<FormErrors>({});
  const [message, setMessage] = useState('');

  function handleUsernameChange(event: ChangeEvent<HTMLInputElement>) {
    setUsername(event.target.value);
  }

  function handlePasswordChange(event: ChangeEvent<HTMLInputElement>) {
    setPassword(event.target.value);
  }

  function handleConfirmPasswordChange(event: ChangeEvent<HTMLInputElement>) {
    setConfirmPassword(event.target.value);
  }

  function handleDirectionChange(event: ChangeEvent<HTMLSelectElement>) {
    setDirection(event.target.value);
  }

  function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const nextErrors: FormErrors = {};
    if (username.trim() === '') {
      nextErrors.username = '请填写用户名。';
    }
    if (password === '') {
      nextErrors.password = '请填写密码。';
    }
    if (confirmPassword === '') {
      nextErrors.confirmPassword = '请再次输入密码。';
    } else if (confirmPassword !== password) {
      nextErrors.confirmPassword = '两次输入的密码不一致。';
    }
    if (direction === '') {
      nextErrors.direction = '请选择学习方向。';
    }

    setErrors(nextErrors);
    if (Object.keys(nextErrors).length > 0) {
      setMessage('');
      return;
    }
    setMessage('注册成功，欢迎你，' + username.trim() + '！');
  }

  return (
    <main className="page">
      <h1>注册账号</h1>
      <form className={styles.form} onSubmit={handleSubmit}>
        <div className={styles.field}>
          <label htmlFor="username">用户名</label>
          <input
            id="username"
            value={username}
            onChange={handleUsernameChange}
            aria-invalid={errors.username !== undefined}
            aria-describedby={errors.username ? 'username-error' : undefined}
          />
          <p className={styles.hint}>已输入 {username.length} / 12 个字</p>
          {errors.username && (
            <p id="username-error" className={styles.error}>
              {errors.username}
            </p>
          )}
        </div>
        <div className={styles.field}>
          <label htmlFor="password">密码</label>
          <div className={styles.passwordRow}>
            <input
              id="password"
              type={showPassword ? 'text' : 'password'}
              value={password}
              onChange={handlePasswordChange}
              aria-invalid={errors.password !== undefined}
              aria-describedby={errors.password ? 'password-error' : undefined}
            />
            <button type="button" onClick={() => setShowPassword(!showPassword)}>
              {showPassword ? '隐藏密码' : '显示密码'}
            </button>
          </div>
          {errors.password && (
            <p id="password-error" className={styles.error}>
              {errors.password}
            </p>
          )}
        </div>
        <div className={styles.field}>
          <label htmlFor="confirm-password">确认密码</label>
          <input
            id="confirm-password"
            type={showPassword ? 'text' : 'password'}
            value={confirmPassword}
            onChange={handleConfirmPasswordChange}
            aria-invalid={errors.confirmPassword !== undefined}
            aria-describedby={errors.confirmPassword ? 'confirm-password-error' : undefined}
          />
          {errors.confirmPassword && (
            <p id="confirm-password-error" className={styles.error}>
              {errors.confirmPassword}
            </p>
          )}
        </div>
        <div className={styles.field}>
          <label htmlFor="direction">学习方向</label>
          <select
            id="direction"
            value={direction}
            onChange={handleDirectionChange}
            aria-invalid={errors.direction !== undefined}
            aria-describedby={errors.direction ? 'direction-error' : undefined}
          >
            <option value="">请选择</option>
            <option value="frontend">前端开发</option>
            <option value="backend">后端开发</option>
            <option value="design">界面设计</option>
          </select>
          {direction === 'frontend' && <p className={styles.hint}>推荐先学：React 入门</p>}
          {direction === 'backend' && <p className={styles.hint}>推荐先学：Node.js 基础</p>}
          {direction === 'design' && <p className={styles.hint}>推荐先学：网页布局实战</p>}
          {errors.direction && (
            <p id="direction-error" className={styles.error}>
              {errors.direction}
            </p>
          )}
        </div>
        <label className={styles.checkbox}>
          <input
            type="checkbox"
            checked={agree}
            onChange={(event) => setAgree(event.target.checked)}
          />
          我已阅读并同意用户协议
        </label>
        <button type="submit" className={styles.submit} disabled={!agree}>
          注册
        </button>
      </form>
      {message && (
        <p role="status" className={styles.success}>
          {message}
        </p>
      )}
    </main>
  );
}
```

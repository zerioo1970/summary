# 第 19 章：列表为空时，如何显示提示？

前置：[第 18 章：为什么列表中的每一项需要一个稳定的 key？](第018章-为什么列表中的每一项需要一个稳定的key.md)

## 一、本章要解决的问题

新闻数组有时是空的，例如新学期刚开始，还没有发布任何新闻。现在数组为空时，页面上只剩一个“小组新闻”标题，下面什么都没有，用户会以为页面坏了或者还没加载完。

本章在没有新闻时显示一句提示“暂时没有新闻。”，有新闻时照常显示列表。完成后，把数组清空，页面显示提示；恢复数据，列表重新出现。

![空列表前后对比](images/第019章-空列表前后对比.png)

## 二、必要原理

### 根据条件显示两种不同的内容

“有新闻显示列表，没有新闻显示提示”，是在两段 JSX 中选一段显示。JavaScript 的条件运算符（也叫三元运算符）正好做这件事：

```ts
条件 ? 条件成立时的结果 : 条件不成立时的结果
```

例如 `age >= 18 ? '成年' : '未成年'`。

在 JSX 的花括号中可以直接使用它：

```tsx
{newsItems.length === 0 ? (
  <p>暂时没有新闻。</p>
) : (
  <ul>……</ul>
)}
```

- `newsItems.length` 是数组中元素的个数，空数组的 `length` 是 0。
- `===` 判断两边是否相等。
- 两段 JSX 都用圆括号包住，方便写成多行。

为什么不用 `if`？JSX 的花括号里只能放**表达式**（能算出一个值的代码），`if` 是语句，不能放进去。条件运算符是表达式，能算出两段 JSX 中的一段。

### 空状态也是界面的一部分

列表为空时显示什么，叫做“空状态”。好的空状态告诉用户“这里本来应该有内容，现在只是没有”，必要时还会告诉用户下一步可以做什么。实际开发中，几乎每个列表都需要考虑空状态。

## 三、动手实现

### 第 1 步：添加提示的样式

在 `src/pages/NewsPage.module.css` 末尾加入：

```css
.empty {
  color: #52606d;
}
```

### 第 2 步：根据数组是否为空选择显示内容

打开 `src/pages/NewsPage.tsx`，把 `<ul>` 整段放进条件运算符中：

```tsx
      <h1>小组新闻</h1>
      {newsItems.length === 0 ? (
        <p className={styles.empty}>暂时没有新闻。</p>
      ) : (
        <ul className={styles.list}>
          {newsItems.map((item) => (
            <li key={item.id} className={styles.item}>
              <h2>{item.title}</h2>
              <p>{item.summary}</p>
            </li>
          ))}
        </ul>
      )}
```

`<ul>` 及其内容没有变化，只是外面多了一层条件，整体缩进了两格。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 编辑器报语法错误，提示 `if` 不能出现在这里 | 在 JSX 的花括号中写了 `if` 语句 | 改用条件运算符 `条件 ? A : B` |
| 有新闻时也显示了提示 | 条件写反了，例如写成 `newsItems.length > 0 ? 提示 : 列表` | 条件成立时的结果写在 `?` 后面，检查顺序 |
| 写成 `newsItems === []` 后，提示永远不出现 | 两个数组即使内容一样，也不是同一个数组，比较结果永远是 `false` | 用 `newsItems.length === 0` 判断 |
| 报错 `':' expected` | 漏写了冒号后面的部分 | 条件运算符必须同时写出两种结果 |
| 数组为空时页面上还留着一条分隔线 | 空的 `ul` 仍然显示了出来 | 把整个 `ul` 放在条件中，而不是只把 `map` 放进去 |

## 六、本章完整代码

### `src/pages/NewsPage.tsx`

```tsx
import { newsItems } from '../data/news';
import styles from './NewsPage.module.css';

export default function NewsPage() {
  return (
    <main className="page">
      <h1>小组新闻</h1>
      {newsItems.length === 0 ? (
        <p className={styles.empty}>暂时没有新闻。</p>
      ) : (
        <ul className={styles.list}>
          {newsItems.map((item) => (
            <li key={item.id} className={styles.item}>
              <h2>{item.title}</h2>
              <p>{item.summary}</p>
            </li>
          ))}
        </ul>
      )}
    </main>
  );
}
```

### `src/pages/NewsPage.module.css`

```css
.list {
  margin: 0;
  padding: 0;
  list-style: none;
}

.item {
  padding: 12px 0;
  border-bottom: 1px solid #d9e2ec;
}

.item h2 {
  margin: 0 0 4px;
  font-size: 18px;
}

.item p {
  margin: 0;
  color: #52606d;
}

.empty {
  color: #52606d;
}
```

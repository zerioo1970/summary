# 第 115A 章：如何拿到页面上的某个元素，让光标回到输入框？

前置：[第 115 章：登录失效后，如何提示用户重新登录？](第115章-登录失效后，如何提示用户重新登录.md)

## 一、本章要解决的问题

在任务管理页连续添加几条任务：输入名称，点“添加”，再输入下一条……可是点完“添加”以后，光标不在输入框里了，每次都要先用鼠标点一下输入框才能接着输入。

要解决这个问题，就要在添加成功后调用输入框的 `focus()` 方法，让光标回到它上面。这需要先拿到页面上的那个输入框元素。本章学习用 `useRef` 拿到元素。完成后：在任务管理页输入名称并点“添加”，添加成功后光标自动回到“新任务”输入框，可以直接输入下一条。

下一部分要做的弹窗，打开和关闭都要调用弹窗元素的方法，用的也是本章的写法。

## 二、必要原理

### 为什么点完按钮光标就不见了

点击按钮时，**焦点**（focus，表示键盘输入会送到哪个元素）移到了按钮上。添加期间按钮被禁用（第 89 章），被禁用的元素不能拥有焦点，焦点就落到了整个页面上。所以接着打字，什么也输入不进去。

### 有些事只能对元素本身做

到现在为止，页面上的变化都是改 state，React 根据 state 重新画出页面。但“把光标放进某个输入框”不是页面长什么样的问题，而是要对那个输入框执行一个动作：调用它的 `focus()` 方法。浏览器中的每个元素都有这样的方法，例如 `focus()`、第 14 部分弹窗的 `showModal()`。要调用它们，必须先拿到这个元素。

### useRef：一个不会引起重新渲染的盒子

`useRef` 创建一个对象，里面只有一个属性 `current`：

```tsx
const newTaskInputRef = useRef<HTMLInputElement>(null);
```

- 尖括号中写这个盒子将来装什么，这里是输入框 `HTMLInputElement`（第 36 章的事件类型中也用过这个名字）。
- 括号中是初始值 `null`：组件第一次渲染时，输入框还没有出现在页面上。

把它交给元素的 `ref` 属性：

```tsx
<input ref={newTaskInputRef} id="new-task" />
```

React 把这个输入框放到页面上以后，会自动把元素存进 `newTaskInputRef.current`；元素被移除时，再改回 `null`。之后在事件处理函数中就能使用它：

```tsx
if (newTaskInputRef.current) {
  newTaskInputRef.current.focus();
}
```

`current` 的类型是 `HTMLInputElement | null`，所以先判断它不是 `null`，和以前判断 `find` 的结果一样。

### ref 和 state 的区别

ref 和 state 都能在多次渲染之间保存东西，但用途不同：

| | state | ref |
| --- | --- | --- |
| 修改后 | 组件重新渲染，页面随之变化 | 什么也不发生，页面不会变 |
| 适合保存 | 要显示在页面上的数据 | 页面上的元素，以及不需要显示的东西 |

所以要显示的数据仍然放进 state。ref 主要用来拿到元素，调用它的方法。

### 什么时候能用 ref.current

`ref.current` 要等元素出现在页面上以后才有值。在组件函数的渲染过程中直接读它，第一次渲染时还是 `null`。所以使用它的地方一般是事件处理函数，或者 Effect 中，那时元素早已在页面上了。

## 三、动手实现

### 第 1 步：创建 ref

打开 `src/pages/TaskServerPage.tsx`，把第一行的导入改为：

```tsx
import { useEffect, useRef, useState } from 'react';
```

在 `draft` 那一行的下面加入：

```tsx
  // 指向“新任务”输入框，添加成功后用它把光标放回去
  const newTaskInputRef = useRef<HTMLInputElement>(null);
```

### 第 2 步：把 ref 交给输入框

在“新任务”的 `<input` 下面、`id="new-task"` 的上面加一行：

```tsx
          ref={newTaskInputRef}
```

### 第 3 步：添加成功后把光标放回输入框

在 `handleAdd` 中，添加成功后更新列表的一行下面加入：

```tsx
      if (newTaskInputRef.current) {
        newTaskInputRef.current.focus();
      }
```

只在添加成功时这样做。名称为空或服务器拒绝时，光标留在原处，用户可以先看错误提示。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 检查命令报 `'newTaskInputRef.current' is possibly 'null'.` | 直接调用了 `newTaskInputRef.current.focus()` | 先判断 `if (newTaskInputRef.current)` |
| 检查命令报 `Expected 1 arguments, but got 0.` | 写成了 `useRef<HTMLInputElement>()`，没有给初始值 | 写成 `useRef<HTMLInputElement>(null)` |
| 添加成功后光标仍然不在输入框中 | 创建了 ref，但没有写到输入框的 `ref` 属性上，`current` 一直是 `null` | 在 `<input>` 上写 `ref={newTaskInputRef}` |
| 想用 ref 保存一个数字并显示在页面上，改了以后页面不变 | 修改 `ref.current` 不会让组件重新渲染 | 要显示的数据用 state |

## 六、本章完整代码

### `src/pages/TaskServerPage.tsx`

```tsx
import { useEffect, useRef, useState } from 'react';
import type { SubmitEvent } from 'react';
import TaskEditor from '../components/TaskEditor';
import { createTask, deleteTask, fetchTasks, updateTask } from '../lib/taskApi';
import type { Task } from '../types/task';
import styles from './TaskPage.module.css';

type LoadState =
  | { status: 'loading'; tasks: Task[] }
  | { status: 'success'; tasks: Task[] }
  | { status: 'error'; message: string; tasks: Task[] };

function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '操作失败，请稍后重试。';
}

export default function TaskServerPage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'loading', tasks: [] });
  const [draft, setDraft] = useState('');
  // 指向“新任务”输入框，添加成功后用它把光标放回去
  const newTaskInputRef = useRef<HTMLInputElement>(null);
  const [titleError, setTitleError] = useState('');
  const [saveError, setSaveError] = useState('');
  const [isAdding, setIsAdding] = useState(false);
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editError, setEditError] = useState('');
  const [isSavingEdit, setIsSavingEdit] = useState(false);
  const tasks = loadState.tasks;
  const editingTask = tasks.find((task) => task.id === editingId);

  useEffect(() => {
    let ignore = false;

    async function loadOnOpen() {
      try {
        const data = await fetchTasks();
        if (!ignore) {
          setLoadState({ status: 'success', tasks: data });
        }
      } catch (error) {
        if (!ignore) {
          setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
        }
      }
    }

    loadOnOpen();
    return () => {
      ignore = true;
    };
  }, []);

  async function handleRetry() {
    setLoadState({ status: 'loading', tasks: [] });
    try {
      const data = await fetchTasks();
      setLoadState({ status: 'success', tasks: data });
    } catch (error) {
      setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
    }
  }

  async function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      setTitleError('请填写任务名称。');
      return;
    }
    setTitleError('');
    setSaveError('');
    setIsAdding(true);
    try {
      const result = await createTask({ title });
      if (result.status === 'invalid') {
        setTitleError(result.titleError);
        return;
      }
      setDraft('');
      setLoadState((current) => ({ ...current, tasks: [...current.tasks, result.task] }));
      if (newTaskInputRef.current) {
        newTaskInputRef.current.focus();
      }
    } catch (error) {
      setSaveError(getErrorMessage(error) + '输入的内容已保留。');
    } finally {
      setIsAdding(false);
    }
  }

  function handleStartEdit(id: string) {
    setEditingId(id);
    setEditError('');
  }

  async function handleSaveEdit(id: string, title: string) {
    setEditError('');
    setIsSavingEdit(true);
    try {
      const result = await updateTask(id, { title });
      if (result.status === 'invalid') {
        setEditError(result.titleError);
        return;
      }
      setEditingId(null);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.map((task) => (task.id === id ? result.task : task)),
      }));
    } catch (error) {
      setEditError(getErrorMessage(error));
    } finally {
      setIsSavingEdit(false);
    }
  }

  async function handleDelete(id: string, title: string) {
    // 删除后无法恢复，先让用户确认；点“取消”时什么也不做
    if (!window.confirm('确定要删除“' + title + '”吗？删除后无法恢复。')) {
      return;
    }
    if (id === editingId) {
      setEditingId(null);
    }
    setSaveError('');
    try {
      await deleteTask(id);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.filter((task) => task.id !== id),
      }));
    } catch (error) {
      setSaveError(getErrorMessage(error));
    }
  }

  return (
    <main className="page">
      <h1>任务管理</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input
          ref={newTaskInputRef}
          id="new-task"
          value={draft}
          onChange={(event) => setDraft(event.target.value)}
          aria-invalid={titleError !== ''}
          aria-describedby={titleError ? 'new-task-error' : undefined}
        />
        <button type="submit" disabled={isAdding}>
          {isAdding ? '正在添加……' : '添加'}
        </button>
      </form>
      {titleError && (
        <p id="new-task-error" className={styles.error}>
          {titleError}
        </p>
      )}
      {saveError && <p role="alert">{saveError}</p>}
      {loadState.status === 'loading' && <p role="status">正在读取任务……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleRetry}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' && tasks.length === 0 && (
        <p className={styles.empty}>还没有任务。</p>
      )}
      {tasks.length > 0 && (
        <ul className={styles.list}>
          {tasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <span className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                {task.title}
              </span>
              <button
                type="button"
                onClick={() => handleStartEdit(task.id)}
                disabled={isSavingEdit}
              >
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id, task.title)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingTask && (
        <TaskEditor
          key={editingTask.id}
          task={editingTask}
          onSave={(title) => handleSaveEdit(editingTask.id, title)}
          onCancel={() => setEditingId(null)}
          saving={isSavingEdit}
          error={editError}
        />
      )}
    </main>
  );
}
```

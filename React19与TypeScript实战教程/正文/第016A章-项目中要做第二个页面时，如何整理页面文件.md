# 第 16A 章：项目中要做第二个页面时，如何整理页面文件？

前置：[第 16 章：如何让同一个卡片容器放入不同内容？](第016章-如何让同一个卡片容器放入不同内容.md)

## 一、本章要解决的问题

到第 16 章为止，学习小组页的全部内容都写在 `src/App.tsx` 里。下一章开始做一个新页面：新闻列表。如果直接把 `App.tsx` 改成新闻页，学习小组页就没了；如果把两个页面都塞进 `App.tsx`，这个文件会越来越长，也分不清哪段代码属于哪个页面。

本章不增加新功能，只整理文件：把学习小组页移到单独的文件 `src/pages/GroupPage.tsx` 中，`App.tsx` 只负责决定“现在显示哪个页面”。完成后，浏览器中的页面和第 16 章完全一样，但项目已经准备好容纳更多页面。

## 二、必要原理

### 页面放进 pages 文件夹

按照本教程的约定：

- `src/components` 放可以在多个页面中重复使用的组件，例如 `ProfileCard`、`Card`；
- `src/pages` 放页面，每个页面一个文件，例如学习小组页 `GroupPage.tsx`、下一章的新闻页 `NewsPage.tsx`；
- `src/App.tsx` 只显示**当前正在练习的那个页面**。

页面本身也是组件，写法和 `ProfileCard` 没有区别，只是它负责一整页的内容。第 94 章学习路由后，再把所有页面用链接连起来，在浏览器中切换。

### 移动文件后，导入路径要跟着改

导入语句中以 `./` 或 `../` 开头的路径，是**相对于当前文件所在文件夹**来写的：

- `.` 表示当前文件所在的文件夹；
- `..` 表示上一级文件夹。

`App.tsx` 在 `src` 中，所以 `'./assets/avatar-lin.svg'` 指的是 `src/assets/avatar-lin.svg`。代码移到 `src/pages/GroupPage.tsx` 后，当前文件夹变成了 `src/pages`，同样写 `./assets/...` 就会去找 `src/pages/assets`，那里没有这个文件。要先用 `..` 回到上一级 `src`，再进入 `assets`，写成 `'../assets/avatar-lin.svg'`。

```text
src
├─ App.tsx              （从这里出发：./assets/...）
├─ assets
│  └─ avatar-lin.svg
├─ components
│  └─ ProfileCard.tsx
└─ pages
   └─ GroupPage.tsx     （从这里出发：../assets/...）
```

### 全站样式留在 App 中

`App.css` 中的 `.page`、`.card-list` 等是所有页面都要用的样式，仍然由 `App.tsx` 导入。CSS 文件一旦被导入，它的样式对整个页面生效，所以 `GroupPage` 中照样可以使用这些类名。

## 三、动手实现

### 第 1 步：新建学习小组页

在 `src` 中新建 `pages` 文件夹，在其中新建 `GroupPage.tsx`。把 `App.tsx` 中除第一行 `import './App.css';` 以外的全部内容复制过来，然后做两处调整：

- 函数名 `App` 改为 `GroupPage`；
- 所有导入路径中的 `./` 改为 `../`。

改好后的完整内容如下：

```tsx
import avatarLin from '../assets/avatar-lin.svg';
import avatarWang from '../assets/avatar-wang.svg';
import avatarChen from '../assets/avatar-chen.svg';
import Card from '../components/Card';
import ProfileCard from '../components/ProfileCard';
import PageHeader from '../components/PageHeader';
import PageFooter from '../components/PageFooter';
import type { Profile } from '../components/ProfileCard';

export default function GroupPage() {
  const lin: Profile = {
    name: '小林',
    role: '前端开发学习者',
    intro: '正在用 React 制作自己的第一个页面。',
    avatar: avatarLin,
  };
  const wang: Profile = {
    name: '小王',
    role: '后端转前端的学习者',
    intro: '正在学习怎样把数据显示到页面上。',
    avatar: avatarWang,
  };
  const chen: Profile = {
    name: '小陈',
    role: '设计转前端的学习者',
    intro: '正在练习把设计稿做成网页。',
    avatar: avatarChen,
  };

  return (
    <main className="page">
      <PageHeader title="前端学习小组" description="我们每周一起完成一个 React 小练习。" />
      <Card>
        <h2>本周练习</h2>
        <p>周六上午十点，一起用 Flex 布局完成一个卡片列表。</p>
      </Card>
      <section className="card-list">
        <ProfileCard profile={lin} note="欢迎一起交流 React！" />
        <ProfileCard profile={wang} />
        <ProfileCard profile={chen} note="作品集：https://example.com/xiaochen/ReactDailyPracticePortfolioAndNotes2026" />
      </section>
      <PageFooter email="study-group@example.com" />
    </main>
  );
}
```

和 `App.tsx` 对照，只有导入路径和函数名不同，其余一行都没有变。

### 第 2 步：让 App 只显示当前页面

把 `src/App.tsx` 改为：

```tsx
import './App.css';
import GroupPage from './pages/GroupPage';

export default function App() {
  return <GroupPage />;
}
```

`App.tsx` 还在 `src` 中，所以导入 `GroupPage` 的路径是 `./pages/GroupPage`。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面和第 16 章完全相同：标题、本周练习、三张成员卡片、页脚都在，头像正常显示。
2. 打开开发者工具的 Elements（元素）面板，页面结构和原来一样，看不出页面是从哪个文件来的。React 只关心组件，不关心组件写在哪个文件里。
3. 打开控制台，没有红色错误。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：在 `GroupPage.tsx` 中，把其中一个头像的路径临时改回 `'./assets/avatar-lin.svg'`，保存，看看页面上的错误层和 `check` 分别提示了什么。读完后改回。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 页面出现错误层，提示找不到 `./assets/avatar-lin.svg` 或 `./components/Card` | `GroupPage.tsx` 中还有导入路径没有改成 `../` | 逐行检查导入语句，`./` 都改为 `../` |
| 页面出现错误层，提示找不到 `./pages/GroupPage` | 文件放错了位置或名字拼错 | 文件路径应是 `src/pages/GroupPage.tsx` |
| 页面内容都在，但没有页面边距，卡片也不再并排 | 把 `import './App.css';` 也移进了 `GroupPage.tsx`，又在 `App.tsx` 中删掉了 | 全站样式在 `App.tsx` 中导入，`GroupPage.tsx` 不需要这一行 |

# 第 105 章：如何让商品列表和购物车使用同一份数据？

前置：[第 104 章：如何根据商品数量计算总价？](第104章-如何根据商品数量计算总价.md)

## 一、本章要解决的问题

`ShopPage.tsx` 已经有一百多行：商品列表、已选商品、小计、合计全写在一个组件里，想改其中一块都要先找半天。按第 11 章的方法，应该把左右两块拆成两个组件：`ProductList` 显示商品，`CartPanel` 显示已选商品。

可是拆开以后有一个问题：两个组件都要用到购物车的数据。`CartPanel` 要显示已选商品，`ProductList` 也要知道每件商品已经选了几件，才能在达到库存时把按钮变成“已达库存”。点击左边的“加入购物车”，右边要立刻多出一行。

本章把两块拆成组件，购物车的 state 留在它们共同的父组件 `ShopPage` 中，通过 props 传给两个组件。完成后，页面的外观和行为与第 104 章完全一样，`ShopPage.tsx` 只剩三十多行。

## 二、必要原理

### state 放在共同的父组件中

两个并排的组件（叫**兄弟组件**）要用同一份数据时，数据不能放在其中任何一个里面：放在 `ProductList` 中，`CartPanel` 拿不到；两边各放一份，就成了两份互不相干的购物车。

办法是把 state 放在它们**共同的父组件**中，再用 props 分别传下去：

```text
ShopPage            cartItems 的 state 在这里
├── ProductList     props：cartItems、onAdd
└── CartPanel       props：cartItems、onChangeQuantity
```

这种做法叫**状态提升**：把 state 提到需要它的几个组件上方最近的那一层。

数据从父组件往下传，用的是 props（第 9 章）；子组件要修改数据时，调用父组件传来的函数，例如 `onAdd(product.id)`，这是第 31 章“子组件通知父组件”的写法。真正修改 state 的 `handleAdd`、`handleChangeQuantity` 仍然在 `ShopPage` 中。

点击左边的“加入购物车”时：`ProductList` 调用 `onAdd`，`ShopPage` 中的 `cartItems` 更新，`ShopPage` 重新渲染，两个子组件都拿到新的 `cartItems`，左右两边同时变化。

### 回调函数的类型

`onAdd` 是一个函数，它的类型写法是“参数列表 => 返回值类型”：

```tsx
type ProductListProps = {
  cartItems: CartItem[];
  onAdd: (productId: number) => void;
};
```

`(productId: number) => void` 表示“接收一个数字参数、不返回值的函数”，`void` 就是“没有返回值”。第 31 章写过 `onToggle: () => void`，那是不接收参数的函数。

### 共用的类型和样式

`CartItem` 类型现在三个文件都要用，移到 `src/types/cart.ts`（第 67 章）。

两个组件的列表样式相同，放进一个共用的 `src/components/ShopList.module.css`，两个组件都导入它（第 85 章）。`ShopPage.module.css` 只留下左右排列的 `.layout`。

### 合计跟着已选商品走

总件数和合计只在已选商品中显示，所以这段计算从 `ShopPage` 移到 `CartPanel` 中。它仍然是现算的值，只是换了一个组件来算。

## 三、动手实现

### 第 1 步：新建购物车类型文件

新建 `src/types/cart.ts`：

```ts
// 购物车只记商品编号和数量，名称、价格用编号到商品数据中查，不重复保存
export type CartItem = {
  productId: number;
  quantity: number;
};
```

### 第 2 步：新建共用的列表样式

新建 `src/components/ShopList.module.css`，把 `src/pages/ShopPage.module.css` 中从 `.list` 开始到文件末尾的规则全部剪切过来。剪切后，`ShopPage.module.css` 中只剩 `.layout` 和 `.layout > section` 两条规则。两个文件的完整内容见第六节。

### 第 3 步：新建商品列表组件

新建 `src/components/ProductList.tsx`：

```tsx
import { products } from '../data/products';
import { formatPrice } from '../lib/format';
import type { CartItem } from '../types/cart';
import styles from './ShopList.module.css';

type ProductListProps = {
  cartItems: CartItem[];
  onAdd: (productId: number) => void;
};

export default function ProductList({ cartItems, onAdd }: ProductListProps) {
  return (
    <section>
      <h2>商品</h2>
      <ul className={styles.list}>
        {products.map((product) => {
          const cartItem = cartItems.find((item) => item.productId === product.id);
          const quantity = cartItem ? cartItem.quantity : 0;
          let buttonText = '加入购物车';
          if (product.stock === 0) {
            buttonText = '缺货';
          } else if (quantity >= product.stock) {
            buttonText = '已达库存';
          }
          return (
            <li key={product.id} className={styles.row}>
              <span className={styles.name}>{product.name}</span>
              <span className={styles.price}>{formatPrice(product.price)}</span>
              <button
                type="button"
                disabled={quantity >= product.stock}
                onClick={() => onAdd(product.id)}
              >
                {buttonText}
              </button>
            </li>
          );
        })}
      </ul>
    </section>
  );
}
```

内容从 `ShopPage` 左边那块原样搬过来，只有一处不同：点击按钮时调用的是 props 中的 `onAdd`，不是 `handleAdd`。

### 第 4 步：新建已选商品组件

新建 `src/components/CartPanel.tsx`：

```tsx
import { products } from '../data/products';
import { formatPrice } from '../lib/format';
import type { CartItem } from '../types/cart';
import styles from './ShopList.module.css';

type CartPanelProps = {
  cartItems: CartItem[];
  onChangeQuantity: (productId: number, change: number) => void;
};

export default function CartPanel({ cartItems, onChangeQuantity }: CartPanelProps) {
  let totalQuantity = 0;
  let totalPrice = 0;
  for (const item of cartItems) {
    const product = products.find((candidate) => candidate.id === item.productId);
    if (product) {
      totalQuantity += item.quantity;
      totalPrice += product.price * item.quantity;
    }
  }

  return (
    <section>
      <h2>已选商品</h2>
      {cartItems.length === 0 ? (
        <p className={styles.empty}>购物车是空的。</p>
      ) : (
        <ul className={styles.list}>
          {cartItems.map((item) => {
            const product = products.find((candidate) => candidate.id === item.productId);
            if (!product) {
              return null;
            }
            return (
              <li key={item.productId} className={styles.row}>
                <span className={styles.name}>{product.name}</span>
                <button
                  type="button"
                  aria-label={'减少一件：' + product.name}
                  disabled={item.quantity <= 1}
                  onClick={() => onChangeQuantity(item.productId, -1)}
                >
                  −
                </button>
                <span className={styles.quantity}>{item.quantity}</span>
                <button
                  type="button"
                  aria-label={'增加一件：' + product.name}
                  disabled={item.quantity >= product.stock}
                  onClick={() => onChangeQuantity(item.productId, 1)}
                >
                  +
                </button>
                <span className={styles.subtotal}>
                  {formatPrice(product.price * item.quantity)}
                </span>
              </li>
            );
          })}
        </ul>
      )}
      {cartItems.length > 0 && (
        <p className={styles.total}>
          共 {totalQuantity} 件，合计 {formatPrice(totalPrice)}
        </p>
      )}
    </section>
  );
}
```

### 第 5 步：ShopPage 只保留 state 和组合

把 `src/pages/ShopPage.tsx` 改为：

```tsx
import { useState } from 'react';
import CartPanel from '../components/CartPanel';
import ProductList from '../components/ProductList';
import type { CartItem } from '../types/cart';
import styles from './ShopPage.module.css';

export default function ShopPage() {
  // 商品列表和已选商品都要用到购物车，所以 state 放在它们共同的父组件中
  const [cartItems, setCartItems] = useState<CartItem[]>([]);

  function handleAdd(productId: number) {
    const existing = cartItems.find((item) => item.productId === productId);
    if (existing) {
      setCartItems(
        cartItems.map((item) =>
          item.productId === productId ? { ...item, quantity: item.quantity + 1 } : item,
        ),
      );
    } else {
      setCartItems([...cartItems, { productId, quantity: 1 }]);
    }
  }

  // change 是 1 或 -1：加一件或减一件
  function handleChangeQuantity(productId: number, change: number) {
    setCartItems(
      cartItems.map((item) =>
        item.productId === productId ? { ...item, quantity: item.quantity + change } : item,
      ),
    );
  }

  return (
    <main className="page">
      <h1>购物车</h1>
      <div className={styles.layout}>
        <ProductList cartItems={cartItems} onAdd={handleAdd} />
        <CartPanel cartItems={cartItems} onChangeQuantity={handleChangeQuantity} />
      </div>
    </main>
  );
}
```

`ShopPage` 不再导入 `products` 和 `formatPrice`，也不再计算合计，这些都交给了两个子组件。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 左边加入后，右边的已选商品没有变化 | 两个子组件各自写了 `useState`，成了两份互不相干的数据 | 只在 `ShopPage` 中保留一份 state，通过 props 传给两个子组件 |
| 检查命令报 `Property 'onAdd' is missing in type '{ cartItems: CartItem[]; }' but required in type 'ProductListProps'.` | 使用 `ProductList` 时忘了传 `onAdd` | 写成 `<ProductList cartItems={cartItems} onAdd={handleAdd} />` |
| 检查命令报 `Expected 0 arguments, but got 1.` | `onAdd` 的类型写成了 `() => void`，调用时却传了商品编号 | 类型写成 `(productId: number) => void` |
| 拆分后列表没有样式 | 组件中导入的样式文件路径不对，或者规则没有剪切到 `ShopList.module.css` 中 | 两个组件都导入 `./ShopList.module.css`，对照第六节检查文件内容 |

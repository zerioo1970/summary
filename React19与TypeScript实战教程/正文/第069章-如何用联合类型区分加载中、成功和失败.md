# 第 69 章：如何用联合类型区分加载中、成功和失败？

前置：[第 68 章：为什么写了类型声明，仍然需要检查接口数据？](第068章-为什么写了类型声明，仍然需要检查接口数据.md)

## 一、本章要解决的问题

文章页现在用三个 state 描述请求：`articles`、`error`、`isLoading`。它们之间有约定：加载时不该有错误，失败时不该显示“加载中”……但这些约定只存在于我们脑子里。在某个函数中漏改一个，页面就会同时显示“正在加载”和错误提示，或者在出错后还显示着旧的文章。

还有一种情况现在区分不出来：接口成功返回了空数组。页面上什么都没有，用户分不清是“还没加载”还是“确实没有文章”。

本章把三个 state 合成一个，用联合类型写明请求只可能处于四种状态之一：还没开始、加载中、成功、失败。不可能出现的组合，从类型上就写不出来。成功但没有文章时，显示“暂时还没有文章。”。

## 二、必要原理

### 一次请求只会处于一种状态

列出页面实际可能的样子：

| 状态 | 页面显示 | 需要的数据 |
| --- | --- | --- |
| 还没开始 | 只有按钮 | 无 |
| 加载中 | 加载提示 | 无 |
| 成功 | 文章列表，或“暂时还没有文章” | 文章数组 |
| 失败 | 错误提示和“重试” | 错误信息 |

三个独立的 state 能组合出 2×2×2 种以上的情况，其中大部分是不应该出现的。真正需要的只有这四种。

### 用联合类型描述四种状态

第 29 章（让多个问题中同时只展开一个）用过 `number | null`：一个值可以是几种类型之一。联合类型的每一种也可以是对象：

```tsx
type LoadState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; articles: Article[] }
  | { status: 'error'; message: string };
```

每种状态都有一个 `status` 字段，值是固定的字符串，用来区分“是哪一种”。只有成功状态带着文章，只有失败状态带着错误信息。第一行开头的 `|` 只是为了排版整齐，可以不写。

state 只剩一个：

```tsx
const [loadState, setLoadState] = useState<LoadState>({ status: 'idle' });
```

### 先判断 status，再使用对应的数据

直接写 `loadState.articles` 会报错，因为 `loadState` 可能是失败状态，那里没有 `articles`。先判断 `status`：

```tsx
{loadState.status === 'success' && <ArticleList articles={loadState.articles} />}
```

在 `&&` 后面，TypeScript 已经知道 `loadState` 是成功状态，可以读取 `articles`。这叫类型的**收窄**，和第 68 章类型守卫通过后 `data` 变成 `Article[]` 是同一个道理。

### 每次都设置一个完整的状态

更新时一次给出整个新状态，例如 `setLoadState({ status: 'error', message: '……' })`。不需要再记得“清空错误”“关闭加载”，因为新状态中本来就没有这些东西。`finally` 也不再需要：每条路径最后都会设置成功或失败状态，“加载中”自然就结束了。

## 三、动手实现

### 第 1 步：定义状态类型，替换三个 state

在 `src/pages/ArticlePage.tsx` 中，在导入的下面、组件的上面加入：

```tsx
type LoadState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; articles: Article[] }
  | { status: 'error'; message: string };
```

把 `articles`、`error`、`isLoading` 三个 state 删除，换成：

```tsx
  const [loadState, setLoadState] = useState<LoadState>({ status: 'idle' });
```

### 第 2 步：改写请求函数

把 `handleLoad` 整个替换为：

```tsx
  async function handleLoad() {
    setLoadState({ status: 'loading' });
    try {
      const response = await fetch('http://127.0.0.1:3001/api/articles');
      if (!response.ok) {
        setLoadState({
          status: 'error',
          message: '文章读取失败：服务器返回了状态 ' + response.status + '。',
        });
        return;
      }
      const data: unknown = await response.json();
      if (!Array.isArray(data) || !data.every(isArticle)) {
        setLoadState({ status: 'error', message: '文章数据格式不正确，暂时无法显示。' });
        return;
      }
      setLoadState({ status: 'success', articles: data });
    } catch {
      setLoadState({ status: 'error', message: '无法连接练习服务，请确认它已经启动。' });
    }
  }
```

### 第 3 步：按状态显示页面

把 `<h1>` 下面的按钮、加载提示、错误提示和 `ArticleList` 替换为：

```tsx
      <button type="button" onClick={handleLoad} disabled={loadState.status === 'loading'}>
        加载文章
      </button>
      {loadState.status === 'loading' && <p role="status">正在加载文章……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleLoad}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' &&
        (loadState.articles.length === 0 ? (
          <p>暂时还没有文章。</p>
        ) : (
          <ArticleList articles={loadState.articles} />
        ))}
```

成功时再用第 19 章（列表为空时显示提示）的写法区分有没有文章。

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。

1. 打开页面只有“加载文章”按钮；点击后显示加载提示，然后显示 4 篇文章。
2. 停止练习服务，点击“加载文章”：文章列表消失，显示“无法连接练习服务”和“重试”。失败状态中没有文章，所以不会再显示旧的列表。
3. 启动练习服务，点击“重试”，文章重新出现。
4. 地址临时加上 `?mode=empty`，显示“暂时还没有文章。”；加上 `?mode=bad`，显示格式错误提示。看完后去掉。
5. 在 React 开发者工具中查看 `ArticlePage`，只有一个 state，展开能看到 `status` 和对应的数据。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：试着写 `setLoadState({ status: 'success' })`（不带文章）或 `setLoadState({ status: 'loading', message: '' })`，运行 `npm.cmd run check`，读一读 TypeScript 的提示。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 编辑器提示 `LoadState` 上不存在属性 `articles` | 没有先判断 `loadState.status === 'success'` 就读取了 `articles` | 先判断状态，再读取对应的数据 |
| 编辑器提示 `"sucess"` 不能赋给 `"success"` | 状态名拼错了 | 联合类型的好处：拼错会被检查出来，照提示改正 |
| 编辑器提示这个比较没有意义，两种类型没有重叠 | 判断写成了 `loadState.status === 'loaded'`，类型中没有这种状态 | 状态名和类型中的写法保持一致 |
| 编辑器在 `setLoadState` 处提示对象只能指定已知的属性 | 写成了 `useState({ status: 'idle' })`，没有写 `<LoadState>`，TypeScript 以为状态中只有 `status` | 写明类型：`useState<LoadState>({ status: 'idle' })` |
| 学完本章后，页面一直报错、一直显示空数据或加载很慢 | 步骤中临时加在请求地址上的 `?mode=`、`?fail=`、`?delay=`、`?cors=` 等参数忘了删 | 运行 `git diff` 查看本章改动，删掉地址中的临时参数 |

## 六、本章完整代码

### `src/pages/ArticlePage.tsx`

```tsx
import { useState } from 'react';
import ArticleList from '../components/ArticleList';
import { isArticle } from '../types/article';
import type { Article } from '../types/article';

type LoadState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; articles: Article[] }
  | { status: 'error'; message: string };

export default function ArticlePage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'idle' });

  async function handleLoad() {
    setLoadState({ status: 'loading' });
    try {
      const response = await fetch('http://127.0.0.1:3001/api/articles');
      if (!response.ok) {
        setLoadState({
          status: 'error',
          message: '文章读取失败：服务器返回了状态 ' + response.status + '。',
        });
        return;
      }
      const data: unknown = await response.json();
      if (!Array.isArray(data) || !data.every(isArticle)) {
        setLoadState({ status: 'error', message: '文章数据格式不正确，暂时无法显示。' });
        return;
      }
      setLoadState({ status: 'success', articles: data });
    } catch {
      setLoadState({ status: 'error', message: '无法连接练习服务，请确认它已经启动。' });
    }
  }

  return (
    <main className="page">
      <h1>文章列表</h1>
      <button type="button" onClick={handleLoad} disabled={loadState.status === 'loading'}>
        加载文章
      </button>
      {loadState.status === 'loading' && <p role="status">正在加载文章……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleLoad}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' &&
        (loadState.articles.length === 0 ? (
          <p>暂时还没有文章。</p>
        ) : (
          <ArticleList articles={loadState.articles} />
        ))}
    </main>
  );
}
```

## 七、本章改动小结

修改 `src/pages/ArticlePage.tsx`：用一个 `LoadState` 联合类型的 state 代替原来的三个 state，加入“暂时还没有文章”的提示。

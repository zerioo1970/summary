# 第 123 章：设置变化后，如何自动保存到本地存储？

前置：[第 122 章：刷新页面后，如何恢复上次保存的设置？](第122章-刷新页面后，如何恢复上次保存的设置.md)

## 一、本章要解决的问题

上一章的设置要点“保存设置”才会保存。用户改了字号，看到预览满意了，常常直接离开页面，忘了点保存，下次打开又是原来的样子。像称呼、字号这样的个人偏好，大多数应用都是改了就自动生效、自动保存的。

本章去掉“保存设置”按钮，让设置一变化就自动写进本地存储。完成后：输入称呼、切换字号以后，不用点任何按钮，刷新页面设置都还在；页面上的提示改为“修改后会自动保存，刷新页面后仍然有效。”。

## 二、必要原理

### 保存是“跟着 state 走”的事

“设置变了就保存”可以理解为：让本地存储中的内容，始终和 `settings` 这个 state 保持一致。本地存储不属于 React，它是页面之外的东西。让外面的东西跟着 state 变化，正是 Effect 的用途（第 74 章）：

```tsx
useEffect(() => {
  saveSettings(settings);
}, [settings]);
```

依赖数组是 `[settings]`（第 76 章）：每次渲染后，React 比较 `settings` 和上一次是否相同，变了才执行，把新的设置写进去。

不论设置是从输入框改的、单选按钮改的，还是以后从别的地方改的，都会经过这一个 Effect，不会漏掉。这比在每个 `onChange` 中都调用一次 `saveSettings` 更可靠。

### 打开页面时也会保存一次

Effect 在第一次显示后也会执行，这时保存的就是刚刚读出来的设置。如果之前没有保存过，本地存储中会多出一份默认设置。这不影响结果：下次读出来的仍然是同样的值。

### 每次改动都写一次可以吗

输入称呼时每打一个字，设置就变一次，本地存储就写一次。本地存储的读写很快，这么小的数据写几十次也感觉不到。如果要保存的内容很大，或者保存要发请求到服务器，就应该像第 77 章那样，等用户停止输入后再保存。

### 不再需要的代码

自动保存以后，“保存设置”按钮、`saved` 这个 state 和 `updateSettings` 函数都不需要了：输入框和单选按钮直接调用 `setSettings`。

## 三、动手实现

### 第 1 步：导入 useEffect，删掉 saved

打开 `src/pages/SettingsPage.tsx`，把第一行改为：

```tsx
import { useEffect, useState } from 'react';
```

删掉 `const [saved, setSaved] = useState(false);` 这一行。

### 第 2 步：用 Effect 自动保存

把 `updateSettings` 和 `handleSave` 两个函数替换为：

```tsx
  // settings 每次变化都保存一次，用户不需要再点按钮
  useEffect(() => {
    saveSettings(settings);
  }, [settings]);
```

把 JSX 中三处 `updateSettings(` 都改为 `setSettings(`。

### 第 3 步：去掉按钮，改成提示

把“保存设置”按钮和“已保存”的提示这两段：

```tsx
        <div>
          <button type="button" onClick={handleSave}>
            保存设置
          </button>
        </div>
        {saved && (
          <p role="status" className={styles.saved}>
            设置已保存，刷新页面后仍然有效。
          </p>
        )}
```

替换为：

```tsx
        <p className={styles.hint}>修改后会自动保存，刷新页面后仍然有效。</p>
```

### 第 4 步：提示的样式

打开 `src/pages/SettingsPage.module.css`，把最后的 `.saved` 规则改为：

```css
.hint {
  margin: 0;
  color: #52606d;
}
```

它现在是一句说明，用灰色，不再用表示“成功”的绿色。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 打开 Application（应用）面板，删掉上一章留下的 `react-daily-practice.settings`，然后刷新设置页。本地存储中马上出现这一项，值是默认设置 `{"nickname":"","fontSize":"normal"}`。
2. 在称呼中输入“小”，本地存储中的值立刻变成 `{"nickname":"小","fontSize":"normal"}`；再输入“林”，变成“小林”。（如果面板中的值没有刷新，点面板上方的刷新图标。）
3. 选择“较大”，值中的 `fontSize` 变成 `"large"`。
4. 按 F5 刷新，称呼是“小林”，字号是“较大”。页面上没有“保存设置”按钮。
5. 关掉标签页，重新打开 `http://127.0.0.1:5173/settings`，设置仍然在。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：在设置页底部显示“上次保存：HH:MM:SS”，每次自动保存后更新这个时间。提示：在 Effect 中保存之后，不能直接调用 `setState`（那会让 Effect 每次都多引起一次渲染）；可以想一想，这个时间能不能在修改设置的地方记录。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 检查命令提示 `React Hook useEffect has a missing dependency: 'settings'`，修改后刷新，设置没有保存 | 依赖数组写成了 `[]`，Effect 只在打开页面时执行一次 | 写成 `[settings]` |
| 刷新后设置总是回到默认值 | 保存用的是 Effect，但 state 的初始值没有从本地存储读取，打开页面时 Effect 把默认值写了进去 | 初始值仍然用 `useState(loadSettings)`（第 122 章） |
| 把 `saveSettings(settings)` 直接写在组件函数中，没有放进 Effect | 组件函数的每次执行都应该只计算界面，保存属于页面之外的操作 | 放进 `useEffect`，按依赖数组决定何时执行 |

## 六、本章完整代码

### `src/pages/SettingsPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import { loadSettings, saveSettings } from '../lib/settings';
import type { Settings } from '../lib/settings';
import styles from './SettingsPage.module.css';

export default function SettingsPage() {
  // 传入函数而不是调用结果：只在第一次渲染时读取一次本地存储
  const [settings, setSettings] = useState<Settings>(loadSettings);
  const previewClass =
    settings.fontSize === 'large' ? styles.preview + ' ' + styles.large : styles.preview;
  const displayName = settings.nickname.trim() === '' ? '朋友' : settings.nickname.trim();

  // settings 每次变化都保存一次，用户不需要再点按钮
  useEffect(() => {
    saveSettings(settings);
  }, [settings]);

  return (
    <main className="page">
      <title>个人设置</title>
      <h1>个人设置</h1>
      <div className={styles.form}>
        <div className={styles.field}>
          <label htmlFor="nickname">称呼</label>
          <input
            id="nickname"
            value={settings.nickname}
            onChange={(event) => setSettings({ ...settings, nickname: event.target.value })}
          />
        </div>
        <fieldset className={styles.options}>
          <legend>字号</legend>
          <label>
            <input
              type="radio"
              name="fontSize"
              checked={settings.fontSize === 'normal'}
              onChange={() => setSettings({ ...settings, fontSize: 'normal' })}
            />
            标准
          </label>
          <label>
            <input
              type="radio"
              name="fontSize"
              checked={settings.fontSize === 'large'}
              onChange={() => setSettings({ ...settings, fontSize: 'large' })}
            />
            较大
          </label>
        </fieldset>
        <div className={previewClass}>你好，{displayName}！这是预览文字。</div>
        <p className={styles.hint}>修改后会自动保存，刷新页面后仍然有效。</p>
      </div>
    </main>
  );
}
```

# 第 113 章：登录成功后，如何回到原来要访问的页面？

前置：[第 112 章：未登录访问个人页面时，如何跳转到登录页？](第112章-未登录访问个人页面时，如何跳转到登录页.md)

## 一、本章要解决的问题

没有登录时打开“我的账号”，会被带到登录页。登录成功后，页面只显示一句“登录成功”，用户还得自己再去点一次“我的账号”。如果他是从同事发来的链接打开的，还要回去重新找那个链接。

本章让登录页记住“用户原来要去哪里”，登录成功后直接送他过去。完成后：没有登录时打开 `/account`，登录成功后自动回到“我的账号”；直接打开登录页登录，成功后回到首页；登录完成后按“后退”，不会回到登录页。

## 二、必要原理

### 跳转时顺便带上一份数据

`Navigate` 和 `navigate` 都可以在跳转时带一份数据，写在 `state` 中：

```tsx
<Navigate to="/login" replace state={{ from: '/account' }} />
```

这份数据不显示在地址栏里，只跟着这一次跳转交给新页面。新页面用 `useLocation()` 取出当前的位置信息，其中的 `state` 就是它：

```tsx
const location = useLocation();
location.state; // { from: '/account' }
```

`useLocation` 返回的对象还有 `pathname`（路径，例如 `/account`）和 `search`（问号及后面的查询参数，例如 `?q=书`）。守卫中用它们拼出原来要去的完整地址。

### 在代码中跳转：useNavigate

登录成功是在点击按钮、等待请求之后发生的，不是在渲染时，所以不用 `Navigate` 组件，而是用 `useNavigate` 得到一个跳转函数：

```tsx
const navigate = useNavigate();

navigate('/account', { replace: true });
```

第一个参数是地址；`replace: true` 用目标页面替换登录页这条历史记录。这样在“我的账号”页按“后退”，会回到打开登录页之前的页面，不会又回到登录页。

上一章说过，渲染过程中不能调用 `navigate`；在事件处理函数中，包括 `await` 之后，都可以调用。

### state 中可能是任何东西

直接打开 `/login` 时，没有人带数据过来，`location.state` 是 `null`。其他页面也可能用 `state` 带别的数据过来。所以读取前要检查：是对象、有 `from`、`from` 是字符串，才使用它，否则回到首页 `/`。这和第 68 章检查接口数据是同一个道理：不是自己能保证的数据，用之前先检查。

### 登录成功后不再显示提示

登录成功就跳走了，原来的“登录成功，欢迎你……”没有机会被看到，连同 `message` 这个 state 一起删掉。导航栏中出现的用户名，已经说明登录成功了。

## 三、动手实现

### 第 1 步：守卫跳转时带上原来的地址

打开 `src/components/RequireAuth.tsx`，把导入改为：

```tsx
import { Navigate, useLocation } from 'react-router';
```

在 `const { user, checking } = useAuth();` 的下面加入：

```tsx
  const location = useLocation();
```

把跳转到登录页的一行改为：

```tsx
    // 把原来要去的地址交给登录页，登录成功后再回来
    const from = location.pathname + location.search;
    return <Navigate to="/login" replace state={{ from }} />;
```

`{ from }` 是 `{ from: from }` 的简写（第 93A 章）。

### 第 2 步：登录页读取地址并跳转

打开 `src/pages/LoginPage.tsx`，把导入 `Link` 的一行改为：

```tsx
import { Link, useLocation, useNavigate } from 'react-router';
```

在 `getErrorMessage` 函数的上面加入：

```tsx
// 跳转时带来的 state 可能是任何内容，确认是字符串地址才使用
function getRedirectPath(state: unknown) {
  if (typeof state === 'object' && state !== null && 'from' in state) {
    if (typeof state.from === 'string') {
      return state.from;
    }
  }
  return '/';
}
```

在组件中 `const { setUser } = useAuth();` 的下面加入：

```tsx
  const location = useLocation();
  const navigate = useNavigate();
```

把登录成功后的三行：

```tsx
      setPassword('');
      setUser(result.user);
      setMessage('登录成功，欢迎你，' + result.user.displayName + '！');
```

改为：

```tsx
      setUser(result.user);
      navigate(getRedirectPath(location.state), { replace: true });
```

### 第 3 步：删掉成功提示

在 `LoginPage.tsx` 中删掉以下三处：

- `const [message, setMessage] = useState('');` 这一行；
- `handleSubmit` 中的 `setMessage('');`；
- JSX 中显示 `message` 的 `{message && (……)}` 这一段。

打开 `src/pages/LoginPage.module.css`，删掉最后的 `.success` 规则，它已经用不到了。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 直接打开登录页登录时，登录框下面显示 `Cannot read properties of null (reading 'from')` | 直接使用了 `location.state.from`，直接打开登录页时 `state` 是 `null` | 用 `getRedirectPath` 检查后再使用，没有时回到首页 |
| 登录后回到“我的账号”，按“后退”又回到了登录页 | `navigate` 没有写 `{ replace: true }` | 加上 `{ replace: true }` |
| 登录后回到了商品目录，但搜索条件没了 | 守卫中只记录了 `location.pathname`，没有加上 `location.search` | 记录 `location.pathname + location.search` |
| 从“我的账号”被带去登录，登录后却回到了首页 | 守卫的 `Navigate` 没有写 `state`，或者登录页读取的名字和守卫中写的不一致 | 两边都用 `from` 这个名字 |

## 六、本章完整代码

### `src/components/RequireAuth.tsx`

```tsx
import type { ReactNode } from 'react';
import { Navigate, useLocation } from 'react-router';
import { useAuth } from '../hooks/useAuth';

type RequireAuthProps = {
  children: ReactNode;
};

export default function RequireAuth({ children }: RequireAuthProps) {
  const { user, checking } = useAuth();
  const location = useLocation();

  // 还不知道是否登录时先等一等，否则刷新页面时已登录的用户也会被送去登录页
  if (checking) {
    return <p className="page">正在确认登录状态……</p>;
  }
  if (!user) {
    // 把原来要去的地址交给登录页，登录成功后再回来
    const from = location.pathname + location.search;
    return <Navigate to="/login" replace state={{ from }} />;
  }
  return children;
}
```

### `src/pages/LoginPage.tsx`

```tsx
import { useState } from 'react';
import type { SubmitEvent } from 'react';
import { Link, useLocation, useNavigate } from 'react-router';
import { useAuth } from '../hooks/useAuth';
import { login } from '../lib/authApi';
import styles from './LoginPage.module.css';

// 跳转时带来的 state 可能是任何内容，确认是字符串地址才使用
function getRedirectPath(state: unknown) {
  if (typeof state === 'object' && state !== null && 'from' in state) {
    if (typeof state.from === 'string') {
      return state.from;
    }
  }
  return '/';
}

function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '登录失败，请稍后重试。';
}

export default function LoginPage() {
  const { setUser } = useAuth();
  const location = useLocation();
  const navigate = useNavigate();
  const [username, setUsername] = useState('');
  const [password, setPassword] = useState('');
  const [isSubmitting, setIsSubmitting] = useState(false);
  const [error, setError] = useState('');

  async function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    if (username.trim() === '' || password === '') {
      setError('请填写用户名和密码。');
      return;
    }
    setError('');
    setIsSubmitting(true);
    try {
      const result = await login(username.trim(), password);
      if (result.status === 'failed') {
        setError(result.message);
        return;
      }
      setUser(result.user);
      navigate(getRedirectPath(location.state), { replace: true });
    } catch (caught) {
      setError(getErrorMessage(caught));
    } finally {
      setIsSubmitting(false);
    }
  }

  return (
    <main className={styles.page}>
      <title>登录</title>
      <h1>登录</h1>
      <form className={styles.form} onSubmit={handleSubmit}>
        <div className={styles.field}>
          <label htmlFor="login-username">用户名</label>
          <input
            id="login-username"
            autoComplete="username"
            value={username}
            onChange={(event) => setUsername(event.target.value)}
          />
        </div>
        <div className={styles.field}>
          <label htmlFor="login-password">密码</label>
          <input
            id="login-password"
            type="password"
            autoComplete="current-password"
            value={password}
            onChange={(event) => setPassword(event.target.value)}
          />
        </div>
        {error && (
          <p role="alert" className={styles.error}>
            {error}
          </p>
        )}
        <button type="submit" disabled={isSubmitting}>
          {isSubmitting ? '正在登录……' : '登录'}
        </button>
      </form>
      <p>
        <Link to="/">返回首页</Link>
      </p>
    </main>
  );
}
```

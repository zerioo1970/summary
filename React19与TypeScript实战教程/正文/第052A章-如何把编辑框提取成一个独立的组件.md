# 第 52A 章：如何把编辑框提取成一个独立的组件？

前置：[第 52 章：【组合】如何让编辑框在点击“取消”后恢复原来的内容？](第052章-如何让编辑框在点击“取消”后恢复原来的内容.md)

## 一、本章要解决的问题

`TaskPage` 越来越长：添加、删除、筛选、编辑都写在里面，编辑框的草稿、输入、保存、取消又占了一大段。读代码时很难一眼看出哪几行属于编辑框。

本章把编辑框提取成一个独立的 `TaskEditor` 组件，草稿由它自己管理，`TaskPage` 只负责告诉它“编辑哪一条”，并在保存和取消时得到通知。完成后，页面的外观和操作与第 52 章完全相同，`TaskPage` 变短了。

## 二、必要原理

### 草稿交给编辑框组件自己管理

草稿只有编辑框用，可以放进 `TaskEditor` 中，用任务名称作为初始值：

```tsx
const [draft, setDraft] = useState(task.title);
```

`TaskPage` 只需要知道正在编辑哪一条，通过 props 把任务传进去，再用第 31 章的方法，让编辑框在保存和取消时通知父组件：`onSave(title)` 和 `onCancel()`。

要传进去的任务，可以用第 51 章介绍的 `find` 从 `tasks` 中找出来：

```tsx
const editingTask = tasks.find((task) => task.id === editingId);
```

没有在编辑时，`editingId` 是 `null`，找不到任务，结果是 `undefined`，`{editingTask && ...}` 就不显示编辑框。

### 提取组件时，页面应该没有任何变化

提取组件是**整理代码**，不是增加功能。做完以后，页面的外观和每一个操作都应该和提取前一样。检查时就按第 52 章的步骤再操作一遍：编辑、保存、取消、清空后不能保存。

### 第 2 步：新建编辑框组件

在 `src/components` 中新建 `TaskEditor.tsx`：

```tsx
import { useState } from 'react';
import type { ChangeEvent, SubmitEvent } from 'react';
import type { Task } from '../data/tasks';
import styles from './TaskEditor.module.css';

type TaskEditorProps = {
  task: Task;
  onSave: (title: string) => void;
  onCancel: () => void;
};

export default function TaskEditor({ task, onSave, onCancel }: TaskEditorProps) {
  const [draft, setDraft] = useState(task.title);

  function handleDraftChange(event: ChangeEvent<HTMLInputElement>) {
    setDraft(event.target.value);
  }

  function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      return;
    }
    onSave(title);
  }

  return (
    <form className={styles.editor} onSubmit={handleSubmit}>
      <label htmlFor="edit-task">修改任务名称</label>
      <input id="edit-task" value={draft} onChange={handleDraftChange} />
      <button type="submit" disabled={draft.trim() === ''}>
        保存
      </button>
      <button type="button" onClick={onCancel}>
        取消
      </button>
    </form>
  );
}
```

内容就是原来 `TaskPage` 中编辑框的那部分，`editDraft` 改名为 `draft`，保存和取消改为调用父组件传来的函数。

### 第 3 步：让 TaskPage 使用编辑框组件

在 `src/pages/TaskPage.tsx` 中：

1. 在顶部加入 `import TaskEditor from '../components/TaskEditor';`。
2. 删除 `editDraft` 这个 state，以及 `handleStartEdit`、`handleEditDraftChange` 两个函数。
3. 在 `remainingCount` 的下面加入 `editingTask`，并把 `handleSaveEdit` 改为接收新名称：

```tsx
  const editingTask = tasks.find((task) => task.id === editingId);
```

```tsx
  function handleSaveEdit(title: string) {
    setTasks(tasks.map((task) => (task.id === editingId ? { ...task, title } : task)));
    setEditingId(null);
  }
```

4. 编辑按钮改为直接记下 `id`：

```tsx
              <button type="button" onClick={() => setEditingId(task.id)}>
```

5. 把整个 `{editingId !== null && (<form …>……</form>)}` 替换为：

```tsx
      {editingTask && (
        <TaskEditor
          task={editingTask}
          onSave={handleSaveEdit}
          onCancel={() => setEditingId(null)}
        />
      )}
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 点击一条任务的“编辑”，编辑框出现，里面是这条任务的名称。
2. 修改名称并保存，列表中的名称随之改变，编辑框关闭。
3. 再打开编辑框，修改几个字后点击“取消”，名称没有变化；重新打开，编辑框中是原来的名称。
4. 清空编辑框，“保存”按钮不能点击。
5. 外观与第 52 章相同，编辑框的边框、间距都还在。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**留给下一章的问题**：编辑框开着时，不关闭它，直接点击另一条任务的“编辑”。你会发现编辑框中还是上一条任务的名称。这是提取组件后才出现的新问题，下一章专门解决。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 编辑器提示 `editingTask` 可能为 `undefined` | 没有先判断就把它传给了 `task` | 用 `{editingTask && (...)}` 包起来 |
| 编辑框没有样式 | 只删了 `TaskPage.module.css` 中的样式，没有新建 `TaskEditor.module.css`，或 import 的路径写错 | 新建样式文件，并检查 `import styles from './TaskEditor.module.css'` |
| 添加任务的输入框变窄了 | 合并样式时把 `.addForm input` 也删掉了 | 保留 `.addForm input {` 那一段，只去掉 `.editor input` |
| 点击“保存”后什么都没变 | `handleSaveEdit` 还在读取已经删除的 `editDraft` | 改为使用参数 `title` |

### `src/pages/TaskPage.tsx`

```tsx
import { useState } from 'react';
import type { ChangeEvent, SubmitEvent } from 'react';
import TaskEditor from '../components/TaskEditor';
import { initialTasks } from '../data/tasks';
import type { Task } from '../data/tasks';
import styles from './TaskPage.module.css';

export default function TaskPage() {
  const [tasks, setTasks] = useState<Task[]>(initialTasks);
  const [newTitle, setNewTitle] = useState('');
  const [editingId, setEditingId] = useState<string | null>(null);
  const [hideCompleted, setHideCompleted] = useState(false);
  const visibleTasks = hideCompleted ? tasks.filter((task) => !task.completed) : tasks;
  const remainingCount = tasks.filter((task) => !task.completed).length;
  const editingTask = tasks.find((task) => task.id === editingId);

  function handleNewTitleChange(event: ChangeEvent<HTMLInputElement>) {
    setNewTitle(event.target.value);
  }

  function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = newTitle.trim();
    if (title === '') {
      return;
    }
    const newTask: Task = { id: crypto.randomUUID(), title, completed: false };
    setTasks([...tasks, newTask]);
    setNewTitle('');
  }

  function handleDelete(id: string) {
    setTasks(tasks.filter((task) => task.id !== id));
    if (id === editingId) {
      setEditingId(null);
    }
  }

  function handleToggle(id: string) {
    setTasks(
      tasks.map((task) => (task.id === id ? { ...task, completed: !task.completed } : task)),
    );
  }

  function handleSaveEdit(title: string) {
    setTasks(tasks.map((task) => (task.id === editingId ? { ...task, title } : task)));
    setEditingId(null);
  }

  return (
    <main className="page">
      <h1>待办事项</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input id="new-task" value={newTitle} onChange={handleNewTitleChange} />
        <button type="submit" disabled={newTitle.trim() === ''}>
          添加
        </button>
      </form>
      <div className={styles.toolbar}>
        <span>{remainingCount === 0 ? '全部完成了！' : '还有 ' + remainingCount + ' 项未完成'}</span>
        <label>
          <input
            type="checkbox"
            checked={hideCompleted}
            onChange={(event) => setHideCompleted(event.target.checked)}
          />
          只看未完成
        </label>
      </div>
      {visibleTasks.length === 0 ? (
        <p className={styles.empty}>没有需要显示的任务。</p>
      ) : (
        <ul className={styles.list}>
          {visibleTasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <label className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                <input
                  type="checkbox"
                  checked={task.completed}
                  onChange={() => handleToggle(task.id)}
                />
                {task.title}
              </label>
              <button type="button" onClick={() => setEditingId(task.id)}>
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingTask && (
        <TaskEditor
          task={editingTask}
          onSave={handleSaveEdit}
          onCancel={() => setEditingId(null)}
        />
      )}
    </main>
  );
}
```

# 第 17 章：如何把一个数组显示成列表？

前置：[第 16A 章：项目中要做第二个页面时，如何整理页面文件？](第016A章-项目中要做第二个页面时，如何整理页面文件.md)

## 一、本章要解决的问题

从本章开始做一个新页面：学习小组的新闻列表。新闻有好几条，每条都有标题和摘要。第 1、2 部分的成员卡片是一张一张手写出来的，新闻却可能有几十条，而且数量会变化，不可能每条都手写一次。

本章把新闻保存在一个数组中，用一段代码把数组中的每一条都显示出来。完成后，页面显示“小组新闻”标题和三条新闻；在数组中增加一条，页面自动多出一条。

本章是第 3 部分的起点。学完第 3 部分（第 17—23 章）时，新闻页会变成下图的样子：新闻分为两个栏目，带有置顶标签、发布日期，没有摘要的新闻显示默认文字。

## 二、必要原理

### 数组：按顺序保存一组数据

数组用方括号表示，元素之间用逗号分隔。数组的元素也可以是对象：

```ts
const newsItems = [
  { id: 1, title: '……', summary: '……' },
  { id: 2, title: '……', summary: '……' },
];
```

TypeScript 中，“由 `NewsItem` 组成的数组”写作 `NewsItem[]`。

### map：把每个元素转换成一段 JSX

数组的 `map` 方法会依次处理数组中的每个元素，把处理结果组成一个新数组：

```ts
[1, 2, 3].map((n) => n * 10); // 得到 [10, 20, 30]
```

`(n) => n * 10` 是一个箭头函数：括号中的 `n` 是当前元素，箭头后面是要返回的结果。`map` 对每个元素调用一次这个函数。

在 React 中，可以把每条数据转换成一段 JSX：

```tsx
{newsItems.map((item) => (
  <li key={item.id}>{item.title}</li>
))}
```

得到的是一个由多个 `<li>` 组成的数组。JSX 的花括号中放一个元素数组，React 会把它们依次显示出来。箭头后面用圆括号包住多行 JSX，表示直接返回这段 JSX。

### key：每一项的身份证

上面的 `<li>` 写了 `key={item.id}`。用 `map` 生成列表时，React 要求每一项都有一个 `key`，并且同一个列表中不能重复，用来区分“这一项是哪一条数据”。数据中的 `id` 正好满足要求。为什么需要它、为什么不能随便写，第 18 章专门讲。本章先照写。

### 数据单独放在一个文件中

新闻数据和页面代码分开，放在 `src/data/news.ts` 中。`.ts` 文件里没有 JSX，只保存数据和类型。页面组件导入后使用。以后数据改为从服务器读取（第 62 章起），只需要换掉数据来源，页面的显示代码基本不用改。

## 三、动手实现

### 第 1 步：准备新闻数据

在 `src` 中新建 `data` 文件夹，在其中新建 `news.ts`：

```ts
export type NewsItem = {
  id: number;
  title: string;
  summary: string;
};

export const newsItems: NewsItem[] = [
  { id: 1, title: '学习小组本周开始新的练习', summary: '本周练习用数组生成新闻列表。' },
  { id: 2, title: '图书角新增三本前端书籍', summary: '欢迎在周末借阅。' },
  { id: 3, title: '下周六举行代码分享会', summary: '每位成员分享一个自己写的组件。' },
];
```

这里用 `export const` 导出数据（没有 `default`），导入时要用花括号写出名字。一个文件可以有多个这样的导出。

### 第 2 步：新建新闻页

在 `src/pages` 中新建 `NewsPage.module.css`：

```css
.list {
  margin: 0;
  padding: 0;
  list-style: none;
}

.item {
  padding: 12px 0;
  border-bottom: 1px solid #d9e2ec;
}

.item h2 {
  margin: 0 0 4px;
  font-size: 18px;
}

.item p {
  margin: 0;
  color: #52606d;
}
```

`.list` 去掉列表默认的圆点和缩进，`.item` 在每条新闻下方画一条分隔线。

再新建 `NewsPage.tsx`：

```tsx
import { newsItems } from '../data/news';
import styles from './NewsPage.module.css';

export default function NewsPage() {
  return (
    <main className="page">
      <h1>小组新闻</h1>
      <ul className={styles.list}>
        {newsItems.map((item) => (
          <li key={item.id} className={styles.item}>
            <h2>{item.title}</h2>
            <p>{item.summary}</p>
          </li>
        ))}
      </ul>
    </main>
  );
}
```

### 第 3 步：让 App 显示新闻页

把 `src/App.tsx` 改为：

```tsx
import './App.css';
import NewsPage from './pages/NewsPage';

export default function App() {
  return <NewsPage />;
}
```

和第 16A 章一样，`App` 只负责显示当前正在练习的页面，现在换成了新闻页。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面显示“小组新闻”标题，下面是三条新闻，每条有加粗的标题和灰色的摘要，之间有分隔线。
2. 在 `news.ts` 的数组末尾加一条 `{ id: 4, title: '新成员加入', summary: '欢迎小赵。' },`，保存，页面上多出第四条。检查后删掉。
3. 把 `App.tsx` 中的 `NewsPage` 临时换回 `GroupPage`（导入路径为 `./pages/GroupPage`），学习小组页与第 16 章完全相同。检查后换回 `NewsPage`。
4. 打开控制台（F12，Console 面板），没有红色错误或黄色警告。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：把 `map` 中的 `key={item.id}` 临时删掉，保存，看看控制台出现了什么警告，再运行 `check`，看 oxlint 报告了哪条规则。读完后恢复。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 编辑器提示 `news.ts` 没有默认导出 | 写成了 `import newsItems from '../data/news'` | 有名字的导出要用花括号：`import { newsItems } from ...` |
| 页面上什么新闻都没有，也没有报错 | 箭头后面用了花括号 `{ <li>...</li> }` 却没写 `return` | 用圆括号包住 JSX：`(item) => (<li>...</li>)` |
| 控制台警告 `Each child in a list should have a unique "key" prop` | `li` 上没有写 `key` | 写 `key={item.id}` |
| 新闻页没有页面边距 | 删掉了 `App.tsx` 中的 `import './App.css'` | 全站样式仍在 `App` 中导入 |

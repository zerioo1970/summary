# 第 79 章：如何取消已经不再需要的请求？

前置：[第 78 章：为什么先发出的请求，可能覆盖后发出的搜索结果？](第078章-为什么先发出的请求，可能覆盖后发出的搜索结果.md)

## 一、本章要解决的问题

上一章看到，`ignore` 能保证晚回来的旧结果不被显示。但旧请求本身并没有停下来：浏览器仍在等它，网络仍在传输它的数据，最后才被丢掉。搜索的结果很大、网络很慢的时候，这些用不上的请求会占着网络，拖慢真正需要的那一个。

本章在关键词变化时直接**取消**上一次的请求。在 Network（网络）面板中，被取消的请求会显示为 `(canceled)`。

## 二、必要原理

### AbortController：取消请求的开关

浏览器提供的 `AbortController` 用来取消请求：

```tsx
const controller = new AbortController();
fetch(url, { signal: controller.signal });
// ……
controller.abort();
```

- 创建一个 `AbortController`，把它的 `signal` 通过 `fetch` 的第二个参数交给请求，两者就连在一起了。
- 调用 `controller.abort()`，浏览器立即停止这个请求。

请求被取消后，正在等待的 `await fetch(...)`（或者正在读取正文的 `await response.json()`）会抛出错误，程序进入 `catch`。

### 在清理函数中取消

和 `ignore` 一样，每执行一次 Effect，就创建一个新的 `AbortController`，清理函数中调用 `abort()`：

```tsx
useEffect(() => {
  const controller = new AbortController();
  // ……用 controller.signal 发请求
  return () => {
    controller.abort();
  };
}, [debouncedKeyword]);
```

关键词变化时，上一次的清理函数取消上一次的请求；StrictMode 多执行一次时，第一次的请求也会被取消。

### 被取消的请求不是“失败”

请求被取消后会进入 `catch`。这不是真的出错，而是我们主动放弃了它，不应该显示错误提示。`controller.signal.aborted` 在调用过 `abort()` 之后为 `true`，在 `catch` 中先检查它，是取消的就直接 `return`。

请求被取消后，`fetchSearchResults` 中的代码不会继续往下执行，也就不会再调用 `setSearchState` 显示结果。所以成功的那一行不再需要检查，`ignore` 变量可以去掉了：`controller.signal.aborted` 起到了同样的作用。

### 把 signal 传给请求函数

请求是在 `fetchSearchResults` 中发出的，所以给它加一个参数 `signal`，类型是 `AbortSignal`，再传给 `fetch`：

```tsx
fetch(url, { signal })
```

`{ signal }` 是 `{ signal: signal }` 的简写。

## 三、动手实现

### 第 1 步：请求函数接收 signal

在 `src/pages/SearchPage.tsx` 中，把 `fetchSearchResults` 的第一行和发送请求的一行改为：

```tsx
async function fetchSearchResults(query: string, signal: AbortSignal): Promise<Article[]> {
```

```tsx
    response = await fetch(apiUrl('/search?q=' + encodeURIComponent(query)), { signal });
```

### 第 2 步：搜索的 Effect 改用 AbortController

把搜索 Effect 中从 `let ignore = false;` 到清理函数结束的部分替换为：

```tsx
    const controller = new AbortController();

    async function search() {
      try {
        const items = await fetchSearchResults(query, controller.signal);
        setSearchState({ status: 'success', items });
      } catch (error) {
        if (controller.signal.aborted) {
          return;
        }
        const message = error instanceof Error ? error.message : '搜索失败。';
        setSearchState({ status: 'error', message });
      }
    }

    search();
    return () => {
      controller.abort();
    };
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 快速改关键词时，页面闪过“无法连接练习服务” | 被取消的请求进入了 `catch`，被当成了失败 | `catch` 中先检查 `controller.signal.aborted` |
| Network 中旧请求没有显示 `(canceled)` | 创建了 `AbortController`，但没有把 `signal` 传给 `fetch` | `fetch(url, { signal })` |
| 所有请求一发出就被取消 | `controller.abort()` 写在了 Effect 的函数体中，而不是清理函数中 | 只在返回的清理函数中调用 |
| 编辑器提示 `fetchSearchResults` 缺少参数 | 给函数加了 `signal` 参数，调用处没有传 | 调用时传入 `controller.signal` |

## 六、本章完整代码

### `src/pages/SearchPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { ChangeEvent } from 'react';
import ArticleList from '../components/ArticleList';
import { apiUrl } from '../lib/api';
import { isArticle } from '../types/article';
import type { Article } from '../types/article';
import styles from './SearchPage.module.css';

type SearchState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; items: Article[] }
  | { status: 'error'; message: string };

async function fetchSearchResults(query: string, signal: AbortSignal): Promise<Article[]> {
  let response: Response;
  try {
    response = await fetch(apiUrl('/search?q=' + encodeURIComponent(query)), { signal });
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
  if (!response.ok) {
    throw new Error('搜索失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (
    typeof data !== 'object' ||
    data === null ||
    !('items' in data) ||
    !Array.isArray(data.items) ||
    !data.items.every(isArticle)
  ) {
    throw new Error('搜索结果格式不正确，暂时无法显示。');
  }
  return data.items;
}

export default function SearchPage() {
  const [keyword, setKeyword] = useState('');
  const [debouncedKeyword, setDebouncedKeyword] = useState('');
  const [searchState, setSearchState] = useState<SearchState>({ status: 'idle' });

  useEffect(() => {
    const timerId = setTimeout(() => {
      setDebouncedKeyword(keyword);
    }, 500);
    return () => {
      clearTimeout(timerId);
    };
  }, [keyword]);

  useEffect(() => {
    const query = debouncedKeyword.trim();
    if (query === '') {
      setSearchState({ status: 'idle' });
      return;
    }
    setSearchState({ status: 'loading' });
    const controller = new AbortController();

    async function search() {
      try {
        const items = await fetchSearchResults(query, controller.signal);
        setSearchState({ status: 'success', items });
      } catch (error) {
        if (controller.signal.aborted) {
          return;
        }
        const message = error instanceof Error ? error.message : '搜索失败。';
        setSearchState({ status: 'error', message });
      }
    }

    search();
    return () => {
      controller.abort();
    };
  }, [debouncedKeyword]);

  function handleKeywordChange(event: ChangeEvent<HTMLInputElement>) {
    setKeyword(event.target.value);
  }

  return (
    <main className="page">
      <h1>搜索文章</h1>
      <div className={styles.searchBox}>
        <label htmlFor="search-keyword">关键词</label>
        <input
          id="search-keyword"
          type="search"
          value={keyword}
          onChange={handleKeywordChange}
        />
      </div>
      {searchState.status === 'idle' && <p className={styles.hint}>输入关键词，搜索文章标题。</p>}
      {searchState.status === 'loading' && <p role="status">正在搜索……</p>}
      {searchState.status === 'error' && <p role="alert">{searchState.message}</p>}
      {searchState.status === 'success' &&
        (searchState.items.length === 0 ? (
          <p className={styles.hint}>没有找到相关文章。</p>
        ) : (
          <ArticleList articles={searchState.items} />
        ))}
    </main>
  );
}
```

修改 `src/pages/SearchPage.tsx`：用 `AbortController` 在关键词变化时取消上一次的搜索请求，去掉 `ignore`。

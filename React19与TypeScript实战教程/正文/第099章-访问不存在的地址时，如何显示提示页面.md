# 第 99 章：访问不存在的地址时，如何显示提示页面？

前置：[第 98 章：如何让多个页面共用顶部导航？](第098章-如何让多个页面共用顶部导航.md)

## 一、本章要解决的问题

在地址栏输入 `/abc`，或者打开一个已经失效的旧链接，页面上只有导航栏，下面一片空白，控制台里有一条 `No routes matched location` 的警告（第 94 章）。用户看到空白页，不知道是网站坏了，还是自己输错了地址。

本章加一个“页面不存在”的提示页。完成后：任何没有对应页面的地址，导航栏下方都显示“页面不存在”和一句说明，并有一个“回到首页”的链接；控制台不再出现那条警告。

下图是打开 `/abc` 以后的样子：

![页面不存在](images/第099章-页面不存在.png)

## 二、必要原理

### path="*"：匹配所有其他地址

`path` 写成星号 `*`，表示“任意地址都能匹配”：

```tsx
<Route path="*" element={<NotFoundPage />} />
```

你可能担心：它能匹配任意地址，会不会把 `/news` 也抢走？不会。React Router 不是按书写顺序逐条比较，而是先给每条路由打分：写得越具体的路由优先级越高。`/news` 是一个完整的固定地址，比 `*` 具体得多，所以地址是 `/news` 时，显示的仍然是新闻页。只有其他路由都匹配不上时，才轮到 `*`。

因为按具体程度排序，`*` 写在路由表的哪个位置，结果都一样。习惯上写在最后，读路由表时一眼就能看出“其余的地址都显示提示页”。

### 放在布局路由里面

`*` 这条路由写在第 98 章的布局路由里面，提示页也会带着导航栏，用户可以直接点导航去别的页面。

### 两种“找不到”

现在项目中有两种“找不到”，处理的位置不同：

| 地址 | 原因 | 谁来处理 |
| --- | --- | --- |
| `/abc`、`/products/2/abc` | 路由表中没有对应的页面 | 本章的 `NotFoundPage` |
| `/products/99` | 地址符合 `/products/:id`，但没有编号为 99 的商品 | 第 95 章详情页中的“没有找到编号为 99 的商品” |

第二种情况，路由已经匹配上了，只是数据不存在，所以由页面自己判断。

### 地址的大小写和末尾斜杠

React Router 默认不区分大小写，也不在意末尾多一个斜杠：`/NEWS`、`/news/` 都会显示新闻页，不会进入提示页。

## 三、动手实现

### 第 1 步：新建提示页

新建 `src/pages/NotFoundPage.tsx`：

```tsx
import { Link } from 'react-router';

export default function NotFoundPage() {
  return (
    <main className="page">
      <h1>页面不存在</h1>
      <p>你访问的地址没有对应的页面，可能是地址输错了，或者这个页面已经被移走。</p>
      <p>
        <Link to="/">回到首页</Link>
      </p>
    </main>
  );
}
```

### 第 2 步：在路由表中加入 * 路由

打开 `src/App.tsx`，在导入 `NewsPage` 的一行下面加入：

```tsx
import NotFoundPage from './pages/NotFoundPage';
```

在布局路由中，`/tasks` 那一行的下面加入：

```tsx
        <Route path="*" element={<NotFoundPage />} />
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 打开 `http://127.0.0.1:5173/abc`，导航栏下方显示“页面不存在”和说明文字。控制台没有 `No routes matched location` 的警告。
2. 导航栏中没有突出显示的项。点击“回到首页”，回到学习小组页。
3. 打开 `/products/2/abc`，也显示“页面不存在”。
4. 打开 `/products/99`，显示的是详情页中的“没有找到编号为 99 的商品。”，不是本章的提示页。
5. 打开 `/news`、`/NEWS`、`/news/`，显示的都是新闻页。
6. 依次点击导航中的每一项，都能正常打开，没有被提示页挡住。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：在提示页中再加一个“去商品目录看看”的链接，链接到 `/products`。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 提示页上没有导航栏 | `*` 路由写在了布局路由的外面 | 移到 `<Route element={<AppLayout />}>` 里面 |
| 检查命令报 `Cannot find name 'NotFoundPage'.` | 路由表中用了 `NotFoundPage`，但文件开头没有导入 | 加上 `import NotFoundPage from './pages/NotFoundPage';` |
| 想在提示页显示“404”，于是新建了一个 `/404` 地址，再让其他地址跳过去 | 其他地址并不会自动跳到 `/404` | 直接用 `path="*"` 显示提示页，地址栏保留用户输入的地址，方便他发现哪里输错了 |

## 六、本章完整代码

### `src/pages/NotFoundPage.tsx`

同第三节第 1 步。

### `src/App.tsx`

```tsx
import { Route, Routes } from 'react-router';
import './App.css';
import AppLayout from './components/AppLayout';
import ArticlePage from './pages/ArticlePage';
import ContactsPage from './pages/ContactsPage';
import FaqPage from './pages/FaqPage';
import GroupPage from './pages/GroupPage';
import NewsPage from './pages/NewsPage';
import NotFoundPage from './pages/NotFoundPage';
import ProductDetailPage from './pages/ProductDetailPage';
import ProductPage from './pages/ProductPage';
import RegisterPage from './pages/RegisterPage';
import SearchPage from './pages/SearchPage';
import TaskPage from './pages/TaskPage';
import TaskServerPage from './pages/TaskServerPage';

export default function App() {
  return (
    <Routes>
      <Route element={<AppLayout />}>
        <Route path="/" element={<GroupPage />} />
        <Route path="/news" element={<NewsPage />} />
        <Route path="/faq" element={<FaqPage />} />
        <Route path="/register" element={<RegisterPage />} />
        <Route path="/todos" element={<TaskPage />} />
        <Route path="/contacts" element={<ContactsPage />} />
        <Route path="/products" element={<ProductPage />} />
        <Route path="/products/:id" element={<ProductDetailPage />} />
        <Route path="/articles" element={<ArticlePage />} />
        <Route path="/search" element={<SearchPage />} />
        <Route path="/tasks" element={<TaskServerPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Route>
    </Routes>
  );
}
```

新增 `src/pages/NotFoundPage.tsx`；修改 `src/App.tsx`：在布局路由中加入 `path="*"` 的路由。

# 第 8 章：如何把一段界面提取成组件？

前置：[第 7 章：写错代码时，如何让检查命令提前发现问题？](第007章-写错代码时，如何让检查命令提前发现问题.md)

## 一、本章要解决的问题

现在 `App` 里既有页面标题，又有资料卡片的全部内容：数据、头像、姓名、介绍都挤在一起。以后页面要放多张卡片、增加页头页脚，`App` 会越来越长，很难看清结构。

本章把资料卡片单独提取成一个组件 `ProfileCard`，并放进自己的文件。完成后，页面显示效果不变，`App` 中只剩下页面标题和一行 `<ProfileCard />`。

## 二、必要原理

### 组件就是一个返回 JSX 的函数

第 1 章说过，`App` 是一个返回页面内容的函数，也就是组件。我们可以照样写出更多组件：

```tsx
function ProfileCard() {
  return <article>……</article>;
}
```

然后像使用 HTML 标签一样使用它：

```tsx
<ProfileCard />
```

React 遇到 `<ProfileCard />` 时，会调用 `ProfileCard` 函数，把它返回的内容放在这个位置。

### 组件名必须大写开头

React 靠首字母区分两种标签：小写开头的 `<article>` 是 HTML 标签，大写开头的 `<ProfileCard>` 是你写的组件。如果写成 `profileCard`，React 会把它当成一个不存在的 HTML 标签，页面上什么都不会显示。

### 把组件放到单独的文件

组件写在同一个文件里完全可以运行。当组件变多时，通常把每个较大的组件放进自己的文件，便于查找和复用。本项目约定把多个页面可能共用的组件放在 `src/components` 文件夹中。

一个文件要让别的文件使用它的组件，需要导出：

```tsx
export default function ProfileCard() { …… }
```

使用的文件再导入：

```tsx
import ProfileCard from './components/ProfileCard';
```

`export default` 表示这是文件的“默认导出”，每个文件最多一个。导入时名字可以自己定，习惯上和组件名保持一致。

## 三、动手实现

先在同一个文件中提取组件，确认没有问题后，再移到单独的文件。

### 第 1 步：在 App.tsx 中提取 ProfileCard

打开 `src/App.tsx`，在 `App` 函数的下方新写一个 `ProfileCard` 函数，把 `profile` 数据和整个 `<article>` 从 `App` 中剪切过来：

```tsx
function ProfileCard() {
  const profile: Profile = {
    name: '小林',
    role: '前端开发学习者',
    intro: '正在用 React 制作自己的第一个页面。',
  };

  return (
    <article className="profile-card">
      ……原来 article 中的全部内容，原样移过来……
    </article>
  );
}
```

`App` 中原来放 `<article>` 的位置改成 `<ProfileCard />`，`App` 变成：

```tsx
export default function App() {
  return (
    <main className="page">
      <h1>个人介绍</h1>
      <ProfileCard />
    </main>
  );
}
```

保存后，页面显示与之前完全相同。此时 `ProfileCard` 没有 `export`，因为只在本文件中使用。

### 第 2 步：把 ProfileCard 移到自己的文件

在 `src` 中新建 `components` 文件夹，在其中新建 `ProfileCard.tsx`。把下面这些内容从 `App.tsx` 剪切到新文件中：

- 头像的导入语句；
- `Profile` 类型；
- 整个 `ProfileCard` 函数。

然后做两处调整：

```tsx
import avatarLin from '../assets/avatar-lin.svg';
```

```tsx
export default function ProfileCard() {
```

- 头像路径从 `./assets/...` 改成 `../assets/...`。因为 `ProfileCard.tsx` 在 `components` 文件夹里，`..` 表示先回到上一级的 `src` 文件夹，再进入 `assets`。
- 函数前加上 `export default`，让别的文件能导入它。

### 第 3 步：在 App.tsx 中导入组件

`App.tsx` 中现在只剩下 CSS 导入和 `App` 函数。在顶部加入组件的导入：

```tsx
import './App.css';
import ProfileCard from './components/ProfileCard';
```

导入路径不写 `.tsx` 扩展名，Vite 和 TypeScript 会自动找到文件。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面显示与第 5 章完全相同：标题、头像、姓名、身份、介绍都在。
2. 在 `App` 中把 `<ProfileCard />` 复制一行，变成两行，保存。页面上出现两张一模一样的卡片。这说明组件可以重复使用；但两张卡片都是小林，因为数据写死在组件里。第 9 章解决这个问题。检查后删掉多余的一行。
3. 按 F12，在 Elements（元素）面板中只能看到 `article`、`img` 等 HTML 标签，看不到 `ProfileCard`。组件只存在于 React 代码中，浏览器得到的是它返回的 HTML。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：仿照本章，把页面标题 `<h1>个人介绍</h1>` 提取成一个 `PageTitle` 组件，写在 `App.tsx` 中（不需要单独文件），并在 `App` 中使用它。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 卡片没有显示，控制台警告 `<profileCard /> is using incorrect casing` | 组件名小写开头，例如写成了 `<profileCard />` | 组件名和使用时都用大写开头 |
| 编辑器提示找不到 `./components/ProfileCard` | 文件夹或文件名拼写不同，或文件不在 `src/components` 中 | 核对路径和大小写 |
| 编辑器提示模块没有默认导出 | `ProfileCard` 前面漏写了 `export default` | 补上 `export default` |
| 页面空白，提示找不到头像图片 | 移动文件后头像路径仍是 `./assets/...` | 改成 `../assets/avatar-lin.svg` |
| `check` 报告 `Profile` 或 `avatarLin` 已声明但未使用 | 剪切时在 `App.tsx` 中留下了多余的类型或导入 | 删除 `App.tsx` 中不再使用的部分 |

## 六、本章完整代码

### `src/components/ProfileCard.tsx`

```tsx
import avatarLin from '../assets/avatar-lin.svg';

type Profile = {
  name: string;
  role: string;
  intro: string;
};

export default function ProfileCard() {
  const profile: Profile = {
    name: '小林',
    role: '前端开发学习者',
    intro: '正在用 React 制作自己的第一个页面。',
  };

  return (
    <article className="profile-card">
      <img
        className="profile-avatar"
        src={avatarLin}
        alt={profile.name + '的头像'}
        width="96"
        height="96"
      />
      <h2>{profile.name}</h2>
      <p className="profile-role">{profile.role}</p>
      <p>
        我是{profile.name}，{profile.intro}
      </p>
    </article>
  );
}
```

### `src/App.tsx`

```tsx
import './App.css';
import ProfileCard from './components/ProfileCard';

export default function App() {
  return (
    <main className="page">
      <h1>个人介绍</h1>
      <ProfileCard />
    </main>
  );
}
```

## 七、本章改动小结

新增 `src/components/ProfileCard.tsx`；修改 `src/App.tsx`：卡片内容移到 `ProfileCard` 组件中，`App` 只保留页面标题和 `<ProfileCard />`。

# 第 117 章：如何点击弹窗外的遮罩关闭弹窗？

前置：[第 116 章：如何用 dialog 元素显示一个弹窗？](第116章-如何用dialog元素显示一个弹窗.md)

## 一、本章要解决的问题

查看便签的弹窗只能点“关闭”或按 Esc 关掉。很多用户习惯直接点弹窗外面变暗的地方，可现在点了没有任何反应，只好再去找“关闭”按钮。

本章让便签的查看弹窗在点击遮罩时关闭。完成后：点弹窗外变暗的区域，弹窗关闭；点弹窗里面的任何地方，包括文字、标题和白框的边缘，弹窗都不会关闭。

## 二、必要原理

### 遮罩属于 dialog 自己

`::backdrop` 遮罩不是一个单独的元素，它属于 `dialog`。点击遮罩时，浏览器认为点的是 `dialog` 本身，所以在 `dialog` 上写 `onClick` 就能收到这次点击。

问题是，点弹窗里面的标题、文字时，`dialog` 的 `onClick` 也会被调用：点击事件会从被点的元素开始，一层一层往外传给它的上层元素，这叫**事件冒泡**。所以要区分“点在遮罩上”和“点在内容上”。

### target 和 currentTarget

事件对象中有两个属性：

- `event.target`：实际被点到的元素；
- `event.currentTarget`：写着这个 `onClick` 的元素，这里就是 `dialog`。

点在遮罩上时，被点到的就是 `dialog` 本身，两者相同；点在里面的文字上时，`target` 是那个 `p`，两者不同。所以：

```tsx
if (event.target === event.currentTarget) {
  handleCloseView();
}
```

事件的类型是 `MouseEvent<HTMLDialogElement>`，写法和第 36 章的 `ChangeEvent` 相同：尖括号中写触发事件的元素类型。

### 内边距要放到里层

白框的边缘是 `dialog` 的内边距 `padding`。点在内边距上，被点到的也是 `dialog` 本身，会被误认为点了遮罩，弹窗就关了。

解决办法：`dialog` 的 `padding` 改为 `0`，里面套一层 `div`，内边距写在这层 `div` 上。这样白框中的每一处都属于里层的 `div`，只有真正的遮罩区域才是 `dialog` 本身。

### 键盘用户不受影响

点击遮罩只是鼠标用户的一种方便。用键盘操作的人仍然用 Esc 关闭，弹窗中的“关闭”按钮也保留，三种方式都能关。

## 三、动手实现

### 第 1 步：写遮罩的点击处理

打开 `src/pages/NotesPage.tsx`，在导入中加入：

```tsx
import type { MouseEvent } from 'react';
```

在 `return` 的前面加入：

```tsx
  function handleViewDialogClick(event: MouseEvent<HTMLDialogElement>) {
    // 点在遮罩上时，事件的目标是 dialog 本身；点在内容上时，目标是里面的元素
    if (event.target === event.currentTarget) {
      handleCloseView();
    }
  }

```

### 第 2 步：dialog 加上 onClick，内容套一层 div

把整个 `dialog` 改为：

```tsx
      <dialog
        ref={viewDialogRef}
        className={styles.dialog}
        aria-labelledby="view-title"
        onClick={handleViewDialogClick}
      >
        <div className={styles.dialogBody}>
          <h2 id="view-title">{viewingNote ? viewingNote.title : ''}</h2>
          <p className={styles.content}>{viewingNote ? viewingNote.content : ''}</p>
          <button type="button" onClick={handleCloseView}>
            关闭
          </button>
        </div>
      </dialog>
```

### 第 3 步：内边距移到里层

打开 `src/pages/NotesPage.module.css`，把 `.dialog` 中的 `padding: 24px;` 改为 `padding: 0;`，并在 `.dialog` 规则的后面加入：

```css

/* 内边距放在里层，点在内边距上也算点在内容上，不会被当成点遮罩 */
.dialogBody {
  padding: 24px;
}
```

把 `.dialog h2` 改为 `.dialogBody h2`，标题现在在里层的 `div` 中。

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 打开便签页，点“周一例会”的“查看”。弹窗的外观和第 116 章完全一样。
2. 点弹窗外变暗的区域，弹窗关闭，焦点回到“查看”按钮上。
3. 再打开，依次点弹窗中的标题、文字、白框左上角的边缘，弹窗都不关闭。
4. 点“关闭”按钮、按 Esc 键，仍然能关闭。

最后运行检查，应没有错误：

```powershell

```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 点弹窗里的文字，弹窗也关了 | `onClick` 中没有判断，直接调用了关闭 | 只在 `event.target === event.currentTarget` 时关闭 |
| 点白框的边缘，弹窗关了 | 内边距写在 `dialog` 上，点在内边距上被当成点在遮罩上 | `dialog` 的 `padding` 设为 `0`，内边距写在里层的 `div` 上 |
| 检查命令报 `Type 'MouseEvent' is not generic.` | 没有从 `react` 导入 `MouseEvent`，用到的是浏览器自带的同名类型，它不接受尖括号 | 写 `import type { MouseEvent } from 'react';` |

## 六、本章完整代码

### `src/pages/NotesPage.tsx`

```tsx
import { useRef, useState } from 'react';
import type { MouseEvent } from 'react';
import { initialNotes } from '../data/notes';
import styles from './NotesPage.module.css';

export default function NotesPage() {
  const [notes] = useState(initialNotes);
  const [viewingId, setViewingId] = useState<number | null>(null);
  const viewDialogRef = useRef<HTMLDialogElement>(null);
  const viewingNote = notes.find((note) => note.id === viewingId);

  function handleView(id: number) {
    setViewingId(id);
    if (viewDialogRef.current) {
      viewDialogRef.current.showModal();
    }
  }

  function handleCloseView() {
    if (viewDialogRef.current) {
      viewDialogRef.current.close();
    }
  }

  function handleViewDialogClick(event: MouseEvent<HTMLDialogElement>) {
    // 点在遮罩上时，事件的目标是 dialog 本身；点在内容上时，目标是里面的元素
    if (event.target === event.currentTarget) {
      handleCloseView();
    }
  }

  return (
    <main className="page">
      <title>便签</title>
      <h1>便签</h1>
      <ul className={styles.list}>
        {notes.map((note) => (
          <li key={note.id} className={styles.item}>
            <span className={styles.itemTitle}>{note.title}</span>
            <button type="button" onClick={() => handleView(note.id)}>
              查看
            </button>
          </li>
        ))}
      </ul>
      <dialog
        ref={viewDialogRef}
        className={styles.dialog}
        aria-labelledby="view-title"
        onClick={handleViewDialogClick}
      >
        <div className={styles.dialogBody}>
          <h2 id="view-title">{viewingNote ? viewingNote.title : ''}</h2>
          <p className={styles.content}>{viewingNote ? viewingNote.content : ''}</p>
          <button type="button" onClick={handleCloseView}>
            关闭
          </button>
        </div>
      </dialog>
    </main>
  );
}
```

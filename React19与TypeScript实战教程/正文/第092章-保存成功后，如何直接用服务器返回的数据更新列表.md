# 第 92 章：保存成功后，如何直接用服务器返回的数据更新列表？

前置：[第 91 章：修改任务保存失败时，如何保留编辑框中的内容？](第091章-修改任务保存失败时，如何保留编辑框中的内容.md)

## 一、本章要解决的问题

现在任务管理页每次添加、修改、删除成功后，都要再请求一次完整的任务列表。打开 Network（网络）面板就能看到：每次保存都是两个请求，等待时间也是两倍。而且还多出一种麻烦的情况：保存成功了，重新读取却失败了。

其实服务器在保存成功的响应中，已经告诉了我们结果。本章不再重新读取列表，直接用响应中的数据更新页面上的列表。完成后，每次操作只有一个请求，结果出现得更快。

## 二、必要原理

### 响应中已经有需要的数据

回顾三种保存请求成功时的响应：

| 操作 | 成功时返回 | 页面上的列表怎样更新 |
| --- | --- | --- |
| 新增 | 状态 201，新建的任务 | 把新任务加到数组末尾 |
| 修改 | 状态 200，修改后的任务 | 用它替换数组中编号相同的那一条 |
| 删除 | 状态 204，没有内容 | 从数组中去掉这个编号的任务 |

删除虽然没有返回内容，但状态 204 已经说明删除成功，要删的是哪一条，我们自己知道。

这三种更新就是第 48 章（如何切换任务的完成状态）总结过的数组写法：添加用 `[...tasks, 新任务]`，修改用 `map`，删除用 `filter`。

### 用服务器返回的任务，不用自己拼

添加任务时，为什么不直接用输入的名称拼一个任务对象？因为新任务的 `id` 是服务器生成的，只有响应中才有。修改任务时也一样，要用服务器返回的任务，而不是用输入的名称自己改：服务器会整理数据，例如去掉名称首尾的空格，返回的才是真正保存下来的样子。

返回的数据同样来自接口，使用前要用 `isTask` 检查格式（第 68 章）。格式不对时，数据很可能已经保存了，只是页面没法显示，所以提示用户刷新页面。

### 用更新函数，基于最新的列表计算

保存函数都是 `async` 函数，从点击到拿到响应，中间要等半秒。这段时间里，用户可能又做了别的操作。比如连续点击两条任务的“删除”：

1. 点击删除 A。这时列表是 `[A, B]`，第一次调用的 `handleDelete` 记住的 `tasks` 是 `[A, B]`。
2. 立刻点击删除 B。页面还没变，第二次调用记住的 `tasks` 也是 `[A, B]`。
3. 删除 A 的响应先回来，用 `tasks.filter` 算出 `[B]`，列表更新为 `[B]`。
4. 删除 B 的响应回来，用它记住的 `[A, B]` 算出 `[A]`，列表更新为 `[A]`。**已经删掉的 A 又出现了。**

问题在于第 4 步用的是点击时的旧列表。第 28 章（如何根据上一次的值连续更新状态）的**更新函数**正好解决这个问题：给 set 函数传一个函数，React 会把**最新的** state 作为参数传进来。第 4 步拿到的就是 `[B]`，算出 `[]`，结果正确。

所以本章的三处更新都写成更新函数：

```tsx
setLoadState((current) => ({ ...current, tasks: [...current.tasks, data] }));
```

`current` 是最新的 `loadState`。`{ ...current, tasks: … }` 复制它的所有属性，只把 `tasks` 换成新数组，`status` 等其他属性保持原样。

### 不再重新读取的代价

页面上的列表不再每次都和服务器同步。如果别人（或另一个浏览器标签）同时修改了任务，这边要刷新页面才看得到。对任务管理页来说，这是可以接受的：自己的操作马上能看到结果，别人的改动刷新后看到。

## 三、动手实现

本章只修改 `src/pages/TaskServerPage.tsx`。三个保存函数中，“重新读取列表”的 `try...catch` 都换成用响应数据更新。

### 第 1 步：添加成功后，把新任务加到末尾

在 `saveNewTask` 中，把 `setDraft('');` 下面的 `try...catch` 整段替换为：

```tsx
    setDraft('');
    const data: unknown = await response.json();
    if (!isTask(data)) {
      setSaveError('任务已保存，但返回的数据格式不正确，请刷新页面查看。');
      return;
    }
    setLoadState((current) => ({ ...current, tasks: [...current.tasks, data] }));
  }
```

### 第 2 步：修改成功后，替换这一条

在 `handleSaveEdit` 中，把 `setEditingId(null);` 下面的 `try...catch` 整段替换为：

```tsx
    setEditingId(null);
    const data: unknown = await response.json();
    if (!isTask(data)) {
      setSaveError('修改已保存，但返回的数据格式不正确，请刷新页面查看。');
      return;
    }
    setLoadState((current) => ({
      ...current,
      tasks: current.tasks.map((task) => (task.id === data.id ? data : task)),
    }));
  }
```

编号相同的那一条换成服务器返回的 `data`，其他任务原样保留。

### 第 3 步：删除成功后，去掉这一条

在 `handleDelete` 中，把最后的 `try...catch` 整段替换为：

```tsx
    setLoadState((current) => ({
      ...current,
      tasks: current.tasks.filter((task) => task.id !== id),
    }));
  }
```

删除请求没有返回内容，直接用参数中的 `id` 去掉这一条。状态 404 也走到这里：任务在服务器上已经不存在，页面上也去掉它。

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。打开 Network 面板，先等列表显示出来。

1. 添加一条任务。Network 中只出现一个 POST 请求，没有随后的 `tasks` GET 请求。新任务半秒左右就出现在列表末尾，比原来快一倍。
2. 编辑一条任务，把名称改为首尾带空格的“  前后空格  ”并保存。Network 中只有一个 PATCH 请求，列表中显示的是去掉空格的“前后空格”。
3. 快速连续点击两条任务的“删除”，两条任务都消失，没有哪一条重新出现。
4. 刷新页面，列表与刷新前完全一致，说明页面上的更新和服务器保存的结果相同。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：把第 3 步中的更新函数暂时改为直接使用旧列表：

```tsx
    setLoadState({ ...loadState, tasks: tasks.filter((task) => task.id !== id) });
```

再快速连续删除两条任务，看看是否会出现第二节描述的“删掉的任务又出现”。观察后恢复本章代码，刷新页面确认服务器上两条任务都已删除。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 快速删除两条任务，其中一条删掉后又出现 | 用的是点击时的 `tasks`，没有用更新函数 | 写成 `setLoadState((current) => …)`，基于 `current.tasks` 计算 |
| 添加任务后，列表变成只有新任务一条 | 写成了 `tasks: [data]`，丢掉了原有的任务 | 写成 `[...current.tasks, data]` |
| `check` 提示 `data` 的类型是 `unknown`，不能放进数组 | 漏写了 `isTask(data)` 的检查 | 先检查，不符合时 `return` |
| 删除后控制台报错 `Unexpected end of JSON input` | 删除时也调用了 `response.json()` | 删除只用参数中的 `id`，不读取响应 |
| 修改后列表中出现两条一样的任务 | 修改时用了添加的写法 `[...current.tasks, data]` | 修改用 `map` 替换编号相同的那一条 |

## 六、本章完整代码

### `src/pages/TaskServerPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { SubmitEvent } from 'react';
import TaskEditor from '../components/TaskEditor';
import { apiUrl } from '../lib/api';
import { isTask } from '../types/task';
import type { Task } from '../types/task';
import styles from './TaskPage.module.css';

type LoadState =
  | { status: 'loading'; tasks: Task[] }
  | { status: 'success'; tasks: Task[] }
  | { status: 'error'; message: string; tasks: Task[] };

async function fetchTasks(): Promise<Task[]> {
  let response: Response;
  try {
    response = await fetch(apiUrl('/tasks'));
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
  if (!response.ok) {
    throw new Error('任务读取失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (!Array.isArray(data) || !data.every(isTask)) {
    throw new Error('任务数据格式不正确，暂时无法显示。');
  }
  return data;
}

function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '任务读取失败。';
}

async function readTitleError(response: Response): Promise<string> {
  let data: unknown;
  try {
    data = await response.json();
  } catch {
    return '任务名称不符合要求。';
  }
  if (
    typeof data === 'object' &&
    data !== null &&
    'fieldErrors' in data &&
    typeof data.fieldErrors === 'object' &&
    data.fieldErrors !== null &&
    'title' in data.fieldErrors &&
    typeof data.fieldErrors.title === 'string'
  ) {
    return data.fieldErrors.title + '。';
  }
  return '任务名称不符合要求。';
}

export default function TaskServerPage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'loading', tasks: [] });
  const [draft, setDraft] = useState('');
  const [titleError, setTitleError] = useState('');
  const [saveError, setSaveError] = useState('');
  const [isAdding, setIsAdding] = useState(false);
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editError, setEditError] = useState('');
  const tasks = loadState.tasks;
  const editingTask = tasks.find((task) => task.id === editingId);

  useEffect(() => {
    let ignore = false;

    async function loadOnOpen() {
      try {
        const data = await fetchTasks();
        if (!ignore) {
          setLoadState({ status: 'success', tasks: data });
        }
      } catch (error) {
        if (!ignore) {
          setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
        }
      }
    }

    loadOnOpen();
    return () => {
      ignore = true;
    };
  }, []);

  async function handleRetry() {
    setLoadState({ status: 'loading', tasks: [] });
    try {
      const data = await fetchTasks();
      setLoadState({ status: 'success', tasks: data });
    } catch (error) {
      setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
    }
  }

  async function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      setTitleError('请填写任务名称。');
      return;
    }
    setTitleError('');
    setSaveError('');
    setIsAdding(true);
    try {
      await saveNewTask(title);
    } finally {
      setIsAdding(false);
    }
  }

  async function saveNewTask(title: string) {
    let response: Response;
    try {
      response = await fetch(apiUrl('/tasks'), {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ title }),
      });
    } catch {
      setSaveError('无法连接练习服务，任务没有保存。输入的内容已保留。');
      return;
    }
    if (response.status === 422) {
      setTitleError(await readTitleError(response));
      return;
    }
    if (!response.ok) {
      setSaveError('保存失败：服务器返回了状态 ' + response.status + '。输入的内容已保留。');
      return;
    }

    setDraft('');
    const data: unknown = await response.json();
    if (!isTask(data)) {
      setSaveError('任务已保存，但返回的数据格式不正确，请刷新页面查看。');
      return;
    }
    setLoadState((current) => ({ ...current, tasks: [...current.tasks, data] }));
  }

  function handleStartEdit(id: string) {
    setEditingId(id);
    setEditError('');
  }

  async function handleSaveEdit(id: string, title: string) {
    setEditError('');

    let response: Response;
    try {
      response = await fetch(apiUrl('/tasks/' + id), {
        method: 'PATCH',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ title }),
      });
    } catch {
      setEditError('无法连接练习服务，修改没有保存。');
      return;
    }
    if (!response.ok) {
      setEditError('修改失败：服务器返回了状态 ' + response.status + '。');
      return;
    }

    setEditingId(null);
    const data: unknown = await response.json();
    if (!isTask(data)) {
      setSaveError('修改已保存，但返回的数据格式不正确，请刷新页面查看。');
      return;
    }
    setLoadState((current) => ({
      ...current,
      tasks: current.tasks.map((task) => (task.id === data.id ? data : task)),
    }));
  }

  async function handleDelete(id: string) {
    if (id === editingId) {
      setEditingId(null);
    }
    setSaveError('');

    let response: Response;
    try {
      response = await fetch(apiUrl('/tasks/' + id), { method: 'DELETE' });
    } catch {
      setSaveError('无法连接练习服务，任务没有删除。');
      return;
    }
    if (!response.ok && response.status !== 404) {
      setSaveError('删除失败：服务器返回了状态 ' + response.status + '。');
      return;
    }

    setLoadState((current) => ({
      ...current,
      tasks: current.tasks.filter((task) => task.id !== id),
    }));
  }

  return (
    <main className="page">
      <h1>任务管理</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input
          id="new-task"
          value={draft}
          onChange={(event) => setDraft(event.target.value)}
          aria-invalid={titleError !== ''}
          aria-describedby={titleError ? 'new-task-error' : undefined}
        />
        <button type="submit" disabled={isAdding}>
          {isAdding ? '正在添加……' : '添加'}
        </button>
      </form>
      {titleError && (
        <p id="new-task-error" className={styles.error}>
          {titleError}
        </p>
      )}
      {saveError && <p role="alert">{saveError}</p>}
      {loadState.status === 'loading' && <p role="status">正在读取任务……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleRetry}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' && tasks.length === 0 && (
        <p className={styles.empty}>还没有任务。</p>
      )}
      {tasks.length > 0 && (
        <ul className={styles.list}>
          {tasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <span className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                {task.title}
              </span>
              <button type="button" onClick={() => handleStartEdit(task.id)}>
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingTask && (
        <TaskEditor
          key={editingTask.id}
          task={editingTask}
          onSave={(title) => handleSaveEdit(editingTask.id, title)}
          onCancel={() => setEditingId(null)}
        />
      )}
      {editingTask && editError && <p role="alert">{editError}</p>}
    </main>
  );
}
```

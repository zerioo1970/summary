# 第 98 章：如何让多个页面共用顶部导航？

前置：[第 97 章：如何突出显示当前所在的导航项？](第097章-如何突出显示当前所在的导航项.md)

## 一、本章要解决的问题

现在的导航栏写在 `App` 中、`Routes` 的外面，所以每个页面上都有它。但并不是所有页面都需要导航栏：第 109 章要做的登录页，通常只显示一个登录框。按现在的写法，只要是 `Routes` 里的页面，就一定带着导航栏。而且 `App.tsx` 既要管导航栏长什么样，又要管路由表，内容越来越多。

本章把导航栏移到一个单独的**布局组件** `AppLayout` 中，再用**布局路由**指定哪些页面使用这个布局。完成后，页面看起来和第 97 章完全一样；但如果把某个页面的路由移到布局路由外面，这个页面就不再显示导航栏。

下图是做一个小实验时的对比：左边的注册页写在布局路由里面，有导航栏；右边把它临时移到布局路由外面，没有导航栏：

![布局路由对比](images/第098章-布局路由对比.png)

## 二、必要原理

### 布局组件和 Outlet

布局组件负责页面上“每页都一样”的部分，例如导航栏、页脚；中间留出一个位置，显示当前页面自己的内容。这个位置用 React Router 的 `Outlet` 表示：

```tsx
<div>
  <nav>（导航链接）</nav>
  <Outlet />
</div>
```

`Outlet` 的意思是“出口”：当前地址匹配到哪个页面，这个页面就显示在 `Outlet` 所在的位置。

它和第 16 章的 `children` 作用相似，都是“组件里留一块位置给别人填”。区别是 `children` 由使用组件的地方写进去，`Outlet` 中显示什么由当前地址决定。

### 布局路由：路由里面套路由

在路由表中，用一个只有 `element`、没有 `path` 的 `Route` 包住其他路由：

```tsx
<Routes>
  <Route element={<AppLayout />}>
    <Route path="/" element={<GroupPage />} />
    <Route path="/news" element={<NewsPage />} />
  </Route>
</Routes>
```

外层的 `Route` 叫**布局路由**。它不对应任何地址，作用是给里面的路由套上一层布局。地址是 `/news` 时，React Router 先显示 `AppLayout`，再把 `NewsPage` 放进 `AppLayout` 的 `Outlet` 中。

写在布局路由里面的页面都有导航栏；写在外面的页面，就只显示页面本身。以后的登录页写在外面即可。

### 换页时布局组件不会重新创建

从 `/news` 换到 `/faq` 时，两个页面都在同一个布局路由中，`AppLayout` 一直保留在页面上，只有 `Outlet` 中的内容换了。所以布局组件中的 state 在换页时不会被清空，这一点第 12 部分做购物车时会用到。

## 三、动手实现

### 第 1 步：新建布局组件

新建 `src/components/AppLayout.tsx`：

```tsx
import { NavLink, Outlet } from 'react-router';

export default function AppLayout() {
  return (
    <div>
      <nav className="site-nav" aria-label="主导航">
        <NavLink to="/">学习小组</NavLink>
        <NavLink to="/news">新闻</NavLink>
        <NavLink to="/faq">常见问题</NavLink>
        <NavLink to="/register">注册</NavLink>
        <NavLink to="/todos">待办事项</NavLink>
        <NavLink to="/contacts">联系人</NavLink>
        <NavLink to="/products">商品目录</NavLink>
        <NavLink to="/articles">文章</NavLink>
        <NavLink to="/search">搜索</NavLink>
        <NavLink to="/tasks">任务管理</NavLink>
      </nav>
      <Outlet />
    </div>
  );
}
```

导航栏从 `App.tsx` 原样搬过来，原来 `Routes` 所在的位置换成了 `<Outlet />`。导航栏的样式仍然在 `App.css` 中，不需要移动。

### 第 2 步：App 只保留路由表

把 `src/App.tsx` 改为：

```tsx
import { Route, Routes } from 'react-router';
import './App.css';
import AppLayout from './components/AppLayout';
import ArticlePage from './pages/ArticlePage';
import ContactsPage from './pages/ContactsPage';
import FaqPage from './pages/FaqPage';
import GroupPage from './pages/GroupPage';
import NewsPage from './pages/NewsPage';
import ProductDetailPage from './pages/ProductDetailPage';
import ProductPage from './pages/ProductPage';
import RegisterPage from './pages/RegisterPage';
import SearchPage from './pages/SearchPage';
import TaskPage from './pages/TaskPage';
import TaskServerPage from './pages/TaskServerPage';

export default function App() {
  return (
    <Routes>
      <Route element={<AppLayout />}>
        <Route path="/" element={<GroupPage />} />
        <Route path="/news" element={<NewsPage />} />
        <Route path="/faq" element={<FaqPage />} />
        <Route path="/register" element={<RegisterPage />} />
        <Route path="/todos" element={<TaskPage />} />
        <Route path="/contacts" element={<ContactsPage />} />
        <Route path="/products" element={<ProductPage />} />
        <Route path="/products/:id" element={<ProductDetailPage />} />
        <Route path="/articles" element={<ArticlePage />} />
        <Route path="/search" element={<SearchPage />} />
        <Route path="/tasks" element={<TaskServerPage />} />
      </Route>
    </Routes>
  );
}
```

- 导入中不再需要 `NavLink`，加入了 `AppLayout`。
- 原来包住导航栏和 `Routes` 的 `<div>` 去掉了，`App` 直接返回 `Routes`。
- 十一条路由原样移到布局路由里面，每条多缩进一级。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 依次打开各个页面，导航栏、当前导航项的高亮都和第 97 章一样。
2. 在 React 开发者工具的 Components 面板中，可以看到组件的层次：`App` 下面是 `AppLayout`，`AppLayout` 下面有当前页面的组件，例如 `NewsPage`。
3. 打开“待办事项”，添加一条任务，再点“新闻”。Components 面板中 `AppLayout` 一直都在，只有它下面的页面组件换了。
4. 做一个小实验：把注册页的那一行路由剪切到 `</Route>` 后面、`</Routes>` 前面，保存。打开 `/register`，注册页还在，但导航栏不见了。实验后把这一行移回原处。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：在 `AppLayout` 的 `<Outlet />` 下面加一个页脚 `<footer className="page-footer">React 日常开发练习</footer>`（`.page-footer` 样式第 11 章已经写在 `App.css` 中），确认所有页面底部都出现了这行文字。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 每个页面都只有导航栏，下面一片空白 | 布局组件中没有写 `<Outlet />`，页面没有地方显示 | 在导航栏后面加上 `<Outlet />` |
| 页面能显示，但导航栏不见了；检查命令提示 `'AppLayout' is declared but its value is never read` | 布局路由写成了 `<Route>`，忘了写 `element={<AppLayout />}` | 写成 `<Route element={<AppLayout />}>` |
| 某个页面没有导航栏 | 这条路由写在了布局路由的外面 | 移到 `<Route element={<AppLayout />}>` 和 `</Route>` 之间 |
| 导航栏出现了两次 | `App` 中原来的导航栏没删，布局组件中又有一份 | `App` 中只保留路由表 |

# 第 92A 章：任务页的请求代码越来越多，如何集中到一个文件中？

前置：[第 92 章：保存成功后，如何直接用服务器返回的数据更新列表？](第092章-保存成功后，如何直接用服务器返回的数据更新列表.md)

## 一、本章要解决的问题

`TaskServerPage.tsx` 已经有二百七十多行。仔细看会发现，读取、添加、修改、删除四个地方都在重复同一套步骤：发送请求，连不上时给出提示，检查状态码，读取并检查返回的数据。请求的细节和页面的状态混在一起，要找“添加成功后列表怎样更新”这一行，得先读过一大段请求代码。

第 73A 章为文章页做过类似的整理：把请求提取成组件外面的 `fetchArticles`。本章更进一步，把任务的所有请求集中到一个单独的文件 `src/lib/taskApi.ts` 中，页面只负责“调用、拿到结果、更新页面”。完成后，页面的代码缩短到一百九十行左右，外观和操作与第 92 章相同。

顺带还有一个改进：修改任务时名称太长，编辑框下面原来只显示“状态 422”，现在会显示服务器给出的具体原因。

## 二、必要原理

### 页面只关心结果

站在页面的角度，添加一条任务只有三种结果：

1. 保存成功，拿到服务器返回的新任务；
2. 名称不符合要求，拿到原因，显示在输入框下方；
3. 其他失败（连不上、服务器出错），拿到一句提示。

至于请求怎样发、状态码怎样判断、返回的数据怎样检查，页面都不需要知道。把这些细节放进 `taskApi.ts`，页面中每个操作都变成“调用一个函数，按结果更新页面”。

### 一个函数负责发请求

四种请求的共同部分是：拼出完整地址，连不上时换成中文提示；需要发送内容时，写上请求头并把内容转成 JSON。把它写成文件内部的函数 `send`：

```ts
async function send(path: string, method = 'GET', body?: unknown): Promise<Response> {
```

- `method = 'GET'` 是参数的默认值（第 10 章 `note` 的默认值是同样的写法）：调用时不写第二个参数，就是 GET 请求。
- `body?: unknown` 是可选参数：不需要发送内容的请求（读取、删除）不传它。
- 函数中的 `RequestInit` 是 `fetch` 第二个参数的类型，由浏览器提供，不需要导入。先写好 `method`，有 `body` 时再加上请求头和正文。

这样，四个请求分别写成 `send('/tasks')`、`send('/tasks', 'POST', { title })`、`send('/tasks/' + id, 'PATCH', { title })`、`send('/tasks/' + id, 'DELETE')`。

### “名称不符合要求”用返回值表示，其他失败用 throw

第 73A 章的 `fetchArticles` 失败时一律 `throw`，页面在 `catch` 中显示提示。添加和修改不能全这样做：名称不符合要求时，页面要把原因显示在**输入框下方**，而连接失败要显示在**别的位置**。如果都用 `throw`，页面在 `catch` 中就分不清是哪一种。

名称不符合要求其实不算“出错”，而是保存的一种正常结果：服务器认真检查了，告诉你哪里要改。所以用返回值表示它。返回值的类型是一个联合类型（第 69 章）：

```ts
export type SaveResult =
  | { status: 'saved'; task: Task }
  | { status: 'invalid'; titleError: string };
```

`status` 为 `'saved'` 时带着保存好的任务，为 `'invalid'` 时带着原因。真正的失败（连不上、500、返回的数据格式不对）仍然 `throw`。

添加和修改对响应的处理完全相同，所以写成一个内部函数 `readSaveResult` 共用，参数 `action` 是“保存”或“修改”，用来拼出提示文字。

### 只导出页面要用的函数

`taskApi.ts` 中写了 `export` 的只有类型 `SaveResult` 和四个请求函数 `fetchTasks`、`createTask`、`updateTaskTitle`、`deleteTask`。`send`、`readTitleError`、`readSaveResult` 只在这个文件内部使用，不加 `export`，别的文件也就用不到它们。第 90 章写的 `readTitleError` 原样移了过来。

### 页面中的处理函数可以合并回一个

第 89 章为了用 `finally` 恢复按钮，把 `handleAdd` 拆成了两个函数，原因是请求部分有好几个 `try` 和 `return`。现在请求细节都在 `createTask` 中，`handleAdd` 中只剩一个 `try...catch...finally`，不再需要拆分：

```tsx
    try {
      const result = await createTask(title);
      // 按 result.status 更新页面
    } catch (error) {
      // 其他失败
    } finally {
      setIsAdding(false);
    }
```

## 三、动手实现

### 第 1 步：新建 taskApi.ts

在 `src/lib` 中新建 `taskApi.ts`：

```ts
import { apiUrl } from './api';
import { isTask } from '../types/task';
import type { Task } from '../types/task';

export type SaveResult =
  | { status: 'saved'; task: Task }
  | { status: 'invalid'; titleError: string };

async function send(path: string, method = 'GET', body?: unknown): Promise<Response> {
  const init: RequestInit = { method };
  if (body !== undefined) {
    init.headers = { 'Content-Type': 'application/json' };
    init.body = JSON.stringify(body);
  }
  try {
    return await fetch(apiUrl(path), init);
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
}

async function readTitleError(response: Response): Promise<string> {
  let data: unknown;
  try {
    data = await response.json();
  } catch {
    return '任务名称不符合要求。';
  }
  if (
    typeof data === 'object' &&
    data !== null &&
    'fieldErrors' in data &&
    typeof data.fieldErrors === 'object' &&
    data.fieldErrors !== null &&
    'title' in data.fieldErrors &&
    typeof data.fieldErrors.title === 'string'
  ) {
    return data.fieldErrors.title + '。';
  }
  return '任务名称不符合要求。';
}

async function readSaveResult(response: Response, action: string): Promise<SaveResult> {
  if (response.status === 422) {
    return { status: 'invalid', titleError: await readTitleError(response) };
  }
  if (!response.ok) {
    throw new Error(action + '失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (!isTask(data)) {
    throw new Error(action + '成功，但返回的数据格式不正确，请刷新页面查看。');
  }
  return { status: 'saved', task: data };
}

export async function fetchTasks(): Promise<Task[]> {
  const response = await send('/tasks');
  if (!response.ok) {
    throw new Error('任务读取失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (!Array.isArray(data) || !data.every(isTask)) {
    throw new Error('任务数据格式不正确，暂时无法显示。');
  }
  return data;
}

export async function createTask(title: string): Promise<SaveResult> {
  const response = await send('/tasks', 'POST', { title });
  return readSaveResult(response, '保存');
}

export async function updateTaskTitle(id: string, title: string): Promise<SaveResult> {
  const response = await send('/tasks/' + id, 'PATCH', { title });
  return readSaveResult(response, '修改');
}

export async function deleteTask(id: string): Promise<void> {
  const response = await send('/tasks/' + id, 'DELETE');
  if (!response.ok && response.status !== 404) {
    throw new Error('删除失败：服务器返回了状态 ' + response.status + '。');
  }
}
```

和页面中原来的代码对照：提示文字基本没变；`fetchTasks` 的内容原样搬了过来，只是第一行改用 `send`。

以下各步修改 `src/pages/TaskServerPage.tsx`。

### 第 2 步：修改导入，删除已经移走的函数

把导入中的这三行：

```tsx
import { apiUrl } from '../lib/api';
import { isTask } from '../types/task';
import type { Task } from '../types/task';
```

改为：

```tsx
import { createTask, deleteTask, fetchTasks, updateTaskTitle } from '../lib/taskApi';
import type { Task } from '../types/task';
```

然后删除组件外面的 `fetchTasks` 和 `readTitleError` 两个函数，它们已经在 `taskApi.ts` 中了。`getErrorMessage` 保留，把它的默认提示改为更通用的文字：

```tsx
function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '操作失败，请稍后重试。';
}
```

### 第 3 步：改写 handleAdd

删除 `handleAdd` 和 `saveNewTask` 两个函数，在原来的位置换成：

```tsx
  async function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      setTitleError('请填写任务名称。');
      return;
    }
    setTitleError('');
    setSaveError('');
    setIsAdding(true);
    try {
      const result = await createTask(title);
      if (result.status === 'invalid') {
        setTitleError(result.titleError);
        return;
      }
      setDraft('');
      setLoadState((current) => ({ ...current, tasks: [...current.tasks, result.task] }));
    } catch (error) {
      setSaveError(getErrorMessage(error) + '输入的内容已保留。');
    } finally {
      setIsAdding(false);
    }
  }
```

- `result.status === 'invalid'` 时，把原因显示在输入框下方，然后 `return`。`finally` 照样会执行，按钮会恢复。
- 走到 `setDraft('')` 时，TypeScript 已经知道 `result.status` 是 `'saved'`，所以可以读取 `result.task`。
- 其他失败在 `catch` 中显示，后面补上“输入的内容已保留。”。

### 第 4 步：改写 handleSaveEdit

把整个 `handleSaveEdit` 替换为：

```tsx
  async function handleSaveEdit(id: string, title: string) {
    setEditError('');
    try {
      const result = await updateTaskTitle(id, title);
      if (result.status === 'invalid') {
        setEditError(result.titleError);
        return;
      }
      setEditingId(null);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.map((task) => (task.id === id ? result.task : task)),
      }));
    } catch (error) {
      setEditError(getErrorMessage(error));
    }
  }
```

结构和 `handleAdd` 相同。名称不符合要求时，原因存进 `editError`，显示在编辑框下方。

### 第 5 步：改写 handleDelete

把整个 `handleDelete` 替换为：

```tsx
  async function handleDelete(id: string) {
    if (id === editingId) {
      setEditingId(null);
    }
    setSaveError('');
    try {
      await deleteTask(id);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.filter((task) => task.id !== id),
      }));
    } catch (error) {
      setSaveError(getErrorMessage(error));
    }
  }
```

`deleteTask` 成功时什么都不返回（返回类型是 `Promise<void>`），状态 404 也算成功，这个规则在 `taskApi.ts` 中已经处理好了。

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。本章是整理代码，下面各项除第 5 项外，都应和第 92 章完全相同。

1. 打开任务页，列表正常显示。
2. 添加一条任务：保存期间按钮是“正在添加……”，半秒后任务出现在末尾，Network（网络）中只有一个 POST 请求。
3. 不填名称点击添加，输入框下方显示“请填写任务名称。”；输入超过 30 个字的名称，显示“任务名称最多 30 个字。”。
4. 停止练习服务后添加，表单下方显示“保存失败：服务器返回了状态 500。输入的内容已保留。”，输入框中的文字还在。重新启动练习服务。
5. 编辑一条任务，输入超过 30 个字的名称并保存：编辑框保留，下方显示“任务名称最多 30 个字。”。第 92 章这里显示的是“状态 422”。
6. 修改名称、删除任务都正常；快速连续删除两条任务，两条都消失。
7. 刷新页面，列表与刷新前一致。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：在 `taskApi.ts` 中再写一个函数 `updateTaskCompleted(id: string, completed: boolean): Promise<SaveResult>`，发送 `{ completed }`。只写函数，不用在页面中使用，运行 `check` 确认没有错误。第 93 章的阶段练习会用到类似的请求。练习后可以保留这个函数，也可以删除。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| `check` 提示 `../lib/taskApi` 没有导出 `fetchTasks` | `taskApi.ts` 中的函数漏写了 `export` | 四个请求函数前面都要写 `export` |
| `check` 提示 `apiUrl` 或 `isTask` 已声明但从未使用 | 页面中旧的导入没有删除 | 按第 2 步修改导入 |
| `check` 提示 `result.task` 可能不存在 | 读取 `result.task` 之前没有先处理 `'invalid'` 的情况 | 先判断 `result.status === 'invalid'` 并 `return` |
| 名称太长时，表单下方显示一句通用提示，输入框下方没有原因 | 在 `taskApi.ts` 中把 422 也写成了 `throw` | 422 用返回值 `{ status: 'invalid', … }` 表示 |
| 添加后按钮一直是“正在添加……” | `setIsAdding(false)` 写在了 `try` 的末尾 | 写在 `finally` 中 |
| 编辑器提示 `send` 找不到 | 页面中直接调用了 `send` | `send` 只在 `taskApi.ts` 内部使用，页面调用 `createTask` 等函数 |

## 六、本章完整代码

### `src/lib/taskApi.ts`

内容同第三节第 1 步。

### `src/pages/TaskServerPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { SubmitEvent } from 'react';
import TaskEditor from '../components/TaskEditor';
import { createTask, deleteTask, fetchTasks, updateTaskTitle } from '../lib/taskApi';
import type { Task } from '../types/task';
import styles from './TaskPage.module.css';

type LoadState =
  | { status: 'loading'; tasks: Task[] }
  | { status: 'success'; tasks: Task[] }
  | { status: 'error'; message: string; tasks: Task[] };

function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '操作失败，请稍后重试。';
}

export default function TaskServerPage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'loading', tasks: [] });
  const [draft, setDraft] = useState('');
  const [titleError, setTitleError] = useState('');
  const [saveError, setSaveError] = useState('');
  const [isAdding, setIsAdding] = useState(false);
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editError, setEditError] = useState('');
  const tasks = loadState.tasks;
  const editingTask = tasks.find((task) => task.id === editingId);

  useEffect(() => {
    let ignore = false;

    async function loadOnOpen() {
      try {
        const data = await fetchTasks();
        if (!ignore) {
          setLoadState({ status: 'success', tasks: data });
        }
      } catch (error) {
        if (!ignore) {
          setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
        }
      }
    }

    loadOnOpen();
    return () => {
      ignore = true;
    };
  }, []);

  async function handleRetry() {
    setLoadState({ status: 'loading', tasks: [] });
    try {
      const data = await fetchTasks();
      setLoadState({ status: 'success', tasks: data });
    } catch (error) {
      setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
    }
  }

  async function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      setTitleError('请填写任务名称。');
      return;
    }
    setTitleError('');
    setSaveError('');
    setIsAdding(true);
    try {
      const result = await createTask(title);
      if (result.status === 'invalid') {
        setTitleError(result.titleError);
        return;
      }
      setDraft('');
      setLoadState((current) => ({ ...current, tasks: [...current.tasks, result.task] }));
    } catch (error) {
      setSaveError(getErrorMessage(error) + '输入的内容已保留。');
    } finally {
      setIsAdding(false);
    }
  }

  function handleStartEdit(id: string) {
    setEditingId(id);
    setEditError('');
  }

  async function handleSaveEdit(id: string, title: string) {
    setEditError('');
    try {
      const result = await updateTaskTitle(id, title);
      if (result.status === 'invalid') {
        setEditError(result.titleError);
        return;
      }
      setEditingId(null);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.map((task) => (task.id === id ? result.task : task)),
      }));
    } catch (error) {
      setEditError(getErrorMessage(error));
    }
  }

  async function handleDelete(id: string) {
    if (id === editingId) {
      setEditingId(null);
    }
    setSaveError('');
    try {
      await deleteTask(id);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.filter((task) => task.id !== id),
      }));
    } catch (error) {
      setSaveError(getErrorMessage(error));
    }
  }

  return (
    <main className="page">
      <h1>任务管理</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input
          id="new-task"
          value={draft}
          onChange={(event) => setDraft(event.target.value)}
          aria-invalid={titleError !== ''}
          aria-describedby={titleError ? 'new-task-error' : undefined}
        />
        <button type="submit" disabled={isAdding}>
          {isAdding ? '正在添加……' : '添加'}
        </button>
      </form>
      {titleError && (
        <p id="new-task-error" className={styles.error}>
          {titleError}
        </p>
      )}
      {saveError && <p role="alert">{saveError}</p>}
      {loadState.status === 'loading' && <p role="status">正在读取任务……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleRetry}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' && tasks.length === 0 && (
        <p className={styles.empty}>还没有任务。</p>
      )}
      {tasks.length > 0 && (
        <ul className={styles.list}>
          {tasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <span className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                {task.title}
              </span>
              <button type="button" onClick={() => handleStartEdit(task.id)}>
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingTask && (
        <TaskEditor
          key={editingTask.id}
          task={editingTask}
          onSave={(title) => handleSaveEdit(editingTask.id, title)}
          onCancel={() => setEditingId(null)}
        />
      )}
      {editingTask && editError && <p role="alert">{editError}</p>}
    </main>
  );
}
```

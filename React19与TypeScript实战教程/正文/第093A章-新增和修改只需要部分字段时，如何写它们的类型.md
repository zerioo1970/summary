# 第 93A 章：新增和修改只需要部分字段时，如何写它们的类型？

前置：[第 93 章：【组合】如何从列表打开编辑，并在保存后显示最新结果？](第093章-如何从列表打开编辑，并在保存后显示最新结果.md)

## 一、本章要解决的问题

一条任务有 `id`、`title`、`completed` 三个字段，类型是 `Task`。但新增任务时，只需要提交名称：`id` 由服务器生成，`completed` 由服务器设为 `false`；修改任务时，有时只改名称，有时只改完成状态，每次只提交其中一部分字段。

第 92A 章（把任务请求集中到一个文件中）写的 `createTask(title)` 和 `updateTaskTitle(id, title)` 只能传名称。如果以后要修改完成状态，就得再写一个函数。如果另外手写一个只含部分字段的类型，`Task` 一改，这些类型就要跟着改，容易漏掉。

本章用 TypeScript 自带的两个工具类型，从 `Task` 直接得到“新增用的类型”和“修改用的类型”，并把修改函数改成可以修改任意字段的 `updateTask`。页面的功能不变；完成后，传错字段时检查命令会报错，例如新增时多传了 `id`。

## 二、必要原理

### 工具类型：从已有类型得到新类型

TypeScript 自带一些**工具类型**，作用是“输入一个类型，得到一个改造过的新类型”。写法和第 29 章的 `useState<number | null>` 一样，用尖括号把类型传进去。本章用两个：

| 工具类型 | 作用 | 例子 | 得到的类型 |
| --- | --- | --- | --- |
| `Omit<类型, 字段名>` | 去掉指定的字段 | `Omit<Task, 'id'>` | `{ title: string; completed: boolean }` |
| `Partial<类型>` | 所有字段都变成可选 | `Partial<Task>` | `{ id?: string; title?: string; completed?: boolean }` |

要去掉多个字段时，用 `|` 把字段名连起来，例如 `Omit<Task, 'id' | 'completed'>`。这里的 `|` 和第 29 章 `number | null` 中的一样，表示“或”。

新类型是从 `Task` 算出来的。以后给 `Task` 加一个字段，例如 `dueDate`，新增和修改的类型会自动带上它，不需要再改。

### 新增用的类型

新增任务时，`id` 和 `completed` 都不由用户提供，去掉这两个字段：

```tsx
export type NewTask = Omit<Task, 'id' | 'completed'>;
```

现在 `NewTask` 就是 `{ title: string }`。

### 修改用的类型：两个工具类型套在一起

修改任务时，`id` 不能改，其余字段都可以只提交一部分。先用 `Omit` 去掉 `id`，再用 `Partial` 把剩下的字段变成可选：

```tsx
export type TaskChanges = Partial<Omit<Task, 'id'>>;
```

从里往外读：`Omit<Task, 'id'>` 得到 `{ title: string; completed: boolean }`，`Partial` 再把它变成 `{ title?: string; completed?: boolean }`。所以 `{ title: '新名称' }`、`{ completed: true }`、两项都写，都符合这个类型；写了 `id`，或者 `completed` 写成字符串，检查命令都会报错。

如果直接写 `Partial<Task>`，`id` 也变成了可以提交的字段，类型就挡不住“修改时把 id 也改了”这种错误。

### 对象字面量中多写字段也会报错

调用 `createTask({ title, id: 'x' })` 时，花括号中直接写出的对象叫**对象字面量**。TypeScript 对对象字面量检查得最严：写了类型中没有的字段，就报错。这正好能发现“把不该提交的字段也传给了服务器”。

`{ title }` 是 `{ title: title }` 的简写：属性名和变量名相同时，可以只写一次。

## 三、动手实现

### 第 1 步：在任务类型文件中加入两个类型

打开 `src/types/task.ts`，在 `isTask` 函数的上面加入：

```ts
// 新增时 id 由服务器生成，completed 由服务器设为 false，只需要提供其余字段
export type NewTask = Omit<Task, 'id' | 'completed'>;

// 修改时可以只提交要改的字段，但 id 不能改
export type TaskChanges = Partial<Omit<Task, 'id'>>;
```

两个类型和 `Task` 放在同一个文件中，任何地方需要时都从这里导入，这是第 67 章（多个文件共用同一个数据类型）的做法。

### 第 2 步：请求函数改用新类型

打开 `src/lib/taskApi.ts`，把类型的导入改为：

```ts
import type { NewTask, Task, TaskChanges } from '../types/task';
```

把 `createTask` 的开头两行改为：

```ts
export async function createTask(newTask: NewTask): Promise<SaveResult> {
  const response = await send('/tasks', 'POST', newTask);
```

参数直接就是要提交的对象，原样作为请求正文发送。

把 `updateTaskTitle` 的开头两行改为：

```ts
export async function updateTask(id: string, changes: TaskChanges): Promise<SaveResult> {
  const response = await send('/tasks/' + id, 'PATCH', changes);
```

函数名去掉了 `Title`，因为它现在可以修改任意字段。练习服务的 `PATCH` 接口只修改正文中出现的字段，正好和 `TaskChanges` 对应。

### 第 3 步：修改页面中的调用

打开 `src/pages/TaskServerPage.tsx`，把导入请求函数的一行改为：

```tsx
import { createTask, deleteTask, fetchTasks, updateTask } from '../lib/taskApi';
```

在 `handleAdd` 中，把 `await createTask(title);` 改为：

```tsx
      const result = await createTask({ title });
```

在 `handleSaveEdit` 中，把 `await updateTaskTitle(id, title);` 改为：

```tsx
      const result = await updateTask(id, { title });
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 检查命令报 `Property 'id' is missing in type '{ title: string; }' but required in type 'NewTask'` | `Omit` 中的字段名写错了，例如写成 `'Id'`。`Omit` 不检查字段名是否存在，写错时什么也没去掉 | 字段名和 `Task` 中的完全一致，区分大小写 |
| 修改时传了 `id` 也不报错 | 修改类型写成了 `Partial<Task>`，`id` 也变成了可选字段 | 先去掉 `id`：`Partial<Omit<Task, 'id'>>` |
| 检查命令报 `has no exported member named 'updateTaskTitle'. Did you mean 'updateTask'?` | 函数改了名字，页面的导入还是旧名字 | 导入和调用都改成 `updateTask` |
| 检查命令报 `Object literal may only specify known properties` | 传给 `createTask` 或 `updateTask` 的对象中多写了类型中没有的字段 | 删掉多余的字段，只提交类型中有的字段 |

## 六、本章完整代码

### `src/types/task.ts`

```ts
export type Task = {
  id: string;
  title: string;
  completed: boolean;
};

// 新增时 id 由服务器生成，completed 由服务器设为 false，只需要提供其余字段
export type NewTask = Omit<Task, 'id' | 'completed'>;

// 修改时可以只提交要改的字段，但 id 不能改
export type TaskChanges = Partial<Omit<Task, 'id'>>;

export function isTask(value: unknown): value is Task {
  return (
    typeof value === 'object' &&
    value !== null &&
    'id' in value &&
    typeof value.id === 'string' &&
    'title' in value &&
    typeof value.title === 'string' &&
    'completed' in value &&
    typeof value.completed === 'boolean'
  );
}
```

### `src/lib/taskApi.ts`

```ts
import { apiUrl } from './api';
import { isTask } from '../types/task';
import type { NewTask, Task, TaskChanges } from '../types/task';

export type SaveResult =
  | { status: 'saved'; task: Task }
  | { status: 'invalid'; titleError: string };

async function send(path: string, method = 'GET', body?: unknown): Promise<Response> {
  const init: RequestInit = { method };
  if (body !== undefined) {
    init.headers = { 'Content-Type': 'application/json' };
    init.body = JSON.stringify(body);
  }
  try {
    return await fetch(apiUrl(path), init);
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
}

async function readTitleError(response: Response): Promise<string> {
  let data: unknown;
  try {
    data = await response.json();
  } catch {
    return '任务名称不符合要求。';
  }
  if (
    typeof data === 'object' &&
    data !== null &&
    'fieldErrors' in data &&
    typeof data.fieldErrors === 'object' &&
    data.fieldErrors !== null &&
    'title' in data.fieldErrors &&
    typeof data.fieldErrors.title === 'string'
  ) {
    return data.fieldErrors.title + '。';
  }
  return '任务名称不符合要求。';
}

async function readSaveResult(response: Response, action: string): Promise<SaveResult> {
  if (response.status === 422) {
    return { status: 'invalid', titleError: await readTitleError(response) };
  }
  if (!response.ok) {
    throw new Error(action + '失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (!isTask(data)) {
    throw new Error(action + '成功，但返回的数据格式不正确，请刷新页面查看。');
  }
  return { status: 'saved', task: data };
}

export async function fetchTasks(): Promise<Task[]> {
  const response = await send('/tasks');
  if (!response.ok) {
    throw new Error('任务读取失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (!Array.isArray(data) || !data.every(isTask)) {
    throw new Error('任务数据格式不正确，暂时无法显示。');
  }
  return data;
}

export async function createTask(newTask: NewTask): Promise<SaveResult> {
  const response = await send('/tasks', 'POST', newTask);
  return readSaveResult(response, '保存');
}

export async function updateTask(id: string, changes: TaskChanges): Promise<SaveResult> {
  const response = await send('/tasks/' + id, 'PATCH', changes);
  return readSaveResult(response, '修改');
}

export async function deleteTask(id: string): Promise<void> {
  const response = await send('/tasks/' + id, 'DELETE');
  if (!response.ok && response.status !== 404) {
    throw new Error('删除失败：服务器返回了状态 ' + response.status + '。');
  }
}
```

### `src/pages/TaskServerPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { SubmitEvent } from 'react';
import TaskEditor from '../components/TaskEditor';
import { createTask, deleteTask, fetchTasks, updateTask } from '../lib/taskApi';
import type { Task } from '../types/task';
import styles from './TaskPage.module.css';

type LoadState =
  | { status: 'loading'; tasks: Task[] }
  | { status: 'success'; tasks: Task[] }
  | { status: 'error'; message: string; tasks: Task[] };

function getErrorMessage(error: unknown) {
  return error instanceof Error ? error.message : '操作失败，请稍后重试。';
}

export default function TaskServerPage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'loading', tasks: [] });
  const [draft, setDraft] = useState('');
  const [titleError, setTitleError] = useState('');
  const [saveError, setSaveError] = useState('');
  const [isAdding, setIsAdding] = useState(false);
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editError, setEditError] = useState('');
  const [isSavingEdit, setIsSavingEdit] = useState(false);
  const tasks = loadState.tasks;
  const editingTask = tasks.find((task) => task.id === editingId);

  useEffect(() => {
    let ignore = false;

    async function loadOnOpen() {
      try {
        const data = await fetchTasks();
        if (!ignore) {
          setLoadState({ status: 'success', tasks: data });
        }
      } catch (error) {
        if (!ignore) {
          setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
        }
      }
    }

    loadOnOpen();
    return () => {
      ignore = true;
    };
  }, []);

  async function handleRetry() {
    setLoadState({ status: 'loading', tasks: [] });
    try {
      const data = await fetchTasks();
      setLoadState({ status: 'success', tasks: data });
    } catch (error) {
      setLoadState({ status: 'error', message: getErrorMessage(error), tasks: [] });
    }
  }

  async function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = draft.trim();
    if (title === '') {
      setTitleError('请填写任务名称。');
      return;
    }
    setTitleError('');
    setSaveError('');
    setIsAdding(true);
    try {
      const result = await createTask({ title });
      if (result.status === 'invalid') {
        setTitleError(result.titleError);
        return;
      }
      setDraft('');
      setLoadState((current) => ({ ...current, tasks: [...current.tasks, result.task] }));
    } catch (error) {
      setSaveError(getErrorMessage(error) + '输入的内容已保留。');
    } finally {
      setIsAdding(false);
    }
  }

  function handleStartEdit(id: string) {
    setEditingId(id);
    setEditError('');
  }

  async function handleSaveEdit(id: string, title: string) {
    setEditError('');
    setIsSavingEdit(true);
    try {
      const result = await updateTask(id, { title });
      if (result.status === 'invalid') {
        setEditError(result.titleError);
        return;
      }
      setEditingId(null);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.map((task) => (task.id === id ? result.task : task)),
      }));
    } catch (error) {
      setEditError(getErrorMessage(error));
    } finally {
      setIsSavingEdit(false);
    }
  }

  async function handleDelete(id: string) {
    if (id === editingId) {
      setEditingId(null);
    }
    setSaveError('');
    try {
      await deleteTask(id);
      setLoadState((current) => ({
        ...current,
        tasks: current.tasks.filter((task) => task.id !== id),
      }));
    } catch (error) {
      setSaveError(getErrorMessage(error));
    }
  }

  return (
    <main className="page">
      <h1>任务管理</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input
          id="new-task"
          value={draft}
          onChange={(event) => setDraft(event.target.value)}
          aria-invalid={titleError !== ''}
          aria-describedby={titleError ? 'new-task-error' : undefined}
        />
        <button type="submit" disabled={isAdding}>
          {isAdding ? '正在添加……' : '添加'}
        </button>
      </form>
      {titleError && (
        <p id="new-task-error" className={styles.error}>
          {titleError}
        </p>
      )}
      {saveError && <p role="alert">{saveError}</p>}
      {loadState.status === 'loading' && <p role="status">正在读取任务……</p>}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleRetry}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' && tasks.length === 0 && (
        <p className={styles.empty}>还没有任务。</p>
      )}
      {tasks.length > 0 && (
        <ul className={styles.list}>
          {tasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <span className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                {task.title}
              </span>
              <button
                type="button"
                onClick={() => handleStartEdit(task.id)}
                disabled={isSavingEdit}
              >
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingTask && (
        <TaskEditor
          key={editingTask.id}
          task={editingTask}
          onSave={(title) => handleSaveEdit(editingTask.id, title)}
          onCancel={() => setEditingId(null)}
          saving={isSavingEdit}
          error={editError}
        />
      )}
    </main>
  );
}
```

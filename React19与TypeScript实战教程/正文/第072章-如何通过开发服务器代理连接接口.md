# 第 72 章：如何通过开发服务器代理连接接口？

前置：[第 71 章：如何排查页面访问接口时的跨域错误？](第071章-如何排查页面访问接口时的跨域错误.md)

## 一、本章要解决的问题

上一章看到，页面在 5173 端口、接口在 3001 端口，跨域请求能否成功完全取决于服务器是否给了许可。开发时，后端还没配置许可、或者只允许了正式网站的地址，前端就没法调试。另外，代码中写死了 `http://127.0.0.1:3001`，换一台电脑或换一个端口都要改代码。

本章让 Vite 开发服务器替页面转发接口请求。页面只请求自己所在的 `/api/articles`，开发服务器收到后转给练习服务，再把结果交回页面。完成后，即使练习服务不给跨域许可（`?cors=off`），文章也能正常读取。

## 二、必要原理

### 代理：让请求变成同源

**代理**就是一个“转交”的中间人：

1. 页面请求 `http://127.0.0.1:5173/api/articles`，这和页面是同一个源，不存在跨域问题。
2. Vite 开发服务器发现地址以 `/api` 开头，就把请求原样转发给 `http://127.0.0.1:3001/api/articles`。
3. 练习服务返回数据，开发服务器再把它交给页面。

同源策略只是浏览器的规则。第 2 步是开发服务器（一个 Node.js 程序）直接向练习服务发请求，不经过浏览器，也就不受这条规则限制。

### 在 vite.config.js 中配置代理

`server.proxy` 中的每一项，左边是要转发的地址开头，右边是转发的目标：

```js
server: {
  proxy: {
    '/api': 'http://127.0.0.1:3001',
  },
},
```

意思是：凡是以 `/api` 开头的请求，都转给 `http://127.0.0.1:3001`，路径保持不变。

### 请求地址改成相对地址

页面中的地址只写路径 `/api/articles`，不写协议、主机和端口。以 `/` 开头的地址叫相对地址，浏览器会自动加上当前页面的源，得到 `http://127.0.0.1:5173/api/articles`。

### 代理只在开发时有效

代理是 Vite **开发服务器**的功能。运行 `npm.cmd run build` 打包后，网站会交给其他服务器托管，那里没有这个代理。正式环境怎样请求接口，下一章解决。

## 三、动手实现

### 第 1 步：配置代理

把 `vite.config.js` 改为：

```js
import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';

export default defineConfig({
  plugins: [react()],
  server: {
    proxy: {
      '/api': 'http://127.0.0.1:3001',
    },
  },
});
```

保存后，运行开发服务器的终端会提示配置已改变并自动重启。如果没有，按 Ctrl+C 停止，再运行 `npm.cmd run dev`。

### 第 2 步：改用相对地址

在 `src/pages/ArticlePage.tsx` 中，把请求的一行改为：

```tsx
      const response = await fetch('/api/articles');
```

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。

1. 点击“加载文章”，文章正常显示。
2. 在 Network（网络）面板中查看这次请求，Request URL 是 `http://127.0.0.1:5173/api/articles`，不再是 3001 端口。
3. 把地址临时改为 `'/api/articles?cors=off'`，文章仍然能读取，控制台没有 CORS 错误。看完后去掉。
4. 停止练习服务，点击“重新加载”，页面显示错误提示，Network 中这次请求的状态是 500，开发服务器的终端中有一条代理错误（`http proxy error`），说明开发服务器收到了请求，但转发失败。启动练习服务后重试正常。
5. 在浏览器中直接打开 `http://127.0.0.1:5173/api/articles`，也能看到文章数据。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 改了配置后仍然有 CORS 错误 | 请求地址还是 `http://127.0.0.1:3001/api/articles`，没有经过代理 | 改为相对地址 `/api/articles` |
| 页面提示无法连接练习服务，Network 中这次请求返回的却是网页 | 开发服务器没有重启，代理配置没有生效，`/api/articles` 被当成了页面地址，`response.json()` 读取网页时出错 | 重启开发服务器 |
| 请求没有被转发，练习服务终端中看不到它 | 请求地址漏了开头的 `/api`，例如写成了 `/articles` | 请求地址必须以代理配置中的 `/api` 开头 |
| 启动开发服务器时报配置文件语法错误 | `server` 前面的逗号或花括号漏写 | 对照第三节第 1 步检查标点 |
| 学完本章后，页面一直报错、一直显示空数据或加载很慢 | 步骤中临时加在请求地址上的 `?mode=`、`?fail=`、`?delay=`、`?cors=` 等参数忘了删 | 运行 `git diff` 查看本章改动，删掉地址中的临时参数 |

## 六、本章完整代码

### `vite.config.js`

内容同第三节第 1 步。

### `src/pages/ArticlePage.tsx`

```tsx
import { useState } from 'react';
import ArticleList from '../components/ArticleList';
import { isArticle } from '../types/article';
import type { Article } from '../types/article';

type LoadState =
  | { status: 'idle' }
  | { status: 'loading'; articles: Article[] }
  | { status: 'success'; articles: Article[] }
  | { status: 'error'; message: string; articles: Article[] };

export default function ArticlePage() {
  const [loadState, setLoadState] = useState<LoadState>({ status: 'idle' });
  const articles = loadState.status === 'idle' ? [] : loadState.articles;
  const hasLoaded = loadState.status === 'success' || articles.length > 0;

  async function handleLoad() {
    setLoadState({ status: 'loading', articles });
    try {
      const response = await fetch('/api/articles');
      if (!response.ok) {
        setLoadState({
          status: 'error',
          message: '文章读取失败：服务器返回了状态 ' + response.status + '。',
          articles,
        });
        return;
      }
      const data: unknown = await response.json();
      if (!Array.isArray(data) || !data.every(isArticle)) {
        setLoadState({ status: 'error', message: '文章数据格式不正确，暂时无法显示。', articles });
        return;
      }
      setLoadState({ status: 'success', articles: data });
    } catch {
      setLoadState({ status: 'error', message: '无法连接练习服务，请确认它已经启动。', articles });
    }
  }

  return (
    <main className="page">
      <h1>文章列表</h1>
      <button type="button" onClick={handleLoad} disabled={loadState.status === 'loading'}>
        {hasLoaded ? '重新加载' : '加载文章'}
      </button>
      {loadState.status === 'loading' && (
        <p role="status">{articles.length === 0 ? '正在加载文章……' : '正在更新……'}</p>
      )}
      {loadState.status === 'error' && (
        <div>
          <p role="alert">{loadState.message}</p>
          <button type="button" onClick={handleLoad}>
            重试
          </button>
        </div>
      )}
      {loadState.status === 'success' && articles.length === 0 && <p>暂时还没有文章。</p>}
      {articles.length > 0 && <ArticleList articles={articles} />}
    </main>
  );
}
```

## 七、本章改动小结

修改 `vite.config.js`：加入 `/api` 代理；修改 `src/pages/ArticlePage.tsx`：请求地址改为相对地址。

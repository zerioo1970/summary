# 第 15 章：如何避免不同组件的 CSS 样式互相影响？

前置：[第 14 章：如何避免长文字把卡片撑出屏幕？](第014章-如何避免长文字把卡片撑出屏幕.md)

## 一、本章要解决的问题

到现在为止，所有样式都写在 `App.css` 里。`App.css` 中的类名对整个页面生效：如果以后别的组件也用了 `profile-role` 这个类名，或者有人在 `App.css` 中又写了一条同名规则，卡片的样子就会被意外改掉。项目越大，组件越多，这种问题越难发现。

本章把资料卡片的样式移到它自己的样式文件中，使用 CSS Modules，让卡片的类名只对卡片组件生效。完成后，页面外观不变，但即使在 `App.css` 中写了同名的类，也影响不到卡片。

## 二、必要原理

### 普通 CSS 文件对整个页面生效

第 4 章说过，`import './App.css'` 导入的样式会加到整个页面上。CSS 本身没有“只属于某个组件”的概念，类名就是全局的名字。两条同名规则，后写的会覆盖先写的。

### CSS Modules：给类名自动加上唯一后缀

文件名以 `.module.css` 结尾的样式文件，Vite 会把它当作 **CSS Module** 处理：文件中的每个类名都会被自动改成一个不会重复的名字，例如 `.role` 变成类似 `_role_x7k2a_12` 的样子。

在组件中这样导入：

```tsx
import styles from './ProfileCard.module.css';
```

`styles` 是一个对象，属性名是你在 CSS 中写的类名，值是改写后的真实类名：

```tsx
<p className={styles.role}>
```

`styles.role` 的值就是 `_role_x7k2a_12` 这样的字符串，浏览器中元素的 `class` 也是它。别的文件即使也写了 `.role`，改写后的名字不同，互不影响。

因为类名只在这个组件中使用，可以起简短的名字，例如 `card`、`role`、`note`，不用再加 `profile-` 前缀。

### 哪些样式留在 App.css

- 整个页面通用的样式，例如 `body`、`.page`，留在 `App.css`。
- 只属于资料卡片的样式，移到 `ProfileCard.module.css`。
- 卡片在列表中怎样排列（宽度、换行），是列表的事，留在 `App.css` 的 `.card-list` 中。

卡片的类名改写后，`App.css` 无法再用 `.profile-card` 选中卡片。列表的规则改为 `.card-list > *`：`>` 表示“直接的子元素”，`*` 表示“任意元素”，合起来就是“列表里的每一项”。

## 三、动手实现

### 第 1 步：先看看全局样式的问题

在 `src/App.css` 最末尾临时加入：

```css
.profile-role {
  color: red;
}
```

假设这是同事为别的页面写的，本意只想改他自己页面上的文字。保存后，三张卡片的身份文字都变成了红色。看完后删掉这几行。

### 第 2 步：新建卡片的样式模块

在 `src/components` 中新建 `ProfileCard.module.css`：

```css
.card {
  padding: 16px 20px;
  border: 1px solid #d9e2ec;
  border-radius: 12px;
  background: #ffffff;
  overflow-wrap: anywhere;
}

.card h2 {
  margin: 0 0 8px;
}

.avatar {
  display: block;
  margin-bottom: 12px;
  border-radius: 50%;
}

.role {
  color: #52606d;
}

.note {
  margin-bottom: 0;
  color: #52606d;
  font-size: 14px;
}
```

内容就是 `App.css` 中卡片相关的规则，只是类名去掉了 `profile-` 前缀。第 14 章的 `overflow-wrap: anywhere` 也移到了 `.card` 中：防止长文字撑开卡片，是卡片自己的需要，在哪里使用卡片都应该有效。

### 第 3 步：在组件中使用样式模块

打开 `src/components/ProfileCard.tsx`，在第一行导入样式：

```tsx
import styles from './ProfileCard.module.css';
```

把 JSX 中的四个类名改为读取 `styles`：

```tsx
    <article className={styles.card}>
      <img
        className={styles.avatar}
```

```tsx
      <p className={styles.role}>{profile.role}</p>
```

```tsx
      <p className={styles.note}>留言：{note}</p>
```

### 第 4 步：从 App.css 中删除卡片样式

打开 `src/App.css`，删除 `.profile-card`、`.profile-card h2`、`.profile-role`、`.profile-avatar`、`.profile-note` 五段规则。再把最后一段改为：

```css
.card-list > * {
  flex: 1 1 200px;
}
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面外观与第 14 章完全相同：三张卡片的边框、圆角、头像、灰色文字都在，小陈的网址仍然在卡片内折行；窄屏时卡片照常换行。
2. 按 F12，在 Elements（元素）面板中选中卡片，`class` 是类似 `_card_x7k2a_1` 的名字，而不是 `card`。具体的字母因电脑而异。
3. 在 `App.css` 末尾临时加入 `.role { color: red; }`，保存。卡片中的身份文字**没有**变红，因为卡片真正的类名不是 `role`。检查后删掉。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：仿照本章，把页脚的样式从 `App.css` 移到 `src/components/PageFooter.module.css` 中，类名改为 `.footer`。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 卡片样式全部消失 | 文件名写成了 `ProfileCard.css`，少了 `.module`，导入后 `styles` 中没有类名 | 文件名必须以 `.module.css` 结尾 |
| 某个元素没有样式，在 Elements 面板中看不到它的 `class` 属性 | `styles.` 后面的名字与 CSS 中的类名不一致，例如 CSS 写的是 `.note`，代码写成了 `styles.notes` | 核对两边的拼写 |
| 写成了 `className="styles.card"` 后没有样式 | 加了引号，变成了普通文字 | 写成 `className={styles.card}` |
| 卡片在列表中不再换行、宽度不一 | `App.css` 中还是 `.card-list .profile-card`，选不中卡片了 | 改成 `.card-list > *` |
| 小陈的网址又撑出了卡片 | 删除 `App.css` 中的规则时，没有把 `overflow-wrap` 移到 `.card` 中 | 对照第三节第 2 步 |

## 六、本章完整代码

### `src/components/ProfileCard.module.css`

内容同第三节第 2 步。

### `src/components/ProfileCard.tsx`

```tsx
import styles from './ProfileCard.module.css';

export type Profile = {
  name: string;
  role: string;
  intro: string;
  avatar: string;
};

type ProfileCardProps = {
  profile: Profile;
  note?: string;
};

export default function ProfileCard({ profile, note = '还没有留言。' }: ProfileCardProps) {
  return (
    <article className={styles.card}>
      <img
        className={styles.avatar}
        src={profile.avatar}
        alt={profile.name + '的头像'}
        width="96"
        height="96"
      />
      <h2>{profile.name}</h2>
      <p className={styles.role}>{profile.role}</p>
      <p>
        我是{profile.name}，{profile.intro}
      </p>
      <p className={styles.note}>留言：{note}</p>
    </article>
  );
}
```

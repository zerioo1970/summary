# 第 52 章：【组合】如何让编辑框在点击“取消”后恢复原来的内容？

前置：[第 51 章：为什么直接修改数组中的任务，页面有时不会更新？](第051章-为什么直接修改数组中的任务，页面有时不会更新.md)

## 一、本章要解决的问题

点开一条任务的编辑框后，如果改了几个字又不想改了，现在没有办法退出：编辑框一直开着，只能保存，或者删掉这条任务。

本章给编辑框加一个“取消”按钮。点击后编辑框关闭，任务名称保持原样；再次点击“编辑”，编辑框中是原来的名称，而不是刚才输入到一半的内容。

本章是一个组合练习，用到第 47 章的编辑状态、第 40 章的按钮类型和第 49 章的条件显示。

## 二、必要原理

### 取消为什么这么简单

回想第 47 章的设计：输入时只修改 `editDraft`，点击保存时才把它写回 `tasks`。所以在点击“取消”之前，`tasks` 中的任务名称从来没有被动过。

取消只需要做一件事：把 `editingId` 设回 `null`，编辑框就关闭了。没有任何东西需要“恢复”，因为原来的数据一直都在。

如果第 47 章写成“输入一个字就改一次 `tasks`”，现在就麻烦了：要想恢复，得在开始编辑时另外保存一份原来的名称，取消时再写回去。**把正在编辑的草稿和正式数据分开存放**，是表单中很常用的做法，第 91 章保存失败时保留输入，用的也是同一个思路。

### 再次编辑时为什么不会留着上次的输入

取消时没有清空 `editDraft`，它还保留着刚才输入到一半的内容。但再次点击“编辑”时，`handleStartEdit` 会执行 `setEditDraft(task.title)`，用这条任务当前的名称覆盖草稿。所以编辑框中总是原来的名称。

### 取消按钮必须是 type="button"

“取消”按钮放在编辑框的 `<form>` 中。第 40 章说过，表单中的按钮不写 `type` 时默认是提交按钮，点击“取消”会触发 `onSubmit`，变成了保存。所以一定要写 `type="button"`。

### 处理只有一行时可以直接写在 JSX 中

取消只调用一次 `setEditingId(null)`，和第 49 章“只看未完成”的复选框一样，可以直接写成箭头函数：

```tsx
onClick={() => setEditingId(null)}
```

## 三、动手实现

### 第 1 步：加入取消按钮

在 `src/pages/TaskPage.tsx` 的编辑框中，“保存”按钮的后面加入：

```tsx
          <button type="submit" disabled={editDraft.trim() === ''}>
            保存
          </button>
          <button type="button" onClick={() => setEditingId(null)}>
            取消
          </button>
```

前三行是原有的保存按钮，用来确认位置。编辑框是 Flex 布局，取消按钮排在保存按钮的右边。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 点击“完成注册表单练习”的“编辑”，编辑框中有“保存”和“取消”两个按钮。
2. 把内容改成“随便改改”，点击“取消”。编辑框关闭，列表中仍是“完成注册表单练习”。
3. 再次点击它的“编辑”，编辑框中是“完成注册表单练习”，不是“随便改改”。
4. 清空编辑框，“保存”变成半透明，但“取消”仍可点击，点击后编辑框关闭。
5. 修改名称后按 Enter，仍然是保存，不受取消按钮影响。
6. 用 Tab 键移到“取消”按钮上，按 Enter，编辑框关闭，名称没有变化。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 点击“取消”后名称被改了 | 取消按钮没有写 `type`，默认提交了表单 | 写 `type="button"` |
| 点击“取消”后名称已经变了，没法恢复 | 输入时直接修改了 `tasks` | 输入时只修改 `editDraft`，保存时再写回 |
| 再次编辑时显示的是上次没保存的内容 | 开始编辑时没有用任务名称覆盖草稿 | `handleStartEdit` 中执行 `setEditDraft(task.title)` |
| 编辑器在取消按钮的 `onClick` 处报类型错误 | 写成了 `onClick={setEditingId(null)}`，传给 `onClick` 的是调用结果，不是函数 | 写成 `onClick={() => setEditingId(null)}` |

## 六、本章完整代码

### `src/pages/TaskPage.tsx`

```tsx
import { useState } from 'react';
import type { ChangeEvent, SubmitEvent } from 'react';
import { initialTasks } from '../data/tasks';
import type { Task } from '../data/tasks';
import styles from './TaskPage.module.css';

export default function TaskPage() {
  const [tasks, setTasks] = useState<Task[]>(initialTasks);
  const [newTitle, setNewTitle] = useState('');
  const [editingId, setEditingId] = useState<string | null>(null);
  const [editDraft, setEditDraft] = useState('');
  const [hideCompleted, setHideCompleted] = useState(false);
  const visibleTasks = hideCompleted ? tasks.filter((task) => !task.completed) : tasks;
  const remainingCount = tasks.filter((task) => !task.completed).length;

  function handleNewTitleChange(event: ChangeEvent<HTMLInputElement>) {
    setNewTitle(event.target.value);
  }

  function handleAdd(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = newTitle.trim();
    if (title === '') {
      return;
    }
    const newTask: Task = { id: crypto.randomUUID(), title, completed: false };
    setTasks([...tasks, newTask]);
    setNewTitle('');
  }

  function handleDelete(id: string) {
    setTasks(tasks.filter((task) => task.id !== id));
    if (id === editingId) {
      setEditingId(null);
    }
  }

  function handleToggle(id: string) {
    setTasks(
      tasks.map((task) => (task.id === id ? { ...task, completed: !task.completed } : task)),
    );
  }

  function handleStartEdit(task: Task) {
    setEditingId(task.id);
    setEditDraft(task.title);
  }

  function handleEditDraftChange(event: ChangeEvent<HTMLInputElement>) {
    setEditDraft(event.target.value);
  }

  function handleSaveEdit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    const title = editDraft.trim();
    if (title === '') {
      return;
    }
    setTasks(tasks.map((task) => (task.id === editingId ? { ...task, title } : task)));
    setEditingId(null);
  }

  return (
    <main className="page">
      <h1>待办事项</h1>
      <form className={styles.addForm} onSubmit={handleAdd}>
        <label htmlFor="new-task">新任务</label>
        <input id="new-task" value={newTitle} onChange={handleNewTitleChange} />
        <button type="submit" disabled={newTitle.trim() === ''}>
          添加
        </button>
      </form>
      <div className={styles.toolbar}>
        <span>{remainingCount === 0 ? '全部完成了！' : '还有 ' + remainingCount + ' 项未完成'}</span>
        <label>
          <input
            type="checkbox"
            checked={hideCompleted}
            onChange={(event) => setHideCompleted(event.target.checked)}
          />
          只看未完成
        </label>
      </div>
      {visibleTasks.length === 0 ? (
        <p className={styles.empty}>没有需要显示的任务。</p>
      ) : (
        <ul className={styles.list}>
          {visibleTasks.map((task) => (
            <li key={task.id} className={styles.item}>
              <label className={task.completed ? styles.title + ' ' + styles.done : styles.title}>
                <input
                  type="checkbox"
                  checked={task.completed}
                  onChange={() => handleToggle(task.id)}
                />
                {task.title}
              </label>
              <button type="button" onClick={() => handleStartEdit(task)}>
                编辑
              </button>
              <button
                type="button"
                aria-label={'删除：' + task.title}
                onClick={() => handleDelete(task.id)}
              >
                删除
              </button>
            </li>
          ))}
        </ul>
      )}
      {editingId !== null && (
        <form className={styles.editor} onSubmit={handleSaveEdit}>
          <label htmlFor="edit-task">修改任务名称</label>
          <input id="edit-task" value={editDraft} onChange={handleEditDraftChange} />
          <button type="submit" disabled={editDraft.trim() === ''}>
            保存
          </button>
          <button type="button" onClick={() => setEditingId(null)}>
            取消
          </button>
        </form>
      )}
    </main>
  );
}
```

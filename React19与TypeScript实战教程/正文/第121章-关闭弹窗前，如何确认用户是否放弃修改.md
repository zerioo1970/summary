# 第 121 章：【组合】关闭弹窗前，如何确认用户是否放弃修改？

前置：[第 120 章：如何让弹窗中的表单把结果交回页面？](第120章-如何让弹窗中的表单把结果交回页面.md)

## 一、本章要解决的问题

在新建便签的弹窗中写了一大段内容，不小心按了 Esc，或者点到了“取消”，弹窗一关，写的东西全没了。表单中已经填了内容时，关闭之前应该先问一句。

本章让新建便签的弹窗在关闭前确认。完成后：表单是空的时候，点“取消”“×”、点遮罩、按 Esc，弹窗直接关闭；填了内容以后，这四种方式都会先弹出“填写的内容还没有保存，确定要放弃吗？”，点“取消”留在弹窗中，内容还在，点“确定”才关闭；点“保存”不会询问。

本章不引入新的技术，组合的是：浏览器自带的确认对话框（第 93B 章）、点击遮罩关闭（第 117 章）、从 state 算出的值（第 32 章）和弹窗组件（第 120 章）。

## 二、必要原理

### 有没有填内容，是算出来的

“表单中有没有内容”由两个 state 决定，直接算出来即可（第 32 章）：

```tsx
const hasChanges = draftTitle.trim() !== '' || draftContent.trim() !== '';
```

只输入了几个空格不算有内容。

### 四种关闭方式，分成两类处理

| 关闭方式 | 怎样关闭 | 怎样拦下 |
| --- | --- | --- |
| “×”、“取消”、点遮罩 | 由我们的代码调用 `close()` | 调用之前先确认，用户不同意就不调用 |
| 按 Esc | 由浏览器关闭 | 在 `cancel` 事件中调用 `event.preventDefault()` |

前三种都由我们自己调用 `close()`，所以把它们集中到一个函数 `handleRequestClose` 中：先确认，同意了再关闭。点遮罩的判断和第 117 章一样，判断成立后也调用它。

按 Esc 时，浏览器在关闭弹窗之前，先在 `dialog` 上触发一个 `cancel` 事件。React 中用 `onCancel` 接收它。在处理函数中调用 `event.preventDefault()`，浏览器就不关闭了，这和第 40 章阻止表单提交是同一个方法。这个事件没有专门的类型，用通用的 `SyntheticEvent<HTMLDialogElement>`。

浏览器为了不让页面“永远关不掉”，在某些情况下会忽略对 Esc 的阻止：例如用户连续按两次 Esc，中间没有任何点击或输入，第二次可能直接关闭弹窗。所以不能只靠 Esc 的确认来保护重要的数据，内容很重要时，还应该保存草稿。

### 确认的写法只写一次

四种方式要问的是同一个问题，写成一个返回真假的函数：

```tsx
function confirmDiscard() {
  return !hasChanges || window.confirm('填写的内容还没有保存，确定要放弃吗？');
}
```

没有内容时 `!hasChanges` 为 `true`，`||` 后面的确认框根本不会弹出，直接返回 `true`；有内容时才弹出确认框，用户点“确定”返回 `true`，点“取消”返回 `false`。

### 保存时不要询问

保存成功后也要关闭弹窗，这时表单中当然有内容，但已经保存了，不应该再问“确定要放弃吗”。所以关闭分成两个函数：`closeDialog` 只管关闭，保存后调用它；`handleRequestClose` 先确认再关闭，给“×”“取消”和遮罩使用。

## 三、动手实现

### 第 1 步：导入事件类型，计算是否有内容

打开 `src/components/NoteFormDialog.tsx`，把导入事件类型的一行改为：

```tsx
import type { MouseEvent, SubmitEvent, SyntheticEvent } from 'react';
```

在 `titleInputRef` 那一行的下面加入：

```tsx
  const hasChanges = draftTitle.trim() !== '' || draftContent.trim() !== '';
```

### 第 2 步：拆分关闭函数，加入确认

把原来的 `handleClose` 函数替换为下面几个函数：

```tsx
  function closeDialog() {
    if (dialogRef.current) {
      dialogRef.current.close();
    }
  }

  // 填了内容还没保存时，先问一句；用户点“取消”就留在弹窗中
  function confirmDiscard() {
    return !hasChanges || window.confirm('填写的内容还没有保存，确定要放弃吗？');
  }

  // “×”“取消”和点遮罩都走这里
  function handleRequestClose() {
    if (confirmDiscard()) {
      closeDialog();
    }
  }

  // 按 Esc 时浏览器先触发 cancel 事件，阻止它就不会关闭
  function handleCancel(event: SyntheticEvent<HTMLDialogElement>) {
    if (!confirmDiscard()) {
      event.preventDefault();
    }
  }

  function handleDialogClick(event: MouseEvent<HTMLDialogElement>) {
    if (event.target === event.currentTarget) {
      handleRequestClose();
    }
  }
```

### 第 3 步：保存后直接关闭

在 `handleSubmit` 的最后，把 `handleClose();` 改为：

```tsx
    // 已经保存了，不需要再问
    closeDialog();
```

### 第 4 步：把处理函数接到弹窗上

在 `dialog` 的 `onClose={onClose}` 下面加两行：

```tsx
      onCancel={handleCancel}
      onClick={handleDialogClick}
```

把“×”按钮和“取消”按钮的 `onClick` 都改为 `handleRequestClose`。

弹窗的内边距已经在里层的 `.body` 上（第 120 章），点白框的边缘不会被当成点遮罩。

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 打开便签页，点“新建便签”，什么也不填，点“取消”，弹窗直接关闭，没有询问。再打开，点遮罩，也直接关闭。
2. 再打开，在标题中输入“草稿”。点“取消”，弹出“填写的内容还没有保存，确定要放弃吗？”，点确认框中的“取消”，仍然留在弹窗中，“草稿”还在。
3. 依次点“×”、点遮罩、按 Esc，每次都先弹出同样的确认，点确认框中的“取消”后都留在弹窗中。
4. 按 Esc，在确认框中点“确定”，弹窗关闭。再打开，表单是空的。
5. 输入标题“要保存”，点“保存”，没有询问，弹窗关闭，列表最后多了“要保存”。
6. 只在标题中输入几个空格，点“取消”，直接关闭，没有询问。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 点“保存”时也弹出“确定要放弃吗” | 保存后调用的是先确认再关闭的 `handleRequestClose` | 保存后调用只负责关闭的 `closeDialog` |
| 点“取消”会询问，按 Esc 却直接关闭了 | 只处理了按钮，没有处理 `cancel` 事件 | 在 `dialog` 上写 `onCancel={handleCancel}`，不同意时 `event.preventDefault()` |
| 表单是空的，点“取消”也要确认一次 | 没有先判断 `hasChanges`，每次都调用 `confirm` | 写成 `!hasChanges \|\| window.confirm(…)` |
| 在 `onClose` 中调用 `preventDefault()`，弹窗照样关闭 | `close` 事件发生时弹窗已经关了，不能再阻止 | 要阻止 Esc 关闭，写在 `onCancel` 中 |

## 六、本章完整代码

### `src/components/NoteFormDialog.tsx`

```tsx
import { useEffect, useRef, useState } from 'react';
import type { MouseEvent, SubmitEvent, SyntheticEvent } from 'react';
import TextField from './TextField';
import type { NoteInput } from '../data/notes';
import styles from './NoteFormDialog.module.css';

type NoteFormDialogProps = {
  // 保存时把填好的便签交给页面，由页面决定怎样加入列表
  onSave: (note: NoteInput) => void;
  // 弹窗关闭时通知页面，不论是保存、取消还是按 Esc
  onClose: () => void;
};

export default function NoteFormDialog({ onSave, onClose }: NoteFormDialogProps) {
  const [draftTitle, setDraftTitle] = useState('');
  const [draftContent, setDraftContent] = useState('');
  const [titleError, setTitleError] = useState('');
  const dialogRef = useRef<HTMLDialogElement>(null);
  const titleInputRef = useRef<HTMLInputElement>(null);
  const hasChanges = draftTitle.trim() !== '' || draftContent.trim() !== '';

  // 组件一出现在页面上就打开弹窗；组件被移除时，弹窗随元素一起消失
  useEffect(() => {
    const dialog = dialogRef.current;
    if (!dialog) {
      return;
    }
    dialog.showModal();
    if (titleInputRef.current) {
      titleInputRef.current.focus();
    }
  }, []);

  function closeDialog() {
    if (dialogRef.current) {
      dialogRef.current.close();
    }
  }

  // 填了内容还没保存时，先问一句；用户点“取消”就留在弹窗中
  function confirmDiscard() {
    return !hasChanges || window.confirm('填写的内容还没有保存，确定要放弃吗？');
  }

  // “×”“取消”和点遮罩都走这里
  function handleRequestClose() {
    if (confirmDiscard()) {
      closeDialog();
    }
  }

  // 按 Esc 时浏览器先触发 cancel 事件，阻止它就不会关闭
  function handleCancel(event: SyntheticEvent<HTMLDialogElement>) {
    if (!confirmDiscard()) {
      event.preventDefault();
    }
  }

  function handleDialogClick(event: MouseEvent<HTMLDialogElement>) {
    if (event.target === event.currentTarget) {
      handleRequestClose();
    }
  }

  function handleSubmit(event: SubmitEvent<HTMLFormElement>) {
    event.preventDefault();
    if (draftTitle.trim() === '') {
      setTitleError('请填写标题。');
      // 把光标送到出错的输入框，用户可以直接补填
      if (titleInputRef.current) {
        titleInputRef.current.focus();
      }
      return;
    }
    onSave({ title: draftTitle.trim(), content: draftContent.trim() });
    // 已经保存了，不需要再问
    closeDialog();
  }

  return (
    <dialog
      ref={dialogRef}
      className={styles.dialog}
      aria-labelledby="create-title"
      onClose={onClose}
      onCancel={handleCancel}
      onClick={handleDialogClick}
    >
      <div className={styles.body}>
        <div className={styles.header}>
          <h2 id="create-title">新建便签</h2>
          <button type="button" aria-label="关闭" onClick={handleRequestClose}>
            ×
          </button>
        </div>
        <form className={styles.form} onSubmit={handleSubmit}>
          <TextField
            ref={titleInputRef}
            id="note-title"
            label="标题"
            value={draftTitle}
            onChange={setDraftTitle}
            error={titleError}
          />
          <label htmlFor="note-content">内容</label>
          <textarea
            id="note-content"
            rows={4}
            value={draftContent}
            onChange={(event) => setDraftContent(event.target.value)}
          />
          <div className={styles.actions}>
            <button type="button" onClick={handleRequestClose}>
              取消
            </button>
            <button type="submit">保存</button>
          </div>
        </form>
      </div>
    </dialog>
  );
}
```

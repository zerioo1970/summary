# 第 25 章：为什么修改普通变量后，页面没有跟着变化？

前置：[第 24 章：如何在点击按钮时执行一段代码？](第024章-如何在点击按钮时执行一段代码.md)

## 一、本章要解决的问题

常见问题页要加一个投票按钮：“有帮助（0）”，每点一次，括号里的数字加 1。按第 24 章学的方法，写一个变量保存次数，点击时让它加 1，看起来很简单。

可是写出来以后，无论点多少次，按钮上的数字一直是 0。本章找出原因：变量确实变了，为什么页面不变？完成后，你能说清楚“变量改变”和“页面更新”是两回事。本章的计数按钮暂时还不能正常工作，第 26 章修好它。

## 二、必要原理

### 组件函数运行一次，生成一次页面

React 显示一个组件时，会调用这个组件函数，拿到它返回的 JSX，再更新到浏览器中。这个过程叫**渲染**。

渲染时，函数从上到下执行：`let helpfulCount = 0` 声明变量，JSX 中的 `{helpfulCount}` 读取它当时的值 0。React 拿到的是一份“按钮上写着 0”的描述，页面就显示 0。函数执行完，这一次渲染就结束了。

### 修改变量不会让 React 重新渲染

点击按钮时，事件处理函数让 `helpfulCount` 变成了 1。但 React 并不知道这件事：普通变量的变化不会通知 React。React 没有收到通知，就不会再调用组件函数，页面上仍然是上一次渲染的结果，也就是 0。

页面上的数字就像渲染那一刻拍下的一张照片，不会自动跟着变量变化。

### 就算重新渲染，普通变量也会被重置

假设因为别的原因，React 重新调用了 `FaqPage` 函数，会发生什么？函数从头执行，`let helpfulCount = 0` 又把它设回了 0。组件函数中的普通变量，每次渲染都会重新创建，记不住上一次的值。

所以普通变量有两个问题：

1. 修改它不会通知 React 更新页面；
2. 每次渲染它都会回到初始值。

React 提供的 **state** 同时解决这两个问题，第 26 章学习。

### 为什么不直接修改页面上的文字

你可能想到：找到按钮元素，直接把它的文字改成新数字。这样做会绕过 React：React 不知道页面被改了，下次渲染时又会用自己的描述覆盖掉你的修改。在 React 中，页面显示什么应该由数据决定，改数据而不是改页面元素。

## 三、动手实现

本章写出的计数按钮**暂时不能正常工作**，用来观察问题，第 26 章修好它。

### 第 1 步：添加投票区域

打开 `src/pages/FaqPage.tsx`，在 `handleContactClick` 的上方加入一个变量和一个事件处理函数：

```tsx
  let helpfulCount = 0;

  function handleHelpfulClick() {
    helpfulCount = helpfulCount + 1;
    console.log('helpfulCount 现在是', helpfulCount);
  }
```

- `let` 声明一个可以重新赋值的变量，`const` 声明的变量不能再赋值。
- `console.log` 把内容输出到浏览器控制台，用来观察变量的值。

### 第 2 步：在页面上显示按钮

在 `<h1>常见问题</h1>` 的下面加入投票区域：

```tsx
      <section className={styles.section}>
        <h2>这些回答对你有帮助吗？</h2>
        <button type="button" onClick={handleHelpfulClick}>
          有帮助（{helpfulCount}）
        </button>
      </section>
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 页面出现“这些回答对你有帮助吗？”和按钮“有帮助（0）”。
2. 按 F12 打开控制台（Console 面板），点击按钮三次。控制台依次输出“helpfulCount 现在是 1”“2”“3”，说明事件处理函数执行了，变量也确实增加了。
3. 但按钮上始终显示“有帮助（0）”。这是本章要观察的现象，不是你写错了。
4. 刷新页面，再点击一次，控制台输出又从 1 开始。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

检查通过，说明代码没有语法和类型错误。这个问题不是写法错误，而是用错了保存数据的方式，检查工具发现不了。

**小练习**：在 `let helpfulCount = 0;` 的下一行加一句 `console.log('FaqPage 渲染了');`，刷新页面后点击按钮几次，观察这句话输出了几次。点击按钮时它有没有再次输出？这说明了什么？练习后删除这一行。（开发环境中，页面刚打开时这句话可能输出两次，第 75 章会解释原因，现在可以先忽略。）

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 控制台中数字在增加，页面上一直是 0 | 普通变量的变化不会让 React 重新渲染 | 这正是本章的现象，第 26 章用 state 解决 |
| 编辑器提示不能给常量赋值 | 用 `const` 声明了 `helpfulCount`，又在函数中给它赋新值 | 本章用 `let`；第 26 章会改用 state |
| 控制台中什么都没有输出 | 控制台没有打开，或者筛选设置隐藏了普通日志 | 确认在 Console 面板，筛选中勾选了“信息”（Info） |
| 想用 `document.querySelector` 找到按钮直接改文字 | 绕过了 React，下次渲染会被覆盖 | 页面内容由数据决定，修改数据 |
| 把变量移到组件函数外面，数字还是不变 | 放在外面能记住值，但仍然不会通知 React 更新 | 用 state |

## 六、本章完整代码

### `src/pages/FaqPage.tsx`

```tsx
import styles from './FaqPage.module.css';

export default function FaqPage() {
  let helpfulCount = 0;

  function handleHelpfulClick() {
    helpfulCount = helpfulCount + 1;
    console.log('helpfulCount 现在是', helpfulCount);
  }

  function handleContactClick() {
    window.alert('客服邮箱：help@example.com，工作日 9:00—18:00 回复。');
  }

  return (
    <main className="page">
      <h1>常见问题</h1>
      <section className={styles.section}>
        <h2>这些回答对你有帮助吗？</h2>
        <button type="button" onClick={handleHelpfulClick}>
          有帮助（{helpfulCount}）
        </button>
      </section>
      <section className={styles.section}>
        <p>没有找到答案？</p>
        <button type="button" onClick={handleContactClick}>
          联系客服
        </button>
      </section>
    </main>
  );
}
```

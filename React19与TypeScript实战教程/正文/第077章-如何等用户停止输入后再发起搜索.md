# 第 77 章：如何等用户停止输入后再发起搜索？

前置：[第 76 章：如何在搜索关键词变化后重新请求数据？](第076章-如何在搜索关键词变化后重新请求数据.md)

## 一、本章要解决的问题

上一章输入 `type` 时发出了 4 个请求：`t`、`ty`、`typ`、`type`。用户真正想搜的只有最后一个，前面 3 个都是白白浪费，服务器要多处理 3 次，网络慢时还会让结果来回跳动。

本章让搜索等用户停下来：输入期间不发请求，最后一次按键后过 0.5 秒还没有新的输入，才按当前的关键词搜索。这种做法叫**防抖**。

## 二、必要原理

### 两个关键词

现在需要区分两个值：

- `keyword`：输入框中当前的内容，每按一个键都变化，输入框要立即显示它。
- `debouncedKeyword`：“停顿下来”的关键词，用户停止输入 0.5 秒后才跟上 `keyword`。

搜索的 Effect 改为依赖 `debouncedKeyword`。快速输入 `type` 时，`debouncedKeyword` 只变化一次，于是只搜索一次。

### setTimeout 和 clearTimeout

浏览器的 `setTimeout(函数, 毫秒)` 在指定时间后执行一次函数，并返回一个编号；`clearTimeout(编号)` 取消还没执行的那一次。

### 用 Effect 实现防抖

```tsx
useEffect(() => {
  const timerId = setTimeout(() => {
    setDebouncedKeyword(keyword);
  }, 500);
  return () => {
    clearTimeout(timerId);
  };
}, [keyword]);
```

逐步看输入 `ty` 的过程：

1. 输入 `t`：`keyword` 变成 `t`，Effect 执行，安排 0.5 秒后把 `debouncedKeyword` 设为 `t`。
2. 0.2 秒后输入 `y`：`keyword` 变成 `ty`。Effect 重新执行之前，React 先执行上一次的清理函数，取消了还没执行的那次 `t`；然后安排 0.5 秒后设为 `ty`。
3. 之后不再输入：0.5 秒到了，`debouncedKeyword` 变成 `ty`，搜索的 Effect 执行，发出请求。

清理函数在这里不是可有可无的：没有它，每个字安排的定时任务都会执行，又回到了每个字一个请求。

### “正在搜索”改到搜索真正开始时再显示

上一章在 `handleKeywordChange` 中设置状态：每输入一个字，就把状态设为 `loading`（清空时设为 `idle`）。加上防抖以后，这样写会出问题：

1. 输入 `type`，0.5 秒后搜索完成，显示结果。此时 `debouncedKeyword` 是 `type`。
2. 多输入一个 `s`，处理函数立刻把状态设为 `loading`，页面显示“正在搜索……”。
3. 发现打错了，在 0.5 秒内删掉 `s`。输入框又是 `type`。
4. 0.5 秒后，防抖的 Effect 把 `debouncedKeyword` 设为 `type`。它本来就是 `type`，**没有变化**，所以搜索的 Effect 不会重新执行，也就没有任何代码把状态从 `loading` 改回来。页面一直显示“正在搜索……”。

问题出在设置状态的位置：处理函数说“要搜索了”，可真正决定搜不搜的是搜索的 Effect。所以把设置状态的代码移进搜索的 Effect：关键词为空时设为 `idle`，否则设为 `loading`，然后发出请求。处理函数只负责更新 `keyword`。

这样一来，只有搜索真正开始时才显示“正在搜索……”，打错又改回的情况下，页面仍显示原来的结果。代价是：输入后等待的 0.5 秒里，页面上还是上一次的内容；清空输入框后，也要过 0.5 秒才显示提示文字。第 84 章会在结果上方写明关键词，让用户分得清眼前的结果属于哪个词。

## 三、动手实现

### 第 1 步：加入防抖后的关键词

在 `src/pages/SearchPage.tsx` 中 `keyword` 的下面加入：

```tsx
  const [debouncedKeyword, setDebouncedKeyword] = useState('');
```

### 第 2 步：加入防抖的 Effect

在搜索的 `useEffect` 前面加入：

```tsx
  useEffect(() => {
    const timerId = setTimeout(() => {
      setDebouncedKeyword(keyword);
    }, 500);
    return () => {
      clearTimeout(timerId);
    };
  }, [keyword]);
```

### 第 3 步：搜索改为依赖防抖后的关键词

在搜索的 Effect 中，第一行改为：

```tsx
    const query = debouncedKeyword.trim();
```

依赖数组改为：

```tsx
  }, [debouncedKeyword]);
```

### 第 4 步：在搜索开始时设置状态

在搜索的 Effect 中，把检查空关键词的部分改为：

```tsx
    const query = debouncedKeyword.trim();
    if (query === '') {
      setSearchState({ status: 'idle' });
      return;
    }
    setSearchState({ status: 'loading' });
```

再把 `handleKeywordChange` 改为只更新关键词：

```tsx
  function handleKeywordChange(event: ChangeEvent<HTMLInputElement>) {
    setKeyword(event.target.value);
  }
```

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。

1. 快速输入 `type`，Network（网络）中只有一个 `search` 请求，地址是 `/api/search?q=type`，结果是“TypeScript 类型检查”。
2. 慢慢输入 `t`、停顿 1 秒、再输入 `ype`：停顿时发出了 `q=t` 的请求，最后又发出 `q=type` 的请求，共两个。
3. 输入期间页面不变，停止输入大约半秒后显示“正在搜索……”并开始请求。
4. 搜出 `type` 的结果后，再输入一个 `s`，然后在半秒内删掉它。页面仍显示 `type` 的结果，Network 中没有新的请求。
5. 清空输入框，大约半秒后显示提示文字。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：把 500 改成 1500，体会等待时间太长的感觉；再改成 100，看看快速输入时会发几个请求。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 仍然每个字发一个请求，只是都晚了 0.5 秒 | 防抖的 Effect 没有返回清理函数，旧的定时任务没有被取消 | 返回 `() => { clearTimeout(timerId); }` |
| 仍然每个字发一个请求，没有延迟 | 搜索的 Effect 仍然依赖 `keyword` | 改为依赖 `debouncedKeyword`，读取的也是它 |
| 输入后页面没有任何变化，Network 中没有请求 | 防抖的 Effect 依赖数组写成了 `[]`，`debouncedKeyword` 只在页面打开时设置了一次 | 写成 `[keyword]` |
| 输入后页面没有任何变化，Network 中也没有请求 | 写成了 `return clearTimeout(timerId);`，定时任务刚安排好就被取消了 | 返回一个函数：`return () => { clearTimeout(timerId); };` |
| 打错一个字又马上删掉，页面一直显示“正在搜索……” | `handleKeywordChange` 中仍在设置 `loading` | 按第 4 步，把设置状态的代码移进搜索的 Effect |

## 六、本章完整代码

### `src/pages/SearchPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import type { ChangeEvent } from 'react';
import ArticleList from '../components/ArticleList';
import { apiUrl } from '../lib/api';
import { isArticle } from '../types/article';
import type { Article } from '../types/article';
import styles from './SearchPage.module.css';

type SearchState =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; items: Article[] }
  | { status: 'error'; message: string };

async function fetchSearchResults(query: string): Promise<Article[]> {
  let response: Response;
  try {
    response = await fetch(apiUrl('/search?q=' + encodeURIComponent(query)));
  } catch {
    throw new Error('无法连接练习服务，请确认它已经启动。');
  }
  if (!response.ok) {
    throw new Error('搜索失败：服务器返回了状态 ' + response.status + '。');
  }
  const data: unknown = await response.json();
  if (
    typeof data !== 'object' ||
    data === null ||
    !('items' in data) ||
    !Array.isArray(data.items) ||
    !data.items.every(isArticle)
  ) {
    throw new Error('搜索结果格式不正确，暂时无法显示。');
  }
  return data.items;
}

export default function SearchPage() {
  const [keyword, setKeyword] = useState('');
  const [debouncedKeyword, setDebouncedKeyword] = useState('');
  const [searchState, setSearchState] = useState<SearchState>({ status: 'idle' });

  useEffect(() => {
    const timerId = setTimeout(() => {
      setDebouncedKeyword(keyword);
    }, 500);
    return () => {
      clearTimeout(timerId);
    };
  }, [keyword]);

  useEffect(() => {
    const query = debouncedKeyword.trim();
    if (query === '') {
      setSearchState({ status: 'idle' });
      return;
    }
    setSearchState({ status: 'loading' });
    let ignore = false;

    async function search() {
      try {
        const items = await fetchSearchResults(query);
        if (!ignore) {
          setSearchState({ status: 'success', items });
        }
      } catch (error) {
        if (!ignore) {
          const message = error instanceof Error ? error.message : '搜索失败。';
          setSearchState({ status: 'error', message });
        }
      }
    }

    search();
    return () => {
      ignore = true;
    };
  }, [debouncedKeyword]);

  function handleKeywordChange(event: ChangeEvent<HTMLInputElement>) {
    setKeyword(event.target.value);
  }

  return (
    <main className="page">
      <h1>搜索文章</h1>
      <div className={styles.searchBox}>
        <label htmlFor="search-keyword">关键词</label>
        <input
          id="search-keyword"
          type="search"
          value={keyword}
          onChange={handleKeywordChange}
        />
      </div>
      {searchState.status === 'idle' && <p className={styles.hint}>输入关键词，搜索文章标题。</p>}
      {searchState.status === 'loading' && <p role="status">正在搜索……</p>}
      {searchState.status === 'error' && <p role="alert">{searchState.message}</p>}
      {searchState.status === 'success' &&
        (searchState.items.length === 0 ? (
          <p className={styles.hint}>没有找到相关文章。</p>
        ) : (
          <ArticleList articles={searchState.items} />
        ))}
    </main>
  );
}
```

## 七、本章改动小结

修改 `src/pages/SearchPage.tsx`：加入 `debouncedKeyword` 和防抖的 Effect，搜索改为在停止输入 0.5 秒后进行；搜索状态改为在搜索的 Effect 中设置。

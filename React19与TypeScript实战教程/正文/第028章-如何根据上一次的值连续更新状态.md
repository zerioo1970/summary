# 第 28 章：如何根据上一次的值连续更新状态？

前置：[第 27 章：如何点击按钮展开或收起一段文字？](第027章-如何点击按钮展开或收起一段文字.md)

## 一、本章要解决的问题

投票区新增一个按钮“非常有帮助（算 2 票）”，点一次要让计数加 2。已经有一个“加 1 票”的逻辑了，最自然的写法是把它调用两次。

但这样写完，点一次“非常有帮助”，计数只加了 1。本章找出原因，并用“更新函数”的写法修好它。完成后，点“有帮助”加 1，点“非常有帮助”加 2。

## 二、必要原理

### 一次事件中，state 的值不会变

第 26 章提过：调用 set 函数后，当前这次执行中的变量不会立刻变成新值。来看问题代码：

```tsx
function addHelpful() {
  setHelpfulCount(helpfulCount + 1);
}

function handleVeryHelpfulClick() {
  addHelpful();
  addHelpful();
}
```

假设当前计数是 3。点击按钮时，这次渲染中的 `helpfulCount` 就是 3，并且在整个事件处理过程中都是 3：

1. 第一次 `addHelpful()`：`setHelpfulCount(3 + 1)`，请求把值设为 4。
2. 第二次 `addHelpful()`：`helpfulCount` 仍然是 3，又是 `setHelpfulCount(3 + 1)`，再次请求设为 4。

两次都是“设为 4”，结果当然是 4，只加了 1。

### React 会把多次更新排队处理

调用 set 函数时，React 不会马上重新渲染，而是把这次更新放进队列，等事件处理函数全部执行完，再统一处理队列、渲染一次。这样一次点击即使修改了好几个 state，页面也只更新一次，效率更高。

### 用更新函数基于上一次的结果计算

set 函数除了接收新值，还可以接收一个**函数**：

```tsx
setHelpfulCount((current) => current + 1);
```

这个函数叫**更新函数**。React 处理队列时，会把“到目前为止最新的值”作为参数 `current` 传给它，用它的返回值作为新值。两次调用的过程变成：

1. 第一个更新函数：`current` 是 3，返回 4。
2. 第二个更新函数：`current` 是上一步的结果 4，返回 5。

最终结果是 5，正确地加了 2。

### 什么时候用更新函数

新值要**根据旧值计算**时（加 1、取反、在数组末尾追加），用更新函数更可靠，不用担心同一次事件中多次更新互相覆盖。新值和旧值无关时（例如直接设为 0），直接传值即可。

更新函数的参数名可以自己起，常见的有 `current`、`prev` 或者 state 名称的首字母。

## 三、动手实现

### 第 1 步：先写出有问题的版本

打开 `src/pages/FaqPage.tsx`，把 `handleHelpfulClick` 替换为下面三个函数：

```tsx
  function addHelpful() {
    setHelpfulCount(helpfulCount + 1);
  }

  function handleHelpfulClick() {
    addHelpful();
  }

  function handleVeryHelpfulClick() {
    addHelpful();
    addHelpful();
  }
```

在“有帮助”按钮的后面加入新按钮：

```tsx
        <button type="button" onClick={handleHelpfulClick}>
          有帮助（{helpfulCount}）
        </button>{' '}
        <button type="button" onClick={handleVeryHelpfulClick}>
          非常有帮助（算 2 票）
        </button>
```

`{' '}` 在两个按钮之间放一个空格。JSX 会忽略标签之间的换行，不加它两个按钮会紧贴在一起。

保存后点击“非常有帮助”，计数只加了 1。

### 第 2 步：改用更新函数

把 `addHelpful` 中的那一行改为：

```tsx
  function addHelpful() {
    setHelpfulCount((current) => current + 1);
  }
```

只改了这一行，其他代码不变。

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 点击“有帮助”，计数从 0 变成 1。
2. 点击“非常有帮助”，计数从 1 变成 3。
3. 再交替点几次，每次“有帮助”加 1，“非常有帮助”加 2。
4. 把 `addHelpful` 临时改回 `setHelpfulCount(helpfulCount + 1)`，再点“非常有帮助”，又只加 1。检查后改回更新函数。


## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 连续调用两次，只加了 1 | 两次都用了这次渲染中同一个旧值 | 改用 `setHelpfulCount((current) => current + 1)` |
| 在 set 之后立刻 `console.log(helpfulCount)`，打印的还是旧值 | state 要到下一次渲染才变成新值 | 这是正常行为；需要新值时，先算出来存到一个普通变量中再使用 |
| 点击后括号里的数字消失，再点也不会出现，编辑器中也有红线 | 更新函数写成了 `(current) => { current + 1 }`，花括号中没有 `return`，每次都返回“没有值” | 写成 `(current) => current + 1`，或在花括号中写 `return` |
| 编辑器提示参数类型不对 | 更新函数中把 `current` 当成了别的类型使用 | `current` 的类型与 state 相同，这里是数字 |
| 两个按钮紧贴在一起 | 没有加 `{' '}` | 在两个按钮之间加一个空格 |

## 六、本章完整代码

### `src/pages/FaqPage.tsx`

```tsx
import { useState } from 'react';
import styles from './FaqPage.module.css';

export default function FaqPage() {
  const [helpfulCount, setHelpfulCount] = useState(0);
  const [isAnswerOpen, setIsAnswerOpen] = useState(false);

  function addHelpful() {
    setHelpfulCount((current) => current + 1);
  }

  function handleHelpfulClick() {
    addHelpful();
  }

  function handleVeryHelpfulClick() {
    addHelpful();
    addHelpful();
  }

  function handleContactClick() {
    window.alert('客服邮箱：help@example.com，工作日 9:00—18:00 回复。');
  }

  return (
    <main className="page">
      <h1>常见问题</h1>
      <div className={styles.item}>
        <h2 className={styles.question}>忘记密码怎么办？</h2>
        <button
          type="button"
          aria-expanded={isAnswerOpen}
          onClick={() => setIsAnswerOpen(!isAnswerOpen)}
        >
          {isAnswerOpen ? '收起' : '展开'}
        </button>
        {isAnswerOpen && (
          <p className={styles.answer}>在登录页点击“忘记密码”，按提示通过邮箱重设。</p>
        )}
      </div>
      <section className={styles.section}>
        <h2>这些回答对你有帮助吗？</h2>
        <button type="button" onClick={handleHelpfulClick}>
          有帮助（{helpfulCount}）
        </button>{' '}
        <button type="button" onClick={handleVeryHelpfulClick}>
          非常有帮助（算 2 票）
        </button>
      </section>
      <section className={styles.section}>
        <p>没有找到答案？</p>
        <button type="button" onClick={handleContactClick}>
          联系客服
        </button>
      </section>
    </main>
  );
}
```

修改 `src/pages/FaqPage.tsx`：新增 `addHelpful` 和“非常有帮助”按钮，`addHelpful` 使用更新函数，保证连续两次更新都生效。

# 第 126 章：为什么定时器中读到的状态可能一直是旧值？

前置：[第 125 章：如何在窗口大小变化时更新页面？](第125章-如何在窗口大小变化时更新页面.md)

## 一、本章要解决的问题

设置页要显示“你已经在本页停留了 N 秒。”，每秒加 1。照第 81 章的写法，在 Effect 中用 `setInterval` 每秒执行一次 `setSeconds(seconds + 1)`，结果数字变成 1 以后就再也不动了。定时器明明每秒都在执行，为什么读到的 `seconds` 一直是 0？

本章弄清楚这个问题的原因，并用更新函数改正。完成后：设置页底部的停留时间每秒加 1；离开设置页再回来，从 0 重新开始计时。

## 二、必要原理

### 函数记住的是它被创建时的值

组件每次渲染都是重新执行一遍组件函数，每一次执行都有自己的一份 `seconds`（第 25、28 章）。第一次渲染时 `seconds` 是 0。

Effect 的依赖数组是 `[]`，只在第一次渲染后执行一次。传给 `setInterval` 的箭头函数就是在这一次中创建的，它里面用到的 `seconds`，永远是第一次渲染时的那个 0：

```tsx
useEffect(() => {
  const timerId = setInterval(() => {
    setSeconds(seconds + 1); // 这里的 seconds 永远是 0
  }, 1000);
  return () => clearInterval(timerId);
}, []);
```

于是每一秒执行的都是 `setSeconds(0 + 1)`。第一秒数字从 0 变成 1，之后每次都把它设成 1，看起来就不动了。组件虽然重新渲染了，拿到了新的 `seconds`，但定时器中的函数还是最初那一个，看不到新值。

这种“函数一直拿着创建时的旧值”的问题，常被叫作**过期的闭包**。检查命令也会提示：`React Hook useEffect has a missing dependency: 'seconds'`。

### 改法一：用更新函数

只是要在当前值的基础上改，就用第 28 章的更新函数：

```tsx
setSeconds((current) => current + 1);
```

React 会把最新的值交给 `current`，定时器中的函数不需要自己记住 `seconds`。依赖数组仍然是 `[]`，定时器只创建一次。

### 为什么不把 seconds 写进依赖数组

照检查命令的提示写成 `[seconds]` 也能正常计时，但过程是：每过一秒，`seconds` 变了，React 先执行清理函数，清除旧的定时器，再执行 Effect，创建一个新的定时器。定时器每秒被拆掉重建一次，白白做了很多事；如果间隔不是整秒，计时还会被打乱。所以能用更新函数时，优先用更新函数。

### 改法二：要“读”最新值，用 useEffectEvent

有时定时器不是要修改 state，而是要**读**最新的值去做别的事，例如每 5 秒把当前的输入内容保存为草稿。这时更新函数帮不上忙，要用第 82 章的 `useEffectEvent`：把读取最新值的那部分包进去，在定时器中调用它。

| 定时器中要做的事 | 写法 |
| --- | --- |
| 在当前值的基础上修改 state | 更新函数：`setX((current) => …)` |
| 读取最新的 state 或 props 去做别的事 | `useEffectEvent` 包住读取的部分 |

## 三、动手实现

### 第 1 步：写停留时间组件

新建 `src/components/StayTimer.tsx`：

```tsx
import { useEffect, useState } from 'react';

export default function StayTimer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const timerId = setInterval(() => {
      // 用更新函数：每次都在最新的秒数上加 1，而不是 Effect 执行那一刻的旧值
      setSeconds((current) => current + 1);
    }, 1000);
    return () => {
      clearInterval(timerId);
    };
  }, []);

  return <p>你已经在本页停留了 {seconds} 秒。</p>;
}
```

清理函数中清除定时器，离开设置页时就不再计时（第 81 章）。

### 第 2 步：在设置页中使用

打开 `src/pages/SettingsPage.tsx`，在导入设置函数的一行上面加入：

```tsx
import StayTimer from '../components/StayTimer';
```

在“修改后会自动保存……”这一行提示的下面加入：

```tsx
        <StayTimer />
```

## 四、运行与检查

保持开发服务器运行（`npm.cmd run dev`），保存文件后在浏览器中查看。

1. 打开设置页，底部显示“你已经在本页停留了 0 秒。”，之后每秒加 1。
2. 修改称呼、切换主题，计时不受影响，继续增加。
3. 点导航中的“新闻”再回到设置页，从 0 重新开始。
4. 做一个小实验：把 `setSeconds((current) => current + 1)` 改成 `setSeconds(seconds + 1)`。运行检查命令，看到 `missing dependency: 'seconds'` 的提示；页面上数字变成 1 以后就不再变化。再把依赖数组改成 `[seconds]`，又能正常计时了，但每秒都会清除并重建一次定时器。实验后恢复本章代码。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：给 `StayTimer` 加一个“暂停 / 继续”按钮，暂停时数字不再增加。提示：用一个 state 记住是否暂停，并写进 Effect 的依赖数组；暂停时 Effect 直接 `return`，不创建定时器，写法和第 81 章“自动刷新”的开关相同。练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 数字变成 1 以后就不动了，检查命令提示 `React Hook useEffect has a missing dependency: 'seconds'` | 定时器中的函数是第一次渲染时创建的，读到的 `seconds` 永远是 0 | 改用更新函数 `setSeconds((current) => current + 1)` |
| 能计时，但定时器每秒都被清除、重新创建 | 依赖数组写成了 `[seconds]` | 用更新函数，依赖数组写 `[]` |
| 离开设置页后，控制台中仍有和计时有关的输出，或者回来后一秒跳好几下 | 没有在清理函数中 `clearInterval` | 返回清理函数，清除定时器 |

### `src/pages/SettingsPage.tsx`

```tsx
import { useEffect, useState } from 'react';
import StayTimer from '../components/StayTimer';
import { applyTheme, loadSettings, saveSettings } from '../lib/settings';
import type { Settings } from '../lib/settings';
import styles from './SettingsPage.module.css';

export default function SettingsPage() {
  // 传入函数而不是调用结果：只在第一次渲染时读取一次本地存储
  const [settings, setSettings] = useState<Settings>(loadSettings);
  const previewClass =
    settings.fontSize === 'large' ? styles.preview + ' ' + styles.large : styles.preview;
  const displayName = settings.nickname.trim() === '' ? '朋友' : settings.nickname.trim();

  // settings 每次变化都保存一次，用户不需要再点按钮
  useEffect(() => {
    saveSettings(settings);
  }, [settings]);

  // 主题变了，马上换掉整个页面的颜色
  useEffect(() => {
    applyTheme(settings.theme);
  }, [settings.theme]);

  return (
    <main className="page">
      <title>个人设置</title>
      <h1>个人设置</h1>
      <div className={styles.form}>
        <div className={styles.field}>
          <label htmlFor="nickname">称呼</label>
          <input
            id="nickname"
            value={settings.nickname}
            onChange={(event) => setSettings({ ...settings, nickname: event.target.value })}
          />
        </div>
        <fieldset className={styles.options}>
          <legend>字号</legend>
          <label>
            <input
              type="radio"
              name="fontSize"
              checked={settings.fontSize === 'normal'}
              onChange={() => setSettings({ ...settings, fontSize: 'normal' })}
            />
            标准
          </label>
          <label>
            <input
              type="radio"
              name="fontSize"
              checked={settings.fontSize === 'large'}
              onChange={() => setSettings({ ...settings, fontSize: 'large' })}
            />
            较大
          </label>
        </fieldset>
        <fieldset className={styles.options}>
          <legend>主题</legend>
          <label>
            <input
              type="radio"
              name="theme"
              checked={settings.theme === 'light'}
              onChange={() => setSettings({ ...settings, theme: 'light' })}
            />
            浅色
          </label>
          <label>
            <input
              type="radio"
              name="theme"
              checked={settings.theme === 'dark'}
              onChange={() => setSettings({ ...settings, theme: 'dark' })}
            />
            深色
          </label>
        </fieldset>
        <div className={previewClass}>你好，{displayName}！这是预览文字。</div>
        <p className={styles.hint}>修改后会自动保存，刷新页面后仍然有效。</p>
        <StayTimer />
      </div>
    </main>
  );
}
```

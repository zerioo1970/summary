# 第 64 章：请求尚未完成时，如何显示加载提示？

前置：[第 63 章：如何在浏览器中查看一次请求实际发送和返回了什么？](第063章-如何在浏览器中查看一次请求实际发送和返回了什么.md)

## 一、本章要解决的问题

点击“加载文章”后，要等半秒左右文章才出现。这段时间里页面没有任何变化，用户不知道是否点上了，可能会连续点好几次，发出好几个相同的请求。网络慢的时候，等待会更长。

本章在请求进行期间显示“正在加载文章……”，同时禁用“加载文章”按钮；请求结束后，无论成功还是失败，提示都消失，按钮恢复可用。

本章完成后，点击“加载文章”到文章出现之前，页面如下图：

## 二、必要原理

### 用一个 state 记住“是否正在加载”

“正在加载”会变化，变化后页面要更新，所以放进 state：

```tsx
const [isLoading, setIsLoading] = useState(false);
```

布尔值的 state 名称常用 `is` 开头，读起来像一个问题：“正在加载吗？”

请求开始前设为 `true`，请求结束后设为 `false`。页面根据它显示提示、禁用按钮，用的都是学过的写法：`{isLoading && <p>…</p>}`（第 21 章：只给符合条件的项显示标记）和 `disabled={isLoading}`（第 38 章：读取复选框是否被选中）。

### 无论成功失败都要结束加载：finally

请求可能成功，也可能失败跳到 `catch`。如果只在 `try` 的末尾写 `setIsLoading(false)`，失败时就不会执行，提示永远显示，按钮永远不能点。在 `try` 和 `catch` 中各写一遍也行，但容易漏。

`try...catch` 后面可以再接一个 `finally`：

```tsx
try {
  // 发送请求，处理结果
} catch {
  // 处理失败
} finally {
  setIsLoading(false);
}
```

`finally` 中的代码在 `try` 正常结束后执行，在 `catch` 处理完后也执行。“无论如何都要做的收尾工作”就写在这里。

### 页面什么时候显示加载提示

`handleLoad` 一开始调用 `setIsLoading(true)`，到 `await fetch(...)` 时函数暂停等待。React 利用这段空闲重新渲染，页面就显示出加载提示。等请求完成，函数从暂停处继续执行，最后在 `finally` 中设回 `false`，页面再次更新。

### 用 role="status" 告诉读屏软件

加载提示加上 `role="status"`，读屏软件会在不打断用户的情况下读出它。错误提示用的 `role="alert"` 会立刻打断朗读，适合更紧急的信息。

## 三、动手实现

### 第 1 步：加入加载状态

在 `src/pages/ArticlePage.tsx` 中 `error` 的下面加入：

```tsx
  const [isLoading, setIsLoading] = useState(false);
```

### 第 2 步：请求前后修改加载状态

把 `handleLoad` 改为：

```tsx
  async function handleLoad() {
    setError('');
    setIsLoading(true);
    try {
      const response = await fetch('http://127.0.0.1:3001/api/articles');
      if (!response.ok) {
        throw new Error('接口返回状态 ' + response.status);
      }
      const data = (await response.json()) as Article[];
      setArticles(data);
    } catch {
      setError('文章读取失败，请确认练习服务已经启动。');
    } finally {
      setIsLoading(false);
    }
  }
```

新增的是第 3 行的 `setIsLoading(true)` 和最后的 `finally`。

### 第 3 步：禁用按钮并显示提示

把“加载文章”按钮和它下面一行改为：

```tsx
      <button type="button" onClick={handleLoad} disabled={isLoading}>
        加载文章
      </button>
      {isLoading && <p role="status">正在加载文章……</p>}
```

## 四、运行与检查

保持开发服务器和练习服务都在运行（准备篇二）。

1. 点击“加载文章”，按钮立刻变成半透明，下方出现“正在加载文章……”；大约半秒后提示消失，文章出现，按钮恢复。
2. 把请求地址临时加上 `?delay=3000`，点击后提示显示 3 秒。这期间连续点击按钮，在 Network（网络）面板（第 63 章）中只看到一个请求。看完后去掉 `?delay=3000`。
3. 停止练习服务，点击“加载文章”：提示短暂出现后消失，显示错误信息，按钮恢复可用。
4. 重新启动练习服务，再点击，文章正常显示。

最后运行检查，应没有错误：

```powershell
npm.cmd run check
```

**小练习**：加载期间把按钮上的文字改为“加载中……”，加载结束后恢复为“加载文章”。（提示：按钮中间写一个条件运算符。）练习后恢复本章代码。

## 五、常见错误

| 现象 | 原因 | 怎么改 |
| --- | --- | --- |
| 请求失败后，“正在加载文章……”一直不消失 | `setIsLoading(false)` 只写在了 `try` 的末尾，失败时没有执行 | 写在 `finally` 中 |
| 加载提示一闪都不出现 | `setIsLoading(true)` 写在了 `await fetch(...)` 之后 | 在发请求之前设为 `true` |
| 加载期间按钮仍然可以点击 | 漏写了 `disabled={isLoading}` | 给按钮加上 `disabled` |
| 页面同时显示加载提示和上一次的错误 | 开始加载时没有清空错误 | 保留开头的 `setError('')` |
| 学完本章后，页面一直报错、一直显示空数据或加载很慢 | 步骤中临时加在请求地址上的 `?mode=`、`?fail=`、`?delay=`、`?cors=` 等参数忘了删 | 运行 `git diff` 查看本章改动，删掉地址中的临时参数 |

## 六、本章完整代码

### `src/pages/ArticlePage.tsx`

```tsx
import { useState } from 'react';

type Article = {
  id: number;
  title: string;
};

export default function ArticlePage() {
  const [articles, setArticles] = useState<Article[]>([]);
  const [error, setError] = useState('');
  const [isLoading, setIsLoading] = useState(false);

  async function handleLoad() {
    setError('');
    setIsLoading(true);
    try {
      const response = await fetch('http://127.0.0.1:3001/api/articles');
      if (!response.ok) {
        throw new Error('接口返回状态 ' + response.status);
      }
      const data = (await response.json()) as Article[];
      setArticles(data);
    } catch {
      setError('文章读取失败，请确认练习服务已经启动。');
    } finally {
      setIsLoading(false);
    }
  }

  return (
    <main className="page">
      <h1>文章列表</h1>
      <button type="button" onClick={handleLoad} disabled={isLoading}>
        加载文章
      </button>
      {isLoading && <p role="status">正在加载文章……</p>}
      {error && <p role="alert">{error}</p>}
      <ul>
        {articles.map((article) => (
          <li key={article.id}>{article.title}</li>
        ))}
      </ul>
    </main>
  );
}
```

## 七、本章改动小结

修改 `src/pages/ArticlePage.tsx`：加入 `isLoading` state，请求期间显示加载提示并禁用按钮。

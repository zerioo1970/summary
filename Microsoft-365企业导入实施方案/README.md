## 5. 统一提示标记

- **必做：** 不完成就不能进入下一阶段。
- **推荐：** 不是强制要求，但建议采用。
- **按需：** 根据企业环境、许可证或业务要求决定。
- **高风险：** 可能影响登录、邮件收发、权限或数据。
- **验证点：** 操作后必须执行的检查。
- **回退点：** 出现问题时恢复原状态的方法。
- **许可证要求：** 使用功能需要核对的许可证能力。

## 6. 当前需要确认的企业信息

- [ ] 使用 Microsoft 365 全球版还是世纪互联运营版。
- [ ] 租户创建国家或地区（决定 Default Geography，创建后不能直接更改）。
- [ ] 企业员工数量、办公地点和本期上线人数。
- [ ] 已购买或计划购买的许可证。
- [ ] 是否存在本地 Active Directory。
- [ ] 是否存在本地 Exchange Server。
- [ ] 当前邮箱系统、邮箱数量和总数据量。
- [ ] 是否迁移日历、联系人、共享邮箱和代理权限。
- [ ] 当前 Office 版本及宏、插件和业务系统依赖。
- [ ] 是否允许员工使用个人电脑和个人手机。
- [ ] 是否计划使用 Intune。
- [ ] Teams 是否需要外部来宾和外部文件共享。
- [ ] 邮件、Teams 和文件的保留要求。
- [ ] 是否需要第三方 Microsoft 365 备份。
- [ ] 计划一次性上线还是分批上线。

## 8. 内容维护原则

1. 一次只写一个小节文件，写完立即存盘。
2. 正式实施前优先核对 Microsoft 官方文档。
3. 全球版和世纪互联运营版的功能不得混写为完全相同。
4. 许可证能力不得只依据产品名称猜测。
5. 高风险操作必须写明准备、验证和回退。
6. 示例账号、域名和人员信息均使用虚构数据；不保存真实密码、恢复码或密钥。
7. 管理页面变化时，优先保留操作目的和验证方法，再更新导航路径。
8. 每完成一节，更新对应篇 `README.md` 和本页的进度与日期。

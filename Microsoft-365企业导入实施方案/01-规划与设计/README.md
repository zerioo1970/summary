## 二、本篇必须产出的结论

进入第2篇之前，以下决策必须有书面结论或明确的负责人和截止日期：

- [ ] 使用 Microsoft 365 全球版还是世纪互联运营版。
- [ ] 租户创建国家或地区（决定 Default Geography，创建后不能直接更改）。
- [ ] 纯云身份还是混合身份，以及是否使用 Entra Connect Sync 或 Cloud Sync。
- [ ] 邮件迁移方式、批次划分和最终切换窗口。
- [ ] Office、Teams、SharePoint/OneDrive 的部署范围和用户分组。
- [ ] 设备管理层级（仅账号保护、应用数据保护还是完整设备管理）。
- [ ] 最低安全基线，包括 MFA、管理员分离、紧急访问账号和邮件身份验证。
- [ ] 按用户画像估算的许可证需求。
- [ ] 试点范围、量化验收标准、回退计划和风险责任人。

详细检查表见 [计划、职责、验收与风险 · 1.35.2](08-计划风险与验收.md)。

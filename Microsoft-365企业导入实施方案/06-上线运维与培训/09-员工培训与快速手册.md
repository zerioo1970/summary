## 6.92 员工培训的三个原则

| 原则 | 说明 |
|---|---|
| **少而精** | 一次培训只讲 5～7 件事，其余放手册 |
| **按需分层** | 全员必学 + 按岗位补充，不要所有人听所有内容 |
| **可查可练** | 提供一页纸手册和图文指引，能随时查 |

### 6.92.1 员工真正需要会的事

按重要性排序，全员必须掌握：

| 排序 | 内容 | 为什么最重要 |
|---|---|---|
| 1 | **完成 MFA 注册，并注册两种方式** | 不做就无法登录 |
| 2 | **收到未发起的验证请求要拒绝并报告** | 防 MFA 疲劳攻击 |
| 3 | **识别可疑邮件并知道如何报告** | 防钓鱼与 BEC |
| 4 | **文件应该放哪里** | 决定文件是否安全、可交接 |
| 5 | **文件误删怎么自己找回** | 减少工单 |
| 6 | 换手机、丢手机怎么办 | 高频场景 |
| 7 | Teams 开会与共享文件的基本操作 | 日常使用 |

> **必做：** 第 2 项和第 3 项属于**安全意识**，比任何操作技巧都重要。技术措施可以被绕过，但一个警觉的员工能挡住攻击。

## 6.93 培训形式与安排

| 形式 | 适合 | 时长 |
|---|---|---|
| 集中培训（现场或线上） | 全员基础 | **30～45 分钟**（不要超过 1 小时） |
| 部门专项 | 财务、销售等特殊需求 | 20～30 分钟 |
| 一对一 | 管理层、助理 | 按需 |
| 图文指引 | 自助查阅 | — |
| 短视频 | 高频操作（如 MFA 注册） | 每个 2～3 分钟 |
| 新员工培训 | 入职流程的一部分 | 纳入 N12 |

### 6.93.1 培训时间安排

| 时间 | 内容 |
|---|---|
| 上线前 1～2 周 | 集中培训（重点：MFA 注册、切换期注意事项） |
| 上线前 1 周 | 图文指引发布 |
| 上线当天 | 现场支持 |
| 上线后 1～2 周 | 答疑场次（解决实际遇到的问题） |
| 上线后 1 个月 | 进阶培训（Teams、文件协作的更好用法） |
| 每年 | 复训（重点：安全意识） |

> **推荐：** **上线后的答疑场次比上线前的培训更有效**。因为此时用户已经遇到了真实问题，学习动机最强。

## 6.94 培训内容一：第一次登录与 MFA 注册

这是**最关键**的一段，必须讲清、演示、并让员工当场完成。

### 6.94.1 讲解要点

1. 为什么要做（一句话：防止密码泄露导致账号被盗）。
2. 需要什么（手机或公司发的安全密钥）。
3. 怎么做（现场演示 + 图文步骤）。
4. **要注册两种方式**（万一手机不在身边）。
5. 完成后测试一次登录。
6. 没有手机怎么办（联系谁）。

### 6.94.2 关键安全提示（必须强调）

> **告诉员工：**
>
> **"如果你没有在登录，却收到了验证请求，绝对不要批准，并立即告知 IT。"**
>
> 这通常意味着你的密码已经泄露，攻击者正在尝试登录。

### 6.94.3 常见疑问的标准答复

| 员工疑问 | 标准答复 |
|---|---|
| 公司会看到我手机里的东西吗？ | **不会。** 公司只能验证你的登录，看不到你的照片、微信或通话记录 |
| 我不想在私人手机上装公司应用 | 可以申请公司提供的安全密钥（联系 IT） |
| 每次登录都要验证吗？ | 在常用设备上通常不用每次都验证 |
| 出国/没信号怎么办？ | 建议注册第二种方式（如验证码），不依赖网络推送 |
| 手机丢了怎么办？ | 立即联系 IT，会有身份核验后的恢复流程 |
| 换手机要做什么？ | 换之前先确认还有其他登录方式，然后在新手机上注册 |

## 6.95 培训内容二：安全意识（防钓鱼与 BEC）

### 6.95.1 要让员工识别的三类邮件

| 类型 | 特征 | 员工该做什么 |
|---|---|---|
| **钓鱼** | 要求点链接输账号密码、制造紧急感 | 不点、不填、报告 |
| **恶意附件** | 要求"启用内容"、陌生附件 | 不打开、报告 |
| **BEC 欺诈** | 冒充领导或供应商要求转账、变更收款账号，**通常没有链接和附件** | **电话回拨核实**、报告 |

### 6.95.2 五个实用判断技巧

1. **看有没有"外部"标识**（第3篇 3.22）——公司内部邮件不会带这个标识。
2. **看发件地址是否精确**——`ceo@contoso.com` 与 `ceo@cont0so.com` 差一个字符。
3. **警惕"紧急 + 保密 + 别问别人"**——这是欺诈的经典组合。
4. **涉及钱和账号密码的，一律换渠道核实**——打电话，用你手机里存的号码，不要用邮件里给的号码。
5. **链接先悬停看目标地址**——不确定就不点。

### 6.95.3 财务、采购、人事的额外要求

> **必做：** 对这些岗位单独培训并写进制度：
>
> - **变更收款账号必须电话回拨确认**（用系统里预存的号码，不是邮件里的号码）。
> - **超过一定金额的付款必须双人复核。**
> - **领导"紧急、保密、马上办"的要求，一律按标准流程核实**——真领导不会因为你核实而生气。
>
> 这三条比任何技术配置都更能防住 BEC（第3篇 3.26）。

### 6.95.4 报告渠道

- [ ] 明确的报告方式（一键上报按钮、或转发到指定地址）。
- [ ] 告诉员工"**报告错了也没关系，宁可多报**"。
- [ ] **报告后要有回音**（第5篇 5.8）——否则员工不会再报。

## 6.96 培训内容三：文件应该放哪里

### 6.96.1 一句话规则

> **"自己一个人用的放 OneDrive，大家一起用的放 Teams 或 SharePoint。"**

### 6.96.2 需要讲清的四点

| 要点 | 说明 |
|---|---|
| **部门文件不要只放在自己的 OneDrive** | 你离职或休假时别人拿不到 |
| 文件用**链接分享**，不要发附件 | 版本统一、权限可控、不占邮箱 |
| 分享时选"**指定的人**"，不要用"任何人" | 后者任何拿到链接的人都能打开 |
| 云朵图标不是文件丢了 | 文件在云端，双击就能打开 |

### 6.96.3 出差前的准备

> **推荐：** 明确告诉经常出差的员工：**出差前把需要的文件标记为"始终保留在此设备上"**，否则没网时打不开（第4篇 4.104）。

## 6.97 培训内容四：文件误删与找回

教会员工自助恢复，能显著减少工单。

| 场景 | 员工自己能做的 |
|---|---|
| 文件删错了 | 打开**回收站**还原 |
| 文件改坏了、覆盖了 | 用**版本历史**还原到之前版本 |
| 整个文件夹没了 | 先查回收站；不行找 IT |
| 找不到文件 | 用搜索；检查是否在别的位置 |

> **必做：** 演示"版本历史"的用法。很多员工仍在用"文件名加日期"管理版本（第4篇 4.91），教会他们这一个功能就能改善协作质量。

### 6.99.1 会议质量的用户侧建议

> **推荐：** 告诉员工三件能立刻改善会议体验的事：
>
> 1. **用耳机**（避免回声和噪音）。
> 2. 不说话时**静音**。
> 3. 网络不好时**关闭视频**（优先保证声音）。
>
> 这三条能解决相当一部分"会议质量差"的抱怨（第4篇 4.77）。

## 6.102 快速手册（一页纸）

建议制作**一页纸**（正反面）的员工快速手册，内容：

### 正面：日常操作
1. 登录地址与账号格式。
2. MFA 注册二维码或链接。
3. 文件放哪里（一张简图）。
4. 如何分享文件（选"指定的人"）。
5. 如何找回删除的文件。
6. Teams 开会基本操作。

### 反面：出问题怎么办
1. 登录不上 → 检查什么 → 找谁。
2. 手机丢了 → 立即联系 IT（电话）。
3. 收到可疑邮件 → 如何报告。
4. **收到未发起的验证请求 → 拒绝并立即报告**。
5. 邮件没收到 → 先查垃圾箱 → 再报工单。
6. 服务台联系方式与值班时间。

> **推荐：** 一页纸手册比十页文档有效得多。可以打印贴在工位，或做成手机壁纸尺寸的图片发到群里。

## 6.104 培训效果确认

| 方式 | 说明 |
|---|---|
| 签到记录 | 谁参加了、谁没参加（需补） |
| **MFA 注册率** | 最直接的效果指标 |
| 工单类型分布 | 培训到位的领域工单会减少 |
| 简短问卷 | 3～5 题，问是否清楚、还需要什么 |
| 抽查 | 随机问几个员工"文件应该放哪里" |
| 钓鱼演练（如有能力） | 检验安全意识 |

### 6.104.1 需要补课的信号

| 信号 | 说明 |
|---|---|
| MFA 注册率停滞 | 指引不清或有阻力 |
| 大量"找不到文件"工单 | 存放规则培训不足 |
| 大量"邮件没收到"工单 | 未教会查垃圾箱与隔离通知 |
| 无人报告可疑邮件 | 报告渠道不清或没有回音 |
| 仍用邮件附件传文件 | 未接受链接分享方式 |

## 6.79 本节目标

完成本节后，企业的管理员应当能够**独立完成日常运维**，不依赖实施方或外部支持。

### 6.79.1 判断培训是否成功的标准

不是"听完了课"，而是能否**独立完成以下操作**：

| 编号 | 能力 | 验证方式 |
|---|---|---|
| K1 | 创建账号、分配许可、加入组 | 实操 |
| K2 | 处理用户 MFA 问题（换手机、丢手机） | 实操 |
| K3 | 用紧急访问账号登录 | 演练 |
| K4 | 用邮件追踪定位"邮件去哪了" | 实操 |
| K5 | 处理隔离区中的误判邮件 | 实操 |
| K6 | 恢复用户误删的文件 | 实操 |
| K7 | 查审计日志回答"谁做了什么" | 实操 |
| K8 | 执行完整的离职流程 | 演练 |
| K9 | 判断并处理疑似账号被盗 | 演练 |
| K10 | 按变更流程修改一条策略并回退 | 演练 |

> **必做：** 培训验收要用**实操**，不是问答。让管理员在测试环境或用测试账号真实操作一遍，才知道是否真的会。

## 6.80 培训对象与分层

| 对象 | 培训深度 | 时长建议 |
|---|---|---|
| **主管理员** | 全部内容 | 完整培训 |
| 各领域管理员（身份/邮件/协作/终端） | 本领域深入 + 其他领域了解 | 分模块 |
| 安全负责人 | 安全、审计、事件处理 | 专项 |
| **服务台** | 一线支持操作 + 升级判断 | 重点培训 |
| 业务联系人 | 团队与来宾管理、复核配合 | 简要 |
| 备份人员 | 紧急操作 | 关键操作 |

> **推荐：** **服务台的培训优先级不低于管理员**。他们处理 80% 的日常问题，培训到位能大幅减少升级到管理员的工单量。

## 6.90 培训考核

### 6.90.1 考核方式

| 方式 | 说明 |
|---|---|
| **实操考核**（主要） | 在测试环境完成 K1～K10 的任务 |
| 场景问答 | 给出场景，说明处置步骤 |
| 文档查找 | 能在方案文档中快速找到对应章节 |

### 6.90.2 考核场景示例

| 编号 | 场景 | 考核点 |
|---|---|---|
| S1 | "用户说客户发的邮件没收到" | 邮件追踪流程 |
| S2 | "用户手机丢了，登不进去" | 身份核验 + TAP |
| S3 | "财务说宏跑不了了" | 宏策略与受信任位置 |
| S4 | "用户误删了整个文件夹" | 恢复手段选择 |
| S5 | "收到告警说某账号异常登录" | 账号被盗处理 |
| S6 | "老板说要查谁把文件发给了外部" | 审计查询 |
| S7 | "有员工今天离职" | 离职流程 + 五项必查 |
| S8 | "要改一条条件访问策略" | 变更流程 + 紧急账号验证 |
| S9 | "所有管理员都登不进管理中心" | 紧急访问账号 |
| S10 | "财务收到变更收款账号的邮件" | BEC 处理 + 电话回拨 |

> **必做：** S9 和 S10 必须考核。这两个场景发生频率不高，但后果最严重，且**临场学习来不及**。

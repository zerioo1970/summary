## 学习建议

1. **按顺序阅读**:章节之间层层递进,每章末尾都有"承上启下"衔接下一章。
2. **先建直觉,再抠细节**:第一遍抓住比喻和图解建立整体感觉,不必纠结每个公式。
3. **动手跑代码**:第 3、4、5、9 章都有可运行的 PyTorch 代码,强烈建议亲自运行、修改。
4. **反复回看**:理解 Transformer 是螺旋上升的过程,学到后面可以回头重读前面的章节。
